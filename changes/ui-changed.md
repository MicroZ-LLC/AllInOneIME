## en

- A fresh install opens the start even when macOS leaves adding the input source to you: the installer's last button, Get Started, opens it, and its first step says where to add AllInOneIME, with Open Keyboard Settings, and goes on by itself once it's added. An update whose input source isn't added still says how in the installer.
- Settings → AI: with a CLI chosen, the line beside the AIs no longer says every AI feature uses it; it says `@question` does, and the line above says where the rest goes. Settings → Common → Autocomplete: with a CLI chosen and no faster AI, the switch shows off and can't be turned on, the reason under it (your setting is kept for when there is one).
- In an app with No AI, or in a password field, an AI command typed by its name after the magic key (`@que` → `question`) is still listed, but dimmed, with why: "No AI in this app" or "No AI in a password field". ⏎, its number or a click on it only says so, and the list stays; Tab still writes the command, which is refused when run, as before.

## zh-CN

- 新装时即使 macOS 要你自己添加输入法，也会打开上手：安装程序最后的按钮「开始使用」打开它，第 1 步写着在哪里添加 AllInOneIME，带「打开键盘设置」按钮，加好以后自己往下走。更新后输入法不在列表里时，安装程序照旧说明怎么加。
- 设置 →「AI」：选了 CLI 时，卡片旁边那行不再说所有 AI 功能都用它，而是说 `@question` 用它，别的功能用哪家见上面那行。设置 →「常用」→「续写」：选了 CLI、又没有更快的 AI 时，开关显示为关，打不开，下面写着原因（你的设置保留着，有了更快的 AI 就照旧）。
- 在关了 AI 的 App 里或密码框里，魔法键后面按名字打的 AI 命令（`@que` → `question`）仍会列出，但显示为灰色，写着原因：「这个 App 里不用 AI」或「密码框里不用 AI」。在它上面按 ⏎、它的编号或点它，只会提示原因，列表不变；按 Tab 照旧只写出命令，执行时被拒绝。
