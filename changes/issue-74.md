## en

- Suggestions show no rows and look nothing up in password managers (1Password, Bitwarden and others), as autocomplete
  and learning already leave them alone.
- Keys received in a password manager before its field is activated no longer learn words, show suggestions, or start autocomplete.
- When a field is later identified as a password field, its suggestion rows disappear and the typed suggestion token is forgotten.

## zh-CN

- 在密码管理器（1Password、Bitwarden 等）里不再出联想行，也不再查询来源，和自动补全、学习一样不碰它们。
- 密码管理器的输入框尚未通知输入法获得焦点时，收到的按键不再学词、显示建议或启动续写。
- 输入框后来被认定为密码框时，建议行会消失，输入法也会忘掉用于建议的已输入文字。
