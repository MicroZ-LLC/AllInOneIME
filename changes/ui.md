## en

- The input menu's Translate to → Add or Reorder Languages… opens Settings → Common at Translate to; it opened Settings → AI, which no longer has that row.
- The start's step 2 no longer offers Sign in with Google, which AllInOneIME Cloud doesn't have yet: Sign in / Sign up with Email is its default button. "Already have your own AI?" is one button, Use My Own AI…, which opens Settings → AI, and once the AI chosen there can answer (a CLI signed in, an API key added, Apple Intelligence, an AWS profile), the start goes on to trying one @ by itself, not only after signing in to AllInOneIME Cloud.

## zh-CN

- 输入菜单「翻译成」→「添加 / 排序语言…」打开设置 →「常用」并指到「翻译成」；以前打开的是设置 →「AI」，那里已经没有这一行了。
- 上手的第 2 步不再列出「用 Google 登录」（AllInOneIME 云还不支持），默认按钮是「用邮箱登录 / 注册」。「已经有自己的 AI？」下面只有一个按钮「使用我自己的 AI…」，打开设置 →「AI」；在那里选的 AI 能用以后（CLI 已登录、填了 API Key、Apple 智能、AWS profile），上手自己进入试一次 @ 的那一步，不再只认登录 AllInOneIME 云。
