macOS 輸入法

在哪裡打字，
就在哪裡和 AI 對話。

在 Mac 的任何 App 裡打 @，後面寫你想做的事：一個問題、要潤飾或翻譯的句子、一個算式、要開啟的 App。最可能要做的排在第一行，按 Enter 就行。

免費 · 支援注音、繁體 · macOS 14 以上 · Apple 晶片和 Intel 都能用 · 經過 Apple 公證

打 @，後面隨便寫。

不用記命令名：每一行都寫著 Enter 會做什麼。選中一行之前，什麼都不發給 AI，什麼也不會執行。

@命令

打命令名的開頭就能找到它：@tr 就是 @translate。單打一個 @ 列出所有命令，常用的在前。

=算式

@3*7+2 邊打邊顯示 23，Enter 就填進去。

↗App 和網址

@xtsz 就是「系統設定」：App 的中文名，用拼音首字母也能找到。資料夾和網址也一樣，Enter 開啟。

◷提醒

@明天下午3點開會，Enter 就加到「提醒事項」裡，時間是明天 15:00。

@improve

寫在哪裡，就在哪裡改得更好。

打 @ 再寫一句話，第一行就是「改寫」。Enter 先給三種潤飾後的說法，再按你選的風格改寫：簡潔、正式、口語、委婉，還有大廠黑話。都用你寫的那種語言。

按數字選一個，或者直接 Enter 選第一個；0 保留原文。

@translate · @question

翻譯成你要的語言，有問題直接問。

@translate 按你排的順序，每種語言出一行：英文、日語、法語、德語、西班牙語等等。寫的是別的語言，第一行就是翻譯。

寫的是問題，第一行就是「問 AI」，答案直接顯示在原地：可以送出，也可以 ⌘C 複製。

能接著問，說一句就設定好。

答案出來可以接著問。改設定說一句就行，整套設定也能一鍵查一遍。

⇄接著問

答案出來後，接著打下一個問題再按 ⇧Enter：候選框變成一段對話，預設最多 5 輪。

↗換個地方接著聊

按 ⌘Enter，把對話照你看到的樣子帶到你的程式設計 agent（Claude Code…）、Claude 或 ChatGPT 裡接著聊。

✦一句話改設定

在設定的搜尋框裡寫「候選豎排」「用 Claude」：每項改動先列出原來 → 改成再應用，還能撤銷。不碰你的金鑰。

✚排查問題

設定 →「關於」→「排查問題」檢查輸入法、AI 服務、權限和語言包，能修的給你一個按鈕。也可以問它哪裡不對。

能接著改，能保護隱私，能按你的習慣來。

結果不太對？說一句怎麼改。有不想給 AI 看的內容？可以不發給它。

↻修改結果

結果出來後打「更短」「更正式」再按 ⇧Enter，新結果就地替換，想改幾次都行。

▭選中的文字

在任何 App 裡選中一段文字再打 @：翻譯、改寫，在聊天 App 裡還能回覆，或者就這段文字提問。選好的版本替換選中的文字。

▦按 App 設定

每個 App 會記住你在那裡先用哪種輸入。也可以讓某些 App 裡乾脆不用 AI。

●隱藏敏感資訊

開啟後，郵箱、電話、卡號、金鑰和你自己加的詞，發給 AI 前先換成佔位符，結果裡再換回來。

◎Apple Intelligence

Mac 支援 Apple Intelligence（macOS 26）時，可以用 macOS 自帶的模型：不用 key，不花錢，不離開這臺 Mac。

↓應用內更新

有新版本時會發通知，點「更新」一下就裝好；裝之前先和簽名的更新資訊核對。

不只是寫字，整臺 Mac 都能用。

在任何輸入框裡，@ 後面打命令名就行。

✦@agent

把任務交給你的程式設計 agent（Claude Code、Gemini CLI、Kiro CLI…）；Claude Code 可以在後臺做，做完通知你。

✎@note

把文字存進「備忘錄」，換行都保留。

›_@py · @js

執行一行 Python 或 JavaScript，把結果送出。

✉@imessage

不離開當前 App 就能發 iMessage。

⌃V剪貼簿歷史

按 ⌃V 列出複製過的文字和圖片；指著圖片那一行就能看大圖。

＋自己加

自己的 AI 指令、程式、網頁連結，還有簽過名的外掛庫裡的 @stock、@calculator 等外掛。

腳本擴充功能

用腳本寫你自己的 @ 命令。

任何語言的腳本，加幾行中繼資料，就是一個 @ 命令：可以送出輸出、顯示進度、邊打字邊給出 Alfred 那樣的列表來選，或者在後臺執行，完成後通知你。

也可以從 Git 倉庫安裝擴充功能包：啟用前先看它會執行什麼，之後點「更新」時從那裡更新。

Raycast 腳本命令拿來就能用。寫法見 擴充功能協議。

選單欄

筆記、提醒、Claude 任務，點一下就在。

點選單欄的 ∞，下拉出用 @note 存的筆記、加的提醒，和 Claude Code 正在做的任務。往左滑一行就能移除。

選中之前什麼都不發

@ 後面打的字，在你選中 AI 那一行之前都留在本機；開啟「續寫」的話，停頓時會發出去。安全輸入時（比如密碼框）沒有 AI 那幾行。

金鑰在鑰匙串裡

API 金鑰存在 macOS 鑰匙串裡，每個只發給儲存時的那個服務。

能在本機的都在本機

@ 後面那幾行都在本機算出來；算式、App、資料夾和 @reminder 都不離開你的 Mac。

敏感內容先隱藏

也可以完全不上雲

macOS 26 上選 Apple Intelligence，由 Mac 自帶的模型回答。你指定的 App 裡，乾脆不用 AI。
