macOS 输入法

任何输入框里，
都能用 AI 命令。

在 Mac 的任何 App 里，开头打 @improve、@translate 或 @question，按回车，选一个结果。不用复制到聊天窗口，也不用切换 App。

下载 macOS 版 在 GitHub 上看

免费 · macOS 14 及以上 · Apple 芯片和 Intel 都能用 · 经过 Apple 公证

@improve

写在哪里，就在哪里改得更好。

先给三种润色后的说法，再按你选的风格改写：简洁、正式、口语、委婉，还有大厂黑话。都用你写的那种语言。

按数字选一个，或者直接回车选第一个；0 保留原文。

@translate · @question

翻译成你要的语言，有问题直接问。

@translate 按你排的顺序，每种语言出一行：英文、日语、法语、德语、西班牙语等等。

@question 直接给答案，可以上屏，也可以 ⌘C 复制。单打一个 @ 就是命令列表。

能接着问，说一句就设置好。

答案出来可以接着问。改设置说一句就行，整套设置也能一句话查一遍。

⇄接着问

@question 的答案出来后，接着打下一个问题再按 ⇧回车：候选框变成一段对话，最多 5 轮。

↗换个地方接着聊

按 ⌘1、⌘2… 把对话照你看到的样子带到你的编程 agent（Claude Code…）、Claude、ChatGPT 或 Gemini，连同你接着打的话。

✦一句话改设置

设置打开就是「助手」：写「候选竖排」「用 Claude」，每项改动先列出原来 → 改成再应用，还能撤销。不碰你的密钥。

✚检查问题

设置 → 助手检查输入法、AI 服务、权限和语言包，能修的点「修复」就行。也可以问它哪里不对。

能接着改，能保护隐私，能按你的习惯来。

结果不太对？说一句怎么改。有不想给 AI 看的内容？可以不发给它。

↻修改结果

结果出来后打「更短」「更正式」再按 ⇧回车，新结果就地替换，想改几次都行。

▭选中的文字

在任何 App 里选中一段文字，再打 @improve 或 @translate：选好的结果替换选中的文字。

?最近的问题

单打 @question 列出最近 5 个问题，当时的答案马上就能看，不联网。

▦按 App 设置

Slack 里用英文，微信里用拼音，邮件里正式、委婉，或者某个 App 里干脆不用 AI。

●隐藏敏感信息

打开后，邮箱、电话、卡号、密钥和你自己加的词，发给 AI 前先换成占位符，结果里再换回来。

◎Apple Intelligence

Mac 支持 Apple Intelligence（macOS 26）时，可以用 macOS 自带的模型：不用 key，不花钱，不离开这台 Mac。

↓应用内更新

设置 →「关于」发现新版本，点一下就装好，装之前先和签名的更新信息核对。

!@reportissue

打开 GitHub 的新问题页，带上你写的标题、App 的版本和设置；不带你别的文字、路径和密钥。

不只是写字，整台 Mac 都能用。

每个命令都以 @ 开头，在任何输入框里都能用。

✦@agent

把任务交给你的编程 agent（Claude Code、Gemini CLI、Kiro CLI…）；Claude Code 可以在后台做，做完通知你。

⌕@open

边打边找文件、文件夹和 App，也能打开网址。

✎@note

把文字存进「备忘录」，换行都保留。

◷@reminder

加一个提醒，时间直接写在里面：「明天下午3点给张三打电话」。

›_@py · @js

运行一行 Python 或 JavaScript，把结果上屏。

✉@imessage

不离开当前 App 就能发 iMessage。

＋自己加

自己的 AI 指令、程序、网页链接，还有签过名的插件库里的 @stock、@calculator 等插件。

脚本扩展

用脚本写你自己的 @ 命令。

任何语言的脚本，加几行元数据，就是一个 @ 命令：可以上屏输出、显示进度、边打字边给出 Alfred 那样的列表来选，或者在后台运行，完成后通知你。

也可以从 Git 仓库安装扩展包：启用前先看它会运行什么，之后点「更新」时从那里更新。

Raycast 脚本命令拿来就能用。写法见 扩展协议。

菜单栏

笔记、提醒、Claude 任务，点一下就在。

点菜单栏的 ∞，下拉出用 @note 存的笔记、加的提醒，和 Claude Code 正在做的任务。往左滑一行就能移除。

和 macOS 一样的玻璃效果，跟着系统设置走。

语音

按住右 ⌥ 说话。

边说边出字，在你的 Mac 上识别，音频不上传。先打命令（比如 @improve）再说，说完回车就执行。

你的 AI，你的密钥，你的 Mac。

只连你选的 AI 服务，用你自己的密钥，而且只在你对命令按回车的时候。

打字时什么都不发

只有执行命令时才发出去。密码框和其他安全输入时，从不发送。

密钥在钥匙串里

API 密钥存在 macOS 钥匙串里，每个只发给保存时的那个服务。

能在本机的都在本机

语音、@open、@note 和 @reminder 都不离开你的 Mac。

敏感内容先隐藏

可以打开：邮箱、号码、密钥和你列出的词，请求发出前先在本机换成占位符。

也可以完全不上云

macOS 26 上用 Apple Intelligence，由 Mac 自带的模型回答。你指定的 App 里，干脆不用 AI。

签名并经过公证

用 Developer ID 签名，经过 Apple 公证。更新装之前先和签名的更新信息核对。

输入语言

英文、中文、法语、韩语、印地语。

中文用拼音（基于 Rime 和雾凇拼音，分不清的音可以开模糊音），法语用它自己的键盘布局，韩语打谚文，印地语用拉丁字母拼出天城文。单按 Shift 切到下一种。

中文、韩语和印地语是语言包，添加时下载。
