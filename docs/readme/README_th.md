# AllInOneIME

### คำสั่ง AI ในทุกช่องข้อความบน Mac ของคุณ

> [!NOTE]
> AllInOneIME ยังไม่ได้รับการรับรอง (notarize) จาก Apple: ในครั้งแรก ให้อนุญาตที่ System Settings → Privacy & Security → Open Anyway (การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย → เปิดต่อไป) ดาวน์โหลดจาก [GitHub Releases](https://github.com/MicroZ-LLC/AllInOneIME/releases) หรือ [allinoneime.com](https://allinoneime.com) เท่านั้น

วิธีป้อนข้อมูล (input method) สำหรับ macOS ที่มีคำสั่ง AI ในทุกช่องข้อความ ขึ้นต้นประโยคด้วย `@` แล้วกด ⏎ เมื่อพิมพ์เสร็จ: `@improve` ขัดเกลาสิ่งที่คุณเขียนและเสนอแบบเขียนใหม่อีกหลายแบบ `@translate` แปลเป็นภาษาที่คุณเลือก `@question` ถามคำถาม `@claude` ส่งงานให้ Claude Code และ `@open` ค้นหาไฟล์และแอป หรือเปิดที่อยู่เว็บ คุณยังกด ⌥ ขวาค้างไว้แล้วพูดได้ด้วย หากไม่มี `@` ปุ่มที่คุณกดจะส่งไปยังแอปตามปกติ นอกจากนี้ยังพิมพ์ภาษาจีน (พินอิน สร้างบน Rime และ rime-ice) ภาษาฝรั่งเศส ภาษาเกาหลี (ฮันกึล) และภาษาฮินดี (อักษรเทวนาครีจากอักษรละติน) ได้ และรันสคริปต์ของคุณเองเป็นคำสั่ง @ ได้

## วิธีใช้

หากไม่มี `@` ก็จะไม่เข้ามายุ่ง: ในโหมดภาษาอังกฤษ ตัวอักษรจะถูกพิมพ์โดยตรงและ ⏎ คือปุ่ม Return ไม่มีอะไรถูกส่งออนไลน์ การติดตั้งใหม่จะพิมพ์ภาษาอังกฤษ หากต้องการพิมพ์ภาษาจีน (พินอิน) ภาษาฝรั่งเศส ภาษาเกาหลี หรือภาษาฮินดีด้วย ให้เพิ่มภาษานั้นในการตั้งค่า (ดู [การป้อนข้อความและการแปล](#การป้อนข้อความและการแปล))

| ปุ่ม | หน้าที่ |
|---|---|
| พิมพ์พินอิน, Space / ตัวเลข | ในโหมดภาษาจีน: เลือกคำ เหมือนวิธีป้อนข้อมูลพินอินทั่วไป |
| `@` (ที่ต้นประโยค) | เปิดรายการคำสั่ง: คำสั่งที่ใช้บ่อยช่วงหลังมาก่อน ครั้งละ 5 รายการ เลื่อนด้วย ↑↓ ล้อเมาส์ หรือแทร็กแพด หรือพิมพ์ตัวอักษรเพื่อค้นหา (ชื่อที่ขึ้นต้นด้วยตัวอักษรนั้นมาก่อน ตามด้วยชื่อที่มีตัวอักษรนั้นอยู่) เลือกด้วย ⏎, Tab, Space หรือตัวเลข |
| ⏎ | รันคำสั่ง ใช้ได้แม้ยังไม่ได้เลือกพินอิน: พินอินจะถูกเลือกก่อน เหมือนกด Space |
| Space, ⏎ / ตัวเลข | เมื่อผลลัพธ์ขึ้นมาแล้ว: แทรกรายการที่ไฮไลต์อยู่ / รายการที่มีหมายเลขนั้น 0 คือข้อความต้นฉบับ |
| ⌘C | คัดลอกผลลัพธ์ที่ไฮไลต์อยู่ (สำหรับ `@open` คือพาธ) แผงตัวเลือกยังคงเปิดอยู่ |
| ⌃V | ในคำสั่ง (เช่น หลัง `@improve `): ต่อข้อความจากคลิปบอร์ดไว้หลังสิ่งที่คุณพิมพ์ แทนที่จะวางลงในแอป หลายบรรทัดจะถูกรวมเป็นบรรทัดเดียว ครั้งละไม่เกิน 2000 อักขระ (`@note` คงการขึ้นบรรทัดใหม่ไว้และรับได้ถึง 20000) ใช้ได้ในทุกแอป หากไม่มีคำสั่ง ปุ่มจะส่งไปยังแอปตามปกติ |
| ⌘V | เหมือน ⌃V แต่บางแอปจัดการ ⌘V เอง (เทอร์มินัลอย่าง Ghostty, iTerm2 และ Terminal รวมถึง Notes) และวางลงในแอปตามปกติ ในแอปเหล่านั้นให้ใช้ ⌃V |
| Esc, ⌫ | กลับไปที่ประโยคเพื่อแก้ไขต่อ พิมพ์ต่อได้เลย |
| แตะ Shift | เมื่อมีภาษาป้อนข้อมูลมากกว่าหนึ่งภาษา: สลับไปภาษาถัดไปตามลำดับ (อังกฤษ → จีน → ฝรั่งเศส → … แล้ววนกลับไปภาษาแรก) |
| กด ⌥ ขวาค้างไว้ | พูด ปล่อยเพื่อหยุด ใช้ภาษาที่คุณกำลังพิมพ์อยู่ (อังกฤษ จีน ฝรั่งเศส เกาหลี หรือฮินดี) ในคำสั่ง ข้อความจะต่อท้ายคำสั่ง ไม่เช่นนั้นจะถูกแทรกโดยตรง |

## คำสั่ง @ (เบต้า)

| คำสั่ง | หน้าที่ |
|---|---|
| `@improve` | ขัดเกลา: 1–3 คือสามแบบในภาษาเดียวกับประโยค ตั้งแต่ 4 ขึ้นไปคือสไตล์การเขียนใหม่ (เพิ่มและจัดลำดับได้ในการตั้งค่า) 0 คือต้นฉบับ ไม่แปล หากเปิด "@improve also translates" (@improve แปลด้วย) จะทำงานเหมือน `@translate @improve` |
| `@translate` | แปลเป็นภาษาที่คุณเพิ่มไว้ (การตั้งค่า → "Translate" ลากเพื่อจัดลำดับ) ภาษาละหนึ่งบรรทัด หากมีเพียงภาษาเดียวจะได้สามแบบ ภาษาเดียวกับประโยคจะถูกข้าม ใช้ `@translate @improve` ร่วมกันเพื่อแปลและเขียนใหม่ในคำขอเดียว |
| `@question` | ถามคำถาม คำตอบจะปรากฏในตัวเลือก ⏎ หรือ Space เพื่อแทรก ⌘C เพื่อคัดลอก |
| `@claude` | ส่งงานให้ Claude Code: โดยค่าเริ่มต้นจะทำงานเบื้องหลัง และแจ้งเตือนเมื่อเสร็จ (คลิกเพื่อเปิดเซสชันใน Terminal และทำต่อ) หรือดูได้ที่ `@tasks` ใช้ Claude Code ของคุณเอง (คำสั่ง `claude`) พร้อมการลงชื่อเข้าใช้และการตั้งค่าของมันเอง ปิด "@claude runs in the background" (@claude ทำงานเบื้องหลัง) ในการตั้งค่าเพื่อเปิดใน Terminal เหมือนเดิม ครั้งแรกที่เปิด Terminal macOS จะถามว่าอนุญาตให้ AllInOneIME ควบคุม Terminal หรือไม่: คลิก OK |
| `@tasks` | แสดงรายการงาน Claude เบื้องหลัง (กำลังทำ / เสร็จแล้ว / รอคุณอยู่) พร้อมคำตอบล่าสุด ⏎ เปิดงานนั้นใน Terminal ⌘C คัดลอกคำตอบ |
| `@settings` | เปิดหน้าต่างการตั้งค่าทันที (แค่เลือกคำสั่งก็พอ) |
| `@open` | แสดงไฟล์ โฟลเดอร์ และแอปที่ตรงกันขณะพิมพ์ (Spotlight) ใช้หลายคำค้นได้ โดยคั่นด้วยเว้นวรรค: ทุกคำต้องอยู่ในพาธ และอย่างน้อยหนึ่งคำต้องอยู่ในชื่อ (ชื่อของโฟลเดอร์มาตรฐานนับรวมกับสิ่งที่อยู่ข้างใน: `downloads pdf` จะพบไฟล์ PDF ใน Downloads) แอปและโฟลเดอร์มาตรฐานค้นด้วยชื่อภาษาจีนได้ด้วย และอินเทอร์เฟซภาษาจีนจะแสดงด้วยชื่อนั้น สิ่งที่คุณเคยเปิดด้วย `@open` มาก่อน ตามด้วยแอปและโฟลเดอร์ดังกล่าว แล้วจึงเป็นไฟล์ที่ใช้หรือแก้ไขล่าสุด เมื่อค้นตามชื่อพบไฟล์ไม่เกินสองไฟล์ และไม่พบแอปหรือโฟลเดอร์ประเภทนั้น ไฟล์ในโฟลเดอร์โฮมของคุณจะถูกค้นตามเนื้อหาด้วย โดยแถวเหล่านั้นจะมีป้าย "content" (เนื้อหา) เมื่อไม่มีผลอื่น ⏎ จะแสดงรายการให้เลือกแทนการเปิดรายการแรก หากเป็นที่อยู่เว็บ (`github.com`, `localhost:3000`, `https://…`) แถวแรกคือ "open in the browser" (เปิดในเบราว์เซอร์) และจะไม่ค้นหาเนื้อหา ไฟล์ที่มีชื่อตรงกันพอดี (เช่น `MANIFEST.in`) จะมาก่อน ข้อความที่ขึ้นต้นด้วย `~/` หรือ `/` คือพาธ: Tab เติมพาธให้สมบูรณ์และเข้าไปในโฟลเดอร์ ⏎ เปิด ⌘C คัดลอกพาธ |
| `@note` | บันทึกข้อความลงในแอป Notes ในโฟลเดอร์ชื่อ AllInOneIME (สร้างให้หากยังไม่มี) ไม่มีการแทรกข้อความ ข้อความที่วางจะคงการขึ้นบรรทัดใหม่ไว้ ได้ถึง 20000 อักขระ |
| `@reminder` | เพิ่มการเตือนความจำในแอป Reminders ในรายการชื่อ AllInOneIME เขียนเวลาไว้ในข้อความ ระบบจะอ่านเวลาบน Mac และมีแถวแสดงสิ่งที่อ่านได้: ⏎ หรือ Space เพื่อเพิ่ม Esc เพื่อกลับไปแก้ไข หากมีเวลา จะเตือนเมื่อถึงเวลานั้น หากมีแค่วันที่ จะเป็นการเตือนทั้งวัน |
| `@calculate` | คำนวณบน Mac เครื่องนี้ ผลลัพธ์จะปรากฏในตัวเลือก ⏎ หรือ Space เพื่อแทรก: `@calculate 23*17` → `391` ใช้ภายในประโยคได้ด้วย: `@reply the total is @calculate 23*17 dollars` |
| `@py` | รัน Python หนึ่งบรรทัด (`python3` ของ Mac) และแทรกผลลัพธ์: ค่าของนิพจน์สุดท้ายในโค้ด เช่น `@py 2**100`, `@py import math; math.sqrt(2)` หรือถ้าไม่มีก็เป็นสิ่งที่โค้ดพิมพ์ออกมา จะไม่มีให้ใช้หากไม่มี `python3` (เครื่องมือบรรทัดคำสั่งของ Xcode มีให้) |
| `@js` | รัน JavaScript หนึ่งบรรทัดและแทรกผลแบบเดียวกัน: ค่าของนิพจน์สุดท้าย หรือสิ่งที่ `console.log` พิมพ์ออกมา เช่น `@js [1, 2, 3].map(x => x * 2)` ใช้ JavaScriptCore ที่มีมาใน macOS จึงไม่ต้องติดตั้งอะไร และไม่สามารถอ่านไฟล์ เข้าถึงเครือข่าย หรือรันโปรแกรมอื่นได้ |
| `@imessage` | ส่ง iMessage: พิมพ์ชื่อ หมายเลขโทรศัพท์ หรืออีเมล (ชื่อภาษาจีนพิมพ์ด้วยพินอินได้ด้วย ทั้งแบบเต็มหรือตัวย่อ) แล้วเลือกผู้รับในแผงตัวเลือก (คนที่คุณส่งข้อความหาล่าสุดมาก่อน หมายเลขหรือที่อยู่แบบเต็มก็ใช้ได้) จากนั้นเขียนข้อความ (คำสั่งข้างในอย่าง `@stock AAPL` จะถูกรันก่อน) ⏎ จะแสดง "Send to Alex (…): message" ในแผง กด ⏎ อีกครั้งเพื่อส่ง Esc เพื่อกลับไปแก้ไข ไม่มีอะไรถูกพิมพ์ลงในช่องข้อความ ครั้งแรก macOS จะถามว่าอนุญาตให้ AllInOneIME เข้าถึง Contacts และควบคุม Messages หรือไม่: คลิก OK ทั้งสองอย่าง |

ตัวอย่าง: `@q` ⏎ พิมพ์ `what is quantum computing` แล้ว ⏎ ส่วน `@note books to read: The Three-Body Problem` ⏎ จะบันทึกโน้ต `@reminder call Bob tomorrow at 3pm` ⏎ ตรวจดูเวลาที่อ่านได้ แล้วกด ⏎ อีกครั้งเพื่อเพิ่ม เมื่อเลือกคำสั่งแล้ว คุณยังกด ⌥ ขวาค้างไว้แล้วพูดได้ด้วย ในโหมดภาษาจีน `@open` และ `@calculate` จะสลับไปใช้ตัวอักษรภาษาอังกฤษชั่วคราว และกลับเป็นภาษาจีนเมื่อคุณเสร็จ

โค้ดของ `@py` และ `@js` พิมพ์ด้วยตัวอักษรภาษาอังกฤษ และเครื่องหมายวรรคตอนแบบเต็มความกว้าง (จากโหมดภาษาจีน) จะกลายเป็น ASCII ให้เขียนในบรรทัดเดียว โดยใช้ `;` คั่นระหว่างคำสั่ง โค้ดจะรันในโพรเซสแยก และถูกหยุดหลังจาก 10 วินาที หรือกด Esc เมื่อใดก็ได้ หากเกิดข้อผิดพลาด จะแสดงบรรทัดแรกของข้อผิดพลาด เช่น `ZeroDivisionError: division by zero` ผลลัพธ์ที่มีหลายบรรทัดจะถูกแทรกตามที่พิมพ์ออกมา ส่วนในเทอร์มินัลจะเข้าไปเป็นบรรทัดเดียว (เทอร์มินัลจะรันทุกบรรทัดที่ได้รับ) เทอร์มินัลภายในโปรแกรมแก้ไขโค้ด (VS Code, Cursor, JetBrains) ไม่สามารถแยกออกจากตัวโปรแกรมแก้ไขได้ ดังนั้นในที่นั้น ผลลัพธ์หลายบรรทัดของทุกคำสั่งจะเข้าไปตามเดิม ทั้งสองคำสั่งใช้ภายในประโยคของคำสั่งอื่นได้ด้วย: `@reply the answer is @py 2**100` หากโค้ดมีเว้นวรรค ให้ใส่ในเครื่องหมายคำพูด: `@question explain @py "sum(x * x for x in range(10))"` แต่กลับกันไม่ได้: โค้ดของ `@py` และ `@js` จะรันตรงตามที่คุณพิมพ์เสมอ และ `@commands` ที่อยู่ข้างในจะไม่ถูกรันก่อน

เมื่อ `@` ไม่ได้ตามด้วยคำสั่ง เช่น `@john` ตัว `@` จะถูกแทรกตามปกติ การ @-กล่าวถึงผู้อื่นในแอปแชตจึงยังใช้ได้ `@question`, `@improve` และ `@translate` จะส่งไปยัง Bedrock ของคุณเองเฉพาะเมื่อคุณกดปุ่มสั่งงานเท่านั้น `@open` ค้นหาบน Mac เครื่องนี้เท่านั้น `@note` และ `@reminder` ส่งไปยัง Notes และ Reminders บน Mac เครื่องนี้เท่านั้น `@claude` ใช้ Claude Code ที่ติดตั้งบน Mac ของคุณ (คำสั่ง `claude`) และบัญชีของมันเอง และจะถามคุณก่อนตามปกติ ก่อนแก้ไขไฟล์หรือรันคำสั่ง หากไม่ได้ติดตั้ง Claude Code จะไม่มี `@claude` ให้ใช้ `@imessage` อ่าน Contacts บน Mac เครื่องนี้เท่านั้น (ชื่อ หมายเลขโทรศัพท์ อีเมล) ไม่ผ่าน AI เลย และ Messages เป็นผู้ส่งข้อความ หากไม่มีแอป Messages จะไม่มีคำสั่งนี้ให้ใช้

`@calculate` ทำงานบน Mac เครื่องนี้แบบออฟไลน์: `+ - * /` (รวมถึง `× ÷`) `^` หรือ `**` สำหรับยกกำลัง วงเล็บ เปอร์เซ็นต์ (`50%` คือ 0.5 และ `200*5%` คือ 10 เหมือนเครื่องคิดเลข เปอร์เซ็นต์ที่บวกหรือลบจะคิดจากค่าที่อยู่ข้างหน้า: `100+10%` คือ 110 และ `100-10%` คือ 90) ฟังก์ชัน `sqrt abs round floor ceil ln log exp sin cos tan min max pow` (`log` เป็นฐาน 10 มุมเป็นเรเดียน `round(x, 2)` เก็บทศนิยมสองตำแหน่ง) และค่าคงที่ `pi` (`π`) และ `e` ตัวเลขและเครื่องหมายแบบเต็มความกว้างก็ใช้ได้ การคำนวณแม่นยำในระบบทศนิยม ดังนั้น `0.1+0.2` คือ `0.3` ผลลัพธ์มีเลขนัยสำคัญได้สูงสุด 15 หลัก และจำนวนเต็มที่ยาวไม่เกิน 38 หลักจะเขียนออกมาเต็ม (`2^100` → `1267650600228229401496703205376`)

### โน้ตและการเตือนความจำ

`@note` สร้างโน้ตใหม่ โดยบรรทัดแรกเป็นชื่อเรื่อง หลังจากคัดลอกข้อความแล้ว ⌃V หลัง `@note ` (หรือ ⌘V นอกเทอร์มินัล) จะบันทึกข้อความพร้อมการขึ้นบรรทัดใหม่ ซึ่งแสดงเป็น ↵ ในคำสั่ง หากคุณออกจากช่องข้อความ (คลิกที่อื่น สลับแอป) หรือกด ⇧⏎ (แทรกตามที่พิมพ์) ก่อนที่โน้ตที่มีการขึ้นบรรทัดใหม่จะถูกบันทึก โน้ตนั้นจะไม่ถูกพิมพ์ลงในแอป (ในเทอร์มินัล แต่ละบรรทัดจะถูกรันเป็นคำสั่ง) แต่จะถูกใส่ไว้ในคลิปบอร์ดแทน ("The note wasn't saved; its text is on the clipboard" – โน้ตไม่ได้ถูกบันทึก ข้อความอยู่ในคลิปบอร์ด) โน้ตที่มีบรรทัดเดียวจะถูกแทรกตามที่พิมพ์

`@reminder` อ่านเวลาอย่าง `tomorrow at 3pm`, `in 2 hours`, `in 3 days at 3pm`, `on the 15th`, `this weekend`, `in 1 month`, `next month` (วันที่ 1 ของเดือนนั้น), `end of the year` ได้ (รวมถึงเวลาที่เขียนเป็นภาษาจีน) วันและเวลาแยกกันได้ (`tomorrow call Bob at 5`) สัปดาห์เริ่มวันจันทร์ เวลาที่ไม่มี am หรือ pm (`at 5`) หมายถึงเวลานั้นครั้งถัดไป และจะไม่อยู่ระหว่างเที่ยงคืนถึง 6 โมงเช้า เวลาที่ผ่านไปแล้วในวันนี้จะหมายถึงพรุ่งนี้ แต่ช่วงของวันที่ยังไม่จบ (`this afternoon`, `tonight`) หมายถึงวันนี้ แบบทั้งวัน วันที่ที่ผ่านไปแล้วในปีนี้จะหมายถึงปีหน้า หากเขียนให้ทำซ้ำ (`standup every Monday at 9`) จะถูกเพิ่มเพียงครั้งเดียว สำหรับครั้งถัดไป: คำเหล่านั้นยังอยู่ในชื่อเรื่อง และแถวจะแสดงว่า "once only" (ครั้งเดียวเท่านั้น) แถวยืนยันจะแสดงเวลาที่อ่านได้ เช่น "tomorrow 3:00 PM" (ตามการตั้งค่า 12/24 ชั่วโมงของ Mac) หากไม่ถูกต้อง Esc จะกลับไปที่ข้อความ หากไม่มีเวลาหรือวันที่ ก็จะไม่มีเวลากำหนด ("no date" – ไม่มีวันที่)

`@stock` และคำสั่งทำนองเดียวกันภายในสองคำสั่งนี้จะไม่ถูกรัน: ข้อความจะถูกบันทึกตามที่เขียน (การพิมพ์ `@` ในนั้นจะไม่เปิดรายการคำสั่ง) ครั้งแรก macOS จะถามว่าอนุญาตให้ AllInOneIME ควบคุม Notes (`@note`) หรือเข้าถึง Reminders (`@reminder`) หรือไม่: ให้อนุญาต หากคุณไม่ได้อนุญาต ให้อนุญาต AllInOneIME ที่ System Settings → Privacy & Security → Automation (Notes) หรือ → Reminders เมื่อบันทึกไม่สำเร็จ (เช่น ไม่มีสิทธิ์) การแจ้งเตือนจะบอกสาเหตุ และข้อความจะกลับมาอยู่ในคำสั่งเพื่อให้แก้ไขและส่งอีกครั้ง เมื่อคุณต้องแก้ไขบางอย่างก่อน (สิทธิ์ บัญชี) ข้อความจะถูกใส่ไว้ในคลิปบอร์ดด้วย (การไปที่ System Settings จะดึงโฟกัสออกจากช่องข้อความ) หากคุณย้ายไปช่องข้อความอื่นหรือกำลังพิมพ์อย่างอื่นอยู่ ข้อความจะถูกใส่ไว้ในคลิปบอร์ดแทน ("Not saved; the text is on the clipboard." – ไม่ได้บันทึก ข้อความอยู่ในคลิปบอร์ด)

### คำสั่งของคุณเอง

ในการตั้งค่า ที่ "Custom @ Commands" (คำสั่ง @ แบบกำหนดเอง) ให้คลิก "Add Command…" (เพิ่มคำสั่ง): ตั้งชื่อและเลือกสิ่งที่คำสั่งทำ (คำสั่งสำหรับ AI โปรแกรม โปรแกรมใน Terminal หรือหน้าเว็บ) หรือเริ่มจากตัวอย่าง คำสั่งของคุณจะอยู่ถัดจากคำสั่งในตัว ชื่อต้องเป็นตัวอักษรภาษาอังกฤษเท่านั้นและซ้ำกับชื่อคำสั่งในตัวไม่ได้ และใช้ได้ตั้งแต่ประโยคถัดไป คำสั่งเหล่านี้เก็บไว้ใน `customCommands` ในไฟล์การตั้งค่า (`~/.config/allinoneime/config.json`) ซึ่งคุณแก้ไขเองได้ด้วย:

```json
"customCommands": [
  { "name": "python", "type": "run", "argv": ["python3", "-c", "{input}"], "summary": "Run Python" },
  { "name": "bc", "type": "run", "argv": ["bc", "-l"], "stdin": "{input}\n" },
  { "name": "sh", "type": "terminal", "argv": ["zsh", "-c", "{input}"] },
  { "name": "reply", "type": "prompt", "prompt": "Write a short, polite reply to the user's message." },
  { "name": "google", "type": "link", "url": "https://www.google.com/search?q={input}" }
]
```

| `type` | หน้าที่ |
|---|---|
| `prompt` | ส่งไปยัง AI โดยใช้ `prompt` เป็นคำสั่ง คำตอบจะปรากฏในตัวเลือก เพื่อแทรกหรือคัดลอก (⌘C) |
| `run` | รัน `argv` เบื้องหลัง สิ่งที่โปรแกรมพิมพ์ออกมาจะปรากฏในตัวเลือก (หลายบรรทัดจะถูกแทรกตามที่พิมพ์ ในเทอร์มินัลจะเป็นบรรทัดเดียว) หากเกิดข้อผิดพลาด จะแสดงบรรทัดสุดท้ายของผลลัพธ์ |
| `terminal` | รัน `argv` ในหน้าต่าง Terminal ใหม่ ไม่มีการแทรกข้อความ |
| `link` | ใส่ข้อความลงในที่อยู่เว็บ `url` และเปิดในเบราว์เซอร์เริ่มต้น ไม่มีการแทรกข้อความ |

- `{input}` จะถูกแทนด้วยสิ่งที่คุณเขียนหลังคำสั่ง และจะอยู่ภายในอาร์กิวเมนต์เดียวที่มันอยู่เสมอ: ไม่มีเชลล์เข้ามาเกี่ยวข้อง หากต้องการเชลล์ ให้ระบุไว้ เหมือน `sh` ด้านบน (`zsh -c`)
- `stdin`: สิ่งที่ส่งไปยังอินพุตมาตรฐานของโปรแกรม โดย `{input}` ก็ถูกแทนที่ด้วย
- `url` ของ `link` ต้องเป็น `https://` มี `{input}` หนึ่งครั้ง หลัง `?` หรือ `#` ข้อความจะถูกเข้ารหัส (เว้นวรรคเป็น `%20` ขึ้นบรรทัดใหม่เป็น `%0A`) ไม่เกิน 4000 อักขระ
- `run` และ `terminal` พิมพ์ตัวอักษรภาษาอังกฤษโดยค่าเริ่มต้น (เหมือน `@open` ในโหมดภาษาจีน ภาษาจีนจะกลับมาหลังจากนั้น) และเครื่องหมายวรรคตอนแบบเต็มความกว้างจะกลายเป็น ASCII ตั้ง `"ascii": false` เพื่อคงข้อความตามที่พิมพ์
- โปรแกรมจะรันในโฟลเดอร์โฮมของคุณ โดยใช้ PATH ของ login shell ของคุณ (จึงพบโปรแกรมที่ติดตั้งผ่าน Homebrew, pyenv และ nvm) `run` จะหยุดโปรแกรมหลังจาก 10 วินาที (`timeoutSeconds`) หรือเมื่อพิมพ์ผลลัพธ์ออกมามากเกินไป Esc หยุดได้ทุกเมื่อ
- `summary` คือคำอธิบายในรายการคำสั่ง (ไม่บังคับ)
- หากไม่พบโปรแกรมใน `argv` (เช่น ไม่มี `python3`) จะไม่มีคำสั่งนั้นให้ใช้ และ `@python …` จะถูกแทรกเป็นข้อความ เมื่อติดตั้งโปรแกรมแล้ว คำสั่งจะปรากฏในช่องข้อความถัดไป

`run` และ `terminal` รันโค้ดบน Mac ของคุณ: เพิ่มเฉพาะคำสั่งที่คุณเขียนเองและไว้ใจเท่านั้น คำสั่งเหล่านี้ก็รันเฉพาะเมื่อคุณกดปุ่มสั่งงาน และไม่รันระหว่างการป้อนข้อมูลแบบปลอดภัย (secure input)

### ส่วนขยายแบบสคริปต์

เพิ่มคำสั่ง @ ของคุณเองในรูปแบบโปรแกรม: สคริปต์ภาษาใดก็ได้ (bash, Python, Node, Swift, …) ที่มีข้อมูลเมตาไม่กี่บรรทัดในคอมเมนต์ วางไว้ใน `~/.config/allinoneime/extensions` หรือในโฟลเดอร์ที่คุณเพิ่มไว้ใน "Settings → Custom Commands → Script Extensions" Raycast Script Commands ใช้ได้ทันทีโดยไม่ต้องแก้ไข และโฟลเดอร์ที่มีสคริปต์เหล่านั้นอยู่แล้วจะถูกพบผ่าน Spotlight

```bash
#!/bin/bash
# @allinoneime.schemaVersion 1
# @allinoneime.title Flights
# @allinoneime.argument1 {"type": "text", "placeholder": "from city"}
# @allinoneime.argument2 {"type": "text", "placeholder": "to city"}

echo "Flights from $1 to $2"
```

`flights.sh` คือ `@flights` เขียนอาร์กิวเมนต์ต่อท้าย คั่นด้วยจุลภาค: `@flights beijing, new york` จะรันโดยมี `beijing` และ `new york` เป็น `$1` และ `$2` (จุลภาคที่เกินมาจะอยู่ในอาร์กิวเมนต์ตัวสุดท้าย) หากอาร์กิวเมนต์ที่จำเป็นว่างอยู่ จะแจ้งว่าขาดอะไรแทนที่จะรัน สิ่งที่สคริปต์พิมพ์ออกมาจะถูกใช้ตามค่า `output` ของมัน:

| `output` | สิ่งที่เกิดขึ้น |
|---|---|
| `insert` (ค่าเริ่มต้น) | ทั้งหมด และแต่ละบรรทัด สำหรับแทรก |
| `show` | แสดงในแผงขณะที่พิมพ์ออกมา (ความคืบหน้า) ไม่มีการแทรกข้อความ ออกจากช่องข้อความแล้วจะทำงานต่อเบื้องหลัง (พร้อมกันได้สูงสุดสี่รายการ) |
| `list` | รายการในรูปแบบ Script Filter JSON ของ Alfred ซึ่งรันใหม่ขณะคุณพิมพ์ การเลือกแถวจะแทรก เปิด (ที่อยู่เว็บ ไฟล์ หรือโฟลเดอร์ ไม่ใช่สิ่งที่รันได้) คัดลอก หรือรันขั้นตอนที่สอง |
| `silent` | แสดงบรรทัดสุดท้ายใกล้เคอร์เซอร์ ไม่มีการแทรกข้อความ |

คำสั่งยังสามารถไม่รับอินพุต (`input none`: กด ⏎ ที่ชื่อเพื่อรัน) รันแบบ `background` และแจ้งเตือนเมื่อเสร็จ (ระหว่างนั้นแผงในแถบเมนูจะแสดงรายการไว้) แสดง `status` ข้างชื่อในรายการคำสั่ง หรือถามก่อน (`confirm`) ได้ คำสั่งจะรันในโฟลเดอร์ของตัวเอง โดยใช้ PATH ของ login shell ของคุณและตัวแปร `ALLINONEIME_*`: ภาษาของอินเทอร์เฟซและภาษาที่ป้อน แอปที่คุณกำลังพิมพ์ และข้อความ **bundle** คือโฟลเดอร์ที่มี `extension.json` ระบุคำสั่งต่าง ๆ ของมัน: คำสั่งเหล่านั้นใช้โค้ดและค่ากำหนดร่วมกัน ซึ่ง Settings จะแสดงไว้ (รหัสผ่านเก็บใน keychain) Settings แสดงรายการทุกคำสั่งพร้อมสวิตช์ และสคริปต์ที่ไม่ได้รวมไว้พร้อมเหตุผล

โหมดของ Raycast จับคู่ดังนี้: `fullOutput` → `show`, `compact` และ `silent` → `silent`, `inline` ที่มี `refreshTime` → status โปรโตคอลทั้งหมดอยู่ใน [docs/extensions.md](../extensions.md) และ [Examples/extensions](../../Examples/extensions) มีตัวอย่างของแต่ละประเภท ส่วนขยายรันโค้ดบน Mac ของคุณ: ใช้เฉพาะที่คุณไว้ใจ ส่วนขยายจะรันเฉพาะเมื่อคุณรันมัน (status หรือ list จะรันขณะคุณพิมพ์) ไม่รันระหว่างการป้อนข้อมูลแบบปลอดภัย และจะหยุดเมื่อวิธีป้อนข้อมูลปิดลง

### ปลั๊กอิน

ปลั๊กอินคือคำสั่ง `@` สำเร็จรูปสำหรับสิ่งที่ไม่ใช่ทุกคนต้องใช้ เช่น `@stock AAPL 600519 700` สำหรับราคาหุ้น เมื่อติดตั้งแล้วจะทำงานเหมือนคำสั่งอื่น ๆ "Plugins" ในการตั้งค่าจะแสดงสิ่งที่ติดตั้งไว้ และแต่ละตัวส่งข้อความของคุณไปที่ใด และใช้ถอดปลั๊กอินออกได้ ปลั๊กอินคือ JavaScript ที่รันในโพรเซสแยก: เข้าถึงได้เฉพาะเว็บไซต์ที่ประกาศไว้ (HTTPS) และไม่สามารถอ่านไฟล์หรือรันโปรแกรมอื่นได้ "Browse Library…" (เรียกดูคลัง) ใต้ Plugins ในการตั้งค่าจะติดตั้งปลั๊กอินจาก [คลังปลั๊กอิน](https://github.com/MicroZ-LLC/AllInOneIME-plugins): ก่อนติดตั้งจะแสดงว่าปลั๊กอินติดต่อเว็บไซต์ใดบ้าง ดัชนีของคลังมีการลงนาม และทุกไฟล์ต้องตรงกับดัชนี เมื่อมีเวอร์ชันใหม่กว่าจะมีปุ่ม "Update" ไม่มีอะไรอัปเดตเอง ปลั๊กอินของคุณเองวางไว้ใน `~/.config/allinoneime/plugins/` ("Open Plugins Folder"): เป็นปลั๊กอินในเครื่อง ซึ่งคลังจะไม่เขียนทับ ปลั๊กอินแบบ "Link" ไม่รันโค้ด: ใส่ข้อความลงในที่อยู่เว็บแล้วเปิดในเบราว์เซอร์ เช่น `@x nice weather today` ซึ่งเปิดหน้าเขียนโพสต์ของ X โดยกรอกข้อความไว้ให้แล้ว ส่วนจะโพสต์หรือไม่ก็ขึ้นอยู่กับคุณบนหน้านั้น คลังมีปลั๊กอินแบบนี้สี่ตัว (`@x`, `@threads`, `@bsky`, `@weibo`) `@xe` แปลงสกุลเงิน: `@xe 100 USD CNY`, `@xe 1000 JPY EUR` ได้หนึ่งบรรทัดพร้อมวันที่ของอัตราแลกเปลี่ยน (อัตราจาก ExchangeRate-API) วิธีเขียนปลั๊กอิน: [docs/plugins.md](../plugins.md)

คำสั่งที่ดึงข้อมูล (ปลั๊กอินและโปรแกรม) ใช้ภายในประโยคได้ด้วย: `@reply tell her @stock AAPL is up today` คำสั่งข้างในจะรันก่อน ผลลัพธ์จะเข้าไปแทนที่ตำแหน่งของมัน แล้วคำสั่งข้างนอกจึงทำงานกับผลนั้น อาร์กิวเมนต์คือคำที่ตามหลังคำสั่ง บวกกับรหัสตัวพิมพ์ใหญ่หรือตัวเลขที่ตามมาทันที (`@stock AAPL TSLA`, `@stock 600519 700`) คำที่เป็นตัวพิมพ์เล็กจะเป็นจุดสิ้นสุด (`@stock SNDK is good to buy` จะค้นหา SNDK) เครื่องหมายคำพูดใช้ระบุอาร์กิวเมนต์อย่างแน่ชัด: `@stock "aapl tsla"` `@calculate` ก็ใช้ภายในประโยคได้ อาร์กิวเมนต์ของมันคือนิพจน์ทั้งหมดที่ตามหลัง รวมเว้นวรรค จนถึงข้อความอื่น: `@reply the total is @calculate 23 * 17 dollars` ภายใน `@claude` และคำสั่งเทอร์มินัล คำสั่งเหล่านี้จะไม่ถูกรัน: คำสั่งเหล่านั้นจะได้รับข้อความตามที่เขียน (การพิมพ์ `@` ในนั้นจะไม่เปิดรายการคำสั่ง)

### ปุ่มสั่งงาน

ค่าเริ่มต้นคือ ⏎ เปลี่ยนได้ที่ "Action key" (ปุ่มสั่งงาน) ในการตั้งค่า (`actionKey` ในไฟล์การตั้งค่า): ⏎, "Tap ⌥" (แตะ ⌥ ข้างใดก็ได้: กดแล้วปล่อยทันที การกด ⌥ ขวาค้างไว้ยังคงใช้สำหรับพูด) ⌥Space หรือ Space (กด Space อีกครั้งหลังจากเลือกคำแล้ว สองครั้งในโหมดภาษาอังกฤษ) ไม่ว่าปุ่มสั่งงานจะเป็นปุ่มใด คำสั่ง @ ก็รันด้วย ⏎ ได้เช่นกัน หาก ⌥Space เป็นปุ่มลัดของ Alfred, Raycast หรือแอปทำนองเดียวกันอยู่แล้ว แอปเหล่านั้นจะได้รับปุ่มก่อน

## แผงในแถบเมนู

<img src="../en/panel-swipe.png" width="520" alt="แผงในแถบเมนู: พื้นหลังกระจกฝ้า มีโน้ต การเตือนความจำ และงาน Claude อยู่บนการ์ด แถวที่ถูกปัดไปทางซ้ายแสดงปุ่ม Remove">

คลิกไอคอนของ AllInOneIME ในแถบเมนู (เครื่องหมาย ∞ กับเคอร์เซอร์ แบบไม่มีกรอบ ส่วนแบบมีกรอบคือแหล่งป้อนข้อมูล) แล้วแผงจะเลื่อนลงมาใต้ไอคอน คลิกที่อื่นเพื่อปิด:

- Notes: โน้ตที่บันทึกด้วย `@note` 5 รายการล่าสุด คลิกเพื่อเปิดใน Notes
- Reminders: การเตือนความจำที่ยังไม่เสร็จในรายการ AllInOneIME ของ Reminders (`@reminder` เพิ่มลงในรายการนั้น) รายการที่ถึงกำหนดเร็วที่สุดมาก่อน แสดง 8 รายการ คลิกวงกลมเพื่อทำเครื่องหมายว่าเสร็จ หรือคลิกชื่อเรื่องเพื่อเปิด Reminders
- Claude Tasks: เหมือน `@tasks` คืองาน Claude เบื้องหลัง (สิ่งที่ `@claude` ส่งต่อไป) ได้ถึง 30 รายการ แสดงครั้งละ 5: เลื่อนเพื่อดูเพิ่ม หรือค้นหาชื่อเรื่องและคำตอบในช่องค้นหา พร้อมความคืบหน้าและบรรทัดแรกของคำตอบล่าสุด คลิกเพื่อเปิดใน Terminal และทำต่อ

ปัดแถว (โน้ต การเตือนความจำ หรืองาน) ไปทางซ้ายด้วยสองนิ้วเพื่อแสดงปุ่ม "Remove" (เอาออก) หรือปัดจนสุดเพื่อเอาออกทันที หากใช้เมาส์ ให้คลิกขวาที่แถว การเอาออกเป็นเพียงการนำออกจากแผง: โน้ตยังอยู่ใน Notes การเตือนความจำยังอยู่ใน Reminders (ยังไม่เสร็จ) งานยังอยู่ใน Claude Code

ส่วนหัวแสดงจำนวน (เช่น "2 reminders · 1 task running" งานที่รอคุณอยู่จะนับแยก เช่น "1 waiting for you") และปุ่มรีเฟรช แผงจะไม่ดึงโฟกัสออกจากแอปที่คุณกำลังพิมพ์: การทำเครื่องหมายการเตือนความจำว่าเสร็จหรือการรีเฟรชจะคงแอปนั้นไว้ด้านหน้า มีเพียงช่องค้นหาของงาน Claude เท่านั้นที่รับแป้นพิมพ์เมื่อถูกคลิก ไอคอนแสดงอยู่โดยค่าเริ่มต้น ปิดได้ที่ "Menu Bar Panel" ในการตั้งค่า

แผงอ่านอะไร และเมื่อใด:

- Notes: รายการเป็นบันทึกของแผงเอง (เก็บไว้แม้แผงจะปิดอยู่) และจะไม่เปิดแอป Notes ขึ้นมาเลย: แผงจะตรวจดู Notes เพื่อหาชื่อเรื่องที่แก้ไขและโน้ตที่ถูกลบ ก็ต่อเมื่อ Notes เปิดอยู่แล้ว และ AllInOneIME เคยได้รับอนุญาตให้ควบคุม Notes มาก่อนเท่านั้น
- Reminders: รายการ AllInOneIME จะถูกอ่านเมื่อแผงเลื่อนลงมา ทุก 60 วินาที และเมื่อการเตือนความจำเปลี่ยนแปลง แผงจะไม่ทำให้ macOS ขอสิทธิ์เข้าถึงด้วยตัวเอง: หาก macOS ยังไม่เคยถามคุณ แผงจะแสดง "Allow Access to Reminders" และมีเพียงปุ่มนั้นที่จะขอสิทธิ์ หากคุณปฏิเสธไปแล้ว แผงจะแสดง "Open System Settings"
- งาน Claude: แผงรัน `claude agents` เฉพาะขณะที่เปิดอยู่เท่านั้น: หนึ่งครั้งเมื่อเลื่อนลงมา เมื่อกด Refresh และเมื่อ `@claude` ส่งต่องาน และทุก 15 วินาทีขณะที่ยังมีงานไม่เสร็จ แต่จะหยุดเมื่องานทั้งหมดเสร็จแล้ว คำตอบล่าสุดอ่านจากส่วนท้ายของบันทึกการสนทนา (transcript) ของ Claude Code บน Mac เครื่องนี้ (`~/.claude/projects`) และเฉพาะเมื่อบันทึกนั้นมีการเปลี่ยนแปลง
- ขณะที่แผงปิดอยู่ จะไม่มีสิ่งใดในนี้ทำงาน แผงจะเก็บเพียงบันทึกของโน้ตที่ `@note` บันทึกไว้

## การป้อนข้อความและการแปล

ในการตั้งค่า:

- **Input languages** (ภาษาที่ป้อน): หนึ่งถึงห้าภาษาจากภาษาอังกฤษ ภาษาจีน (พินอิน) ภาษาฝรั่งเศส ภาษาเกาหลี และภาษาฮินดี เพิ่มด้วยปุ่ม + (แสดงอยู่เสมอ และจะเป็นสีเทาเมื่อครบห้าภาษา) การติดตั้งใหม่เริ่มด้วยภาษาอังกฤษเพียงภาษาเดียว ช่องข้อความใหม่เริ่มด้วยภาษาแรก แตะ Shift เพื่อไปภาษาถัดไปตามลำดับ หากมีภาษาเดียว Shift จะไม่สลับ
  - **ภาษาฝรั่งเศส** พิมพ์ด้วยรูปแบบแป้นพิมพ์ของตัวเอง: AZERTY เว้นแต่คุณจะเลือกแบบอื่นบนการ์ดของภาษานี้ ปุ่ม dead key (^, ¨, `, ´, ~) ก็ประกอบอักขระจากรูปแบบนั้นด้วย
  - **ภาษาเกาหลี** พิมพ์ฮันกึลด้วยรูปแบบ 2-set (Dubeolsik) แต่ละพยางค์ประกอบขึ้นขณะคุณพิมพ์ (g k s → 한) Shift ให้ ㄲ ㄸ ㅃ ㅆ ㅉ และ ㅒ ㅖ
  - **ภาษาฮินดี**: พิมพ์คำตามเสียงอ่านด้วยอักษรละติน แล้วได้อักษรเทวนาครี (namaste → नमस्ते) คำที่ใช้บ่อยจะสะกดตามที่ภาษาฮินดีเขียน นอกนั้น Space แทรกการสะกดแบบแรก ตัวเลขแทรกแบบอื่น ⏎ แทรกตัวอักษรตามที่พิมพ์ และ "." คือเครื่องหมายทัณฑะ (।)
  - ชื่อคำสั่ง ข้อความของ `@open` และโค้ด (`@py`, `@js`) พิมพ์ด้วยอักษรละตินไม่ว่าจะใช้ภาษาใด แล้วภาษานั้นจะกลับมาหลังคำสั่ง
  - `@improve` คงประโยคภาษาเกาหลี ฮินดี หรือฝรั่งเศสไว้ในภาษาเดิม และ `@translate` แปลเป็นภาษาของคุณ (ภาษาฝรั่งเศสจะแยกออกจากภาษาอังกฤษได้เมื่อเป็นหนึ่งในภาษาที่คุณป้อน)
- **Language packs** (แพ็กภาษา): แอปมาพร้อมภาษาอังกฤษ (และภาษาฝรั่งเศส ซึ่งต้องการเพียงรูปแบบแป้นพิมพ์ของ macOS) ภาษาจีน เกาหลี และฮินดีเป็นแพ็กที่คุณดาวน์โหลดเมื่อเพิ่มภาษานั้น: การเพิ่มภาษาจีน (พินอิน) จะดาวน์โหลดพจนานุกรม (ประมาณ 34 MB หรือ 125 MB เมื่อแตกไฟล์) พร้อมแถบความคืบหน้า และพินอินใช้ได้ทันทีที่ดาวน์โหลดเสร็จ โดยไม่ต้องรีสตาร์ต แพ็กภาษาเกาหลี (ตารางปุ่มและวิธีที่จาโมประกอบเป็นพยางค์) และแพ็กภาษาฮินดี (ตัวอักษรและคำที่ใช้บ่อย) มีขนาดเพียงไม่กี่กิโลไบต์ แพ็กเป็นข้อมูลล้วน (พจนานุกรม ตาราง และสคีมา ไม่มีโค้ด) ระบุอยู่ในดัชนีที่มีการลงนาม และตรวจสอบกับ SHA-256 ก่อนใช้งาน เหมือนปลั๊กอิน การ์ดของแต่ละภาษาแสดงแพ็กของภาษานั้น (เวอร์ชัน ขนาด แหล่งที่มา) พร้อมปุ่ม "Delete…" และการนำภาษาออกจะเสนอให้ลบแพ็กของภาษานั้นด้วย การอัปเดตจาก 0.6.1 หรือก่อนหน้านั้นจะคงภาษาจีนไว้โดยไม่ต้องดาวน์โหลด: ตัวติดตั้งจะเก็บพจนานุกรมที่มากับเวอร์ชันเก่าไว้
- **Fuzzy pinyin** (พินอินแบบคลุมเครือ เมื่อป้อนภาษาจีน): เสียงที่คุณไม่ได้แยกแยะ พิมพ์แบบใดก็ได้ เช่น z ↔ zh, n ↔ l, in ↔ ing ที่หน้า "Input" เลือก "Chinese (pinyin)" ในแถบภาษาที่ป้อน เปิด "Fuzzy pinyin" และเลือกคู่เสียง พจนานุกรมจะถูกนำไปใช้ใหม่ภายในหนึ่งถึงสองวินาที ฟีเจอร์นี้เขียน `rime_ice.custom.yaml` ในโฟลเดอร์ผู้ใช้ของ Rime และจะไม่เขียนทับไฟล์ของคุณเองที่อยู่ในนั้น
- **Translate (@translate)**: เพิ่มภาษาที่จะแปลไป (สเปน ฝรั่งเศส เยอรมัน ญี่ปุ่น เกาหลี จีน ฮินดี เบงกาลี ทมิฬ และภาษาหลักอื่น ๆ ของอินเดีย…) แล้วลากเพื่อจัดลำดับ ภาษาฮินดีที่พิมพ์ด้วยอักษรละติน ("aap kaise ho") จะได้กลับมาเป็นอักษรเทวนาครี `@translate` เขียนภาษาละหนึ่งบรรทัดตามลำดับนี้ (หากมีเพียงภาษาเดียวจะได้สามแบบ) ภาษาเดียวกับประโยคจะถูกข้าม การติดตั้งใหม่จะแปลเป็นภาษาแรกในรายการภาษาที่ต้องการของ Mac ที่ไม่ใช่ภาษาอังกฤษ หากมีเพียงภาษาอังกฤษ `@translate` จะเปิดหน้านี้ให้เพิ่มภาษา
- **Keyboard layouts** (รูปแบบแป้นพิมพ์): ภาษาฝรั่งเศสพิมพ์ด้วยรูปแบบที่เลือกไว้บนการ์ดของภาษานั้น (`keyboardLayouts` ในไฟล์การตั้งค่า) สำหรับภาษาอื่น ขณะใช้วิธีป้อนข้อมูลนี้ macOS จะคงรูปแบบแป้นพิมพ์ละตินล่าสุดของคุณไว้ (AZERTY, QWERTZ, Spanish, US International…) คุณจึงพิมพ์ได้ตามปกติ รวมถึง `@` ไม่ว่ารูปแบบของคุณจะวางไว้ที่ใด และ dead key ก็ประกอบอักขระในข้อความของคำสั่งได้ด้วย (⌥E แล้ว E → é, ^ แล้ว e → ê) รูปแบบที่ไม่มีอักษรละติน (รัสเซีย Hindi InScript) ใช้ภายใต้วิธีป้อนข้อมูลไม่ได้: สลับไปใช้ด้วย ⌃Space หรือวาง (⌃V) หรือบอกให้พิมพ์ (dictation) ข้อความลงในคำสั่ง
- `@improve` ขัดเกลาและเขียนใหม่โดยไม่แปล ใช้ `@translate @improve` ร่วมกันเพื่อแปลและเขียนใหม่ในคำขอเดียว เปิด "@improve also translates" ในการตั้งค่าเพื่อให้ `@improve` ทำเช่นนั้นเสมอ

## สไตล์การเขียนใหม่

หลังบรรทัด 1–3 คือแบบเขียนใหม่ **ในภาษาที่คุณพิมพ์**: เขียนใหม่เป็นภาษาอังกฤษสำหรับภาษาอังกฤษ เขียนใหม่เป็นภาษาจีนสำหรับภาษาจีน เลือกสไตล์ใดก็ได้ในการตั้งค่า:

- Polish (ขัดเกลา): น้ำเสียงเดิม เป็นธรรมชาติมากขึ้น
- Concise (กระชับ)
- Formal (เป็นทางการ): สำหรับหัวหน้าและลูกค้า
- Casual (เป็นกันเอง)
- Tactful (ถนอมน้ำใจ)
- Jargon (ศัพท์เฉพาะ): ภาษาแบบ Amazon ในภาษาอังกฤษ (bandwidth, circle back…) ศัพท์เฉพาะของบริษัทเทคโนโลยีใหญ่ในภาษาจีน ข่าวร้ายจะถูกพูดให้เบาลง เช่น "this is a blocker bug" → "Oh! Looks like your team has the bandwidth to fix this minor issue!"

แบบเขียนใหม่ที่เปลี่ยนแค่เครื่องหมายวรรคตอน หรือซ้ำกับบรรทัดอื่น จะไม่แสดง

### รายการศัพท์เฉพาะ (คำศัพท์ของคุณเอง)

Jargon ไม่มีรายการคำศัพท์ในตัว คุณเตรียมรายการของคุณเองได้ (เช่น วลีที่ทีมของคุณใช้) และโมเดลจะเลือกใช้คำเหล่านั้นก่อน ในตัวเลือก บรรทัด Jargon จะระบุความหมายของคำที่ใช้

รายการเป็นไฟล์ข้อความ หนึ่งคำต่อหนึ่งบรรทัด จะตามด้วยความหมายหรือไม่ก็ได้ โดยคั่นด้วย "=" ทวิภาค (:) หรือ Tab (คุณคัดลอกสองคอลัมน์จากสเปรดชีตมาวางได้) บรรทัดที่ขึ้นต้นด้วย `#` คือคอมเมนต์:

```
PRFAQ = a new-feature proposal: the press release and FAQ, written first
COE = an incident review
two-way door = a decision you can undo at any time
```

ที่ "Rewrite Styles → Jargon list" ในการตั้งค่า คลิก "New" เพื่อสร้างรายการว่างที่ `~/.config/allinoneime/jargon.txt` และเปิดขึ้นมา หากคุณมีไฟล์รายการอยู่แล้ว คลิก "Choose File…" เพื่อใช้ไฟล์นั้นในตำแหน่งเดิม (`jargonFile` ในไฟล์การตั้งค่า) การเปลี่ยนแปลงมีผลทันที จะอ่านเพียง 150 คำแรกเท่านั้น เมื่อเลือก "Jargon" ไว้ รายการจะถูกส่งไปยัง Bedrock พร้อมกับทุกคำขอ

## การป้อนด้วยเสียง

<img src="../en/voice.png" width="340" alt="กด ⌥ ขวาค้างไว้เพื่อพูด">

กด ⌥ ขวาค้างไว้แล้วพูด เมื่อปล่อย ข้อความจะถูกแทรก ระบบจะรู้จำเสียงในภาษาที่คุณกำลังพิมพ์ (อังกฤษ จีน ฝรั่งเศส เกาหลี หรือฮินดี) หากคุณพิมพ์คำสั่งก่อน (เช่น `@improve `, `@question `) แล้วจึงพูด ข้อความจะต่อท้ายคำสั่งและ ⏎ จะรันคำสั่งนั้น คุณยังกด ⏎ โดยไม่ปล่อย ⌥ ขวาเพื่อรันทันทีที่พูดจบได้ด้วย เสียงจะถูกรู้จำบน Mac ด้วยระบบรู้จำเสียงในตัวของ macOS (SpeechAnalyzer) และไม่มีการอัปโหลดเสียง ต้องใช้ macOS 26 ขึ้นไป

ครั้งแรก:

- macOS จะถามว่าอนุญาตให้ AllInOneIME ใช้ไมโครโฟนหรือไม่ คุณยังคลิก "Allow Microphone" ในการตั้งค่าไว้ล่วงหน้าได้ด้วย
- หาก Mac เครื่องนี้ยังไม่มีโมเดลเสียงสำหรับภาษานั้น จะดาวน์โหลดให้อัตโนมัติหนึ่งครั้ง คุณยังดาวน์โหลดได้ในการตั้งค่าด้วย

การบันทึกเสียงจะเริ่มหลังจากคุณกดปุ่มค้างไว้ประมาณ 0.2 วินาทีเท่านั้น ดังนั้นการแตะ ⌥ ขวาสั้น ๆ จะไม่เปิดไมโครโฟน (เมื่อตั้งปุ่มสั่งงานเป็น "Tap ⌥" การแตะจะเป็นการสั่งงาน) หากคุณกดปุ่มอื่นขณะกดค้างไว้ (ปุ่มลัด ⌥, ⌥←) จะนับเป็นปุ่มลัดและไม่มีการบันทึกเสียงเช่นกัน การกดปุ่มอื่นใดขณะกำลังบันทึกจะยกเลิกการบันทึก

## การติดตั้ง

การใช้งานต้องใช้ macOS 14 ขึ้นไป ส่วนการป้อนด้วยเสียงต้องใช้ macOS 26 ขึ้นไป ตัวติดตั้งเป็นแบบ universal: ใช้ได้กับ Mac ทั้งที่ใช้ Apple silicon และ Intel จนถึงตอนนี้ทดสอบบน macOS 27 กับ Apple silicon เท่านั้น (บิลด์ Intel ทดสอบผ่านการทดสอบตัวเองภายใต้ Rosetta เท่านั้น)

1. ดาวน์โหลด `AllInOneIME-<version>.dmg` จาก [Releases](https://github.com/MicroZ-LLC/AllInOneIME/releases/latest) (จากที่นั่นเท่านั้น) แล้วเปิดไฟล์
2. ดับเบิลคลิก "Install AllInOneIME" ข้างใน แล้วคลิก "Install" วิธีป้อนข้อมูลจะถูกติดตั้งไปที่ `~/Library/Input Methods` และ "AllInOneIME Settings" ไปที่ `~/Applications` สำหรับผู้ใช้คนนี้เท่านั้น ไม่ต้องใช้รหัสผ่านผู้ดูแลระบบ
3. ตัวติดตั้งยังไม่ได้รับการรับรอง (notarize) จาก Apple ดังนั้น macOS จึงตรวจสอบไม่ได้ว่าใครเป็นผู้สร้าง และในครั้งแรกจะแจ้งว่าไม่สามารถตรวจสอบ "Install AllInOneIME" ได้: คลิก "Done" ("Cancel" บน macOS 14) เปิด System Settings → Privacy & Security คลิก "Open Anyway" ใกล้ด้านล่าง แล้วยืนยัน ตัวติดตั้งของแต่ละเวอร์ชันใหม่ต้องทำขั้นตอนนี้หนึ่งครั้ง

หลังจากนั้น AllInOneIME จะถูกเปิดใช้งานและอยู่ในแหล่งป้อนข้อมูลของคุณ สลับไปใช้ด้วย Ctrl+Space (ปุ่ม 🌐 จะสลับได้ก็ต่อเมื่อตั้ง "Press 🌐 key to" เป็น "Change Input Source" ใน System Settings → Keyboard) หากตัวติดตั้งบอกให้คุณเพิ่มเอง แสดงว่า Mac เครื่องนี้ไม่อนุญาตให้โปรแกรมเปิดใช้งาน ให้เพิ่มเองหนึ่งครั้ง: System Settings → Keyboard → Text Input → Input Sources → Edit… → + (ซ้ายล่าง) → English → AllInOneIME (จะพิมพ์พินอินได้ด้วยเมื่อคุณเพิ่มภาษาจีนที่ "Input" ในการตั้งค่าของแอป)

หาก Ctrl+Space ไม่พาคุณไปที่ AllInOneIME หรือสลับกลับเป็น U.S. หลังจากผ่านไปสักพัก ให้รันตัวติดตั้งอีกครั้ง: ตัวติดตั้งจะเพิ่ม AllInOneIME กลับเข้าไปในแหล่งป้อนข้อมูลของคุณ

หากต้องการอัปเดต ให้ติดตั้งอีกครั้งจากดิสก์อิมเมจของเวอร์ชันใหม่ โดยไม่ต้องถอนการติดตั้งก่อน การตั้งค่า รายการศัพท์เฉพาะ และคำที่เรียนรู้ไว้จะยังอยู่ ก่อนอัปเกรด โปรดอ่าน [บันทึกการเปลี่ยนแปลง](../../CHANGELOG.md): มีการเปลี่ยนแปลงและหมายเหตุการอัปเกรดของแต่ละเวอร์ชัน

หากคุณเคยติดตั้ง AIPinyin (ชื่อเดิมของ AllInOneIME) ก็ติดตั้งได้เลย: AIPinyin.app เดิมและตัวเปิดการตั้งค่าของมันจะถูกลบออก และรายการในแหล่งป้อนข้อมูลของคุณจะเปลี่ยนเป็นชื่อใหม่ โดยไม่ต้องเพิ่มใหม่ การตั้งค่า รายการศัพท์เฉพาะ และคำที่เรียนรู้ไว้จะย้ายไปยังโฟลเดอร์ใหม่ (`~/.config/allinoneime` และอื่น ๆ) เมื่อเปิดครั้งแรก และโฟลเดอร์เดิมแต่ละโฟลเดอร์จะถูกเก็บไว้เป็นลิงก์ไปยังโฟลเดอร์ใหม่

หากต้องการถอนการติดตั้ง ให้เปิด "Install AllInOneIME" แล้วคลิก "Uninstall…" การตั้งค่าและคำที่เรียนรู้ไว้จะยังอยู่

### การบิลด์จากซอร์สโค้ด

การบิลด์ต้องใช้ Xcode 26 ขึ้นไป เนื่องจากการป้อนด้วยเสียงใช้ macOS 26 SDK

```sh
git clone https://github.com/MicroZ-LLC/AllInOneIME.git
cd AllInOneIME
make install
```

`make install` ดาวน์โหลด librime และพจนานุกรม rime-ice แล้วตรวจสอบ บิลด์ และติดตั้งไปยังตำแหน่งเดียวกัน พร้อมเพิ่มลงในแหล่งป้อนข้อมูลของคุณด้วยวิธีเดียวกัน แอปที่ติดตั้งจะไม่มีพจนานุกรมภาษาจีน (พจนานุกรมเหล่านั้นคือแพ็กภาษาจีน): การติดตั้งที่มีพจนานุกรมอยู่แล้วจะเก็บไว้เป็นแพ็ก ไม่เช่นนั้น `make install-pack` จะติดตั้งแพ็กจากพจนานุกรมใน checkout โดยไม่ต้องดาวน์โหลด `make status` แสดงเวอร์ชันที่ติดตั้ง (`version:`) และอยู่ในแหล่งป้อนข้อมูลของคุณหรือไม่ (`listed:`) ถอนการติดตั้ง: `make uninstall`

## การตั้งค่า AI

การแปลและการเขียนใหม่ใช้ผู้ให้บริการ AI ของคุณเอง และค่าใช้จ่ายจะเรียกเก็บจากบัญชีของคุณ: โดยค่าเริ่มต้นคือ Amazon Bedrock ในบัญชี AWS ของคุณ หรือ Claude API, Gemini หรือบริการที่เข้ากันได้กับ OpenAI (ดู "ผู้ให้บริการ AI อื่น" ด้านล่าง)

### Amazon Bedrock

1. เปิดใช้ Bedrock ใน AWS console และตรวจสอบว่าคุณใช้โมเดลที่เลือกได้ ค่าเริ่มต้นคือ Claude Haiku 4.5 ครั้งแรกที่ใช้โมเดลของ Anthropic คุณต้องกรอกแบบฟอร์มกรณีการใช้งานหนึ่งครั้ง
2. สร้าง access key ที่มีสิทธิ์ `bedrock:InvokeModelWithResponseStream` และใส่ไว้ใน profile ใน `~/.aws/credentials` ขณะนี้รองรับเฉพาะคีย์แบบคงที่เช่นนี้ ยังไม่รองรับ SSO หรือ assume-role
3. เปิด "AllInOneIME Settings": หาได้ใน Spotlight หรือใน Applications หรือเปิดจากไอคอนของวิธีป้อนข้อมูลในแถบเมนู → "Settings…" เลือก profile, region และโมเดล แล้วคลิก "Test Connection" (ทดสอบการเชื่อมต่อ) "Language" ที่ด้านบนของหน้าต่างการตั้งค่าเลือกได้ระหว่าง English หรือ Chinese โดยค่าเริ่มต้น ("System") จะตามระบบ (ภาษาจีนหากภาษาจีนอยู่ก่อนภาษาอังกฤษในภาษาที่ต้องการของระบบ นอกนั้นเป็นภาษาอังกฤษ) หน้าต่างการตั้งค่า คำแนะนำในแผงตัวเลือก และเมนูป้อนข้อมูลจะเป็นไปตามค่านี้ทั้งหมด

### ผู้ให้บริการ AI อื่น: Claude API, Gemini, บริการที่เข้ากันได้กับ OpenAI

คุณไม่จำเป็นต้องใช้ AWS: เลือกผู้ให้บริการที่ "AI Provider" ในการตั้งค่า วาง API key คลิก "Save" แล้วคลิก "Test Connection"

| ผู้ให้บริการ | โมเดลเริ่มต้น | API key |
|---|---|---|
| Claude API | `claude-haiku-5-5` (เร็วที่สุด ถูกที่สุด ส่วน Sonnet 5.5 และ Opus 5.5 รอบคอบกว่าแต่ช้ากว่าและแพงกว่า) | [Claude Console](https://platform.claude.com) |
| Gemini API | `gemini-3.8-flash` | Google AI Studio |
| เข้ากันได้กับ OpenAI | `gpt-6-luna` ของ OpenAI (หรือ `gpt-5.4-mini`) "Common Services…" มี DeepSeek, Qwen, Kimi, Zhipu GLM, SiliconFlow, OpenRouter และ Ollama บน Mac เครื่องนี้: เลือกบริการแล้ว base URL จะถูกกรอกให้ จากนั้นใส่ชื่อโมเดล | คีย์ของบริการนั้น ตั้ง Base URL เป็นที่อยู่ของบริการ เช่น `https://api.deepseek.com/v1` หรือ `http://localhost:11434/v1` สำหรับ Ollama บน Mac เครื่องนี้ |

- API key เก็บไว้ใน keychain ของระบบ ไม่เคยเก็บในไฟล์การตั้งค่า หากไม่มีคีย์ในนั้น จะใช้ `ANTHROPIC_API_KEY`, `GEMINI_API_KEY` (หรือ `GOOGLE_API_KEY`) และ `OPENAI_API_KEY` จากเชลล์ของคุณ
- "Thinking" (การคิด) ตั้งไว้ต่ำโดยค่าเริ่มต้น: วิธีป้อนข้อมูลต้องรอทุกประโยค และการคิดน้อยลงก็เร็วขึ้น เลือก "Not set" สำหรับโมเดลที่ไม่รองรับตัวเลือกนี้
- เมื่อเลือก Claude Opus 5.5 หรือ Sonnet 5.5 คำขอจะมีกลไกสำรองเมื่อถูกปฏิเสธของ Claude API (`fallbacks: "default"`): เมื่อตัวจำแนกความปลอดภัยปฏิเสธ เซิร์ฟเวอร์จะลองใหม่ด้วยโมเดลอื่น
- ในไฟล์การตั้งค่า: `provider` (`"bedrock"`, `"anthropic"`, `"gemini"`, `"openai"`) และ `model`, `baseURL`, `effort` และ `temperature` ภายใต้ `anthropic`, `gemini` และ `openai` (ค่าที่ไม่ได้ตั้งจะใช้ค่าเริ่มต้น)

การตั้งค่าทั้งหมดเก็บไว้ใน `~/.config/allinoneime/config.json` หลังจากเปลี่ยนแปลง การแปลครั้งถัดไปจะใช้การตั้งค่าใหม่ โดยไม่ต้องรีสตาร์ต คีย์ที่เพิ่มเข้ามาใหม่:

| คีย์ | หน้าที่ | ค่าเริ่มต้น |
|---|---|---|
| `inputLanguages` | ภาษาที่ป้อน หนึ่งถึงห้าภาษา ภาษาแรกคือค่าเริ่มต้น: `"en"` อังกฤษ, `"zh"` จีน (พินอิน), `"fr"` ฝรั่งเศส, `"ko"` เกาหลี, `"hi"` ฮินดี เช่น `["en", "zh"]`, `["fr", "en", "ko"]` ภาษาจีน เกาหลี และฮินดีใช้ได้เมื่อติดตั้งแพ็กแล้ว | `["en"]` (การติดตั้งใหม่) |
| `keyboardLayouts` | รูปแบบแป้นพิมพ์ที่ภาษาที่ป้อนใช้ ระบุตามรหัสภาษา (ขณะนี้มีเฉพาะภาษาฝรั่งเศส): `{"fr": "com.apple.keylayout.French-PC"}` | ฝรั่งเศส: `com.apple.keylayout.French` (AZERTY) |
| `outputLanguages` | ภาษาที่ `@translate` แปลไป ตามลำดับ: `["es", "fr", "de"]`, … | `["en"]` |
| `improveTranslates` | `@improve` แปลด้วย (เหมือน `@translate @improve`) | `false` |
| `voiceInput` | กด ⌥ ขวาค้างไว้เพื่อพูด | `true` |
| `actionKey` | ปุ่มสั่งงาน: `"enter"` (⏎), `"optionTap"` (Tap ⌥), `"optionSpace"` (⌥Space), `"space"` (Space) | `"enter"` |
| `uiLanguage` | ภาษาของอินเทอร์เฟซ (หน้าต่างการตั้งค่า คำแนะนำในแผงตัวเลือก เมนู): `"zh"`, `"en"` | `null` (ตามระบบ) |
| `rewriteStyles` | สไตล์การเขียนใหม่: `polish`, `concise`, `formal`, `casual`, `tactful`, `jargon` เช่น `["polish", "concise", "jargon"]` | Polish, Concise, Formal |
| `jargonFile` | ไฟล์รายการศัพท์เฉพาะของคุณเอง | `null` (คือ `~/.config/allinoneime/jargon.txt`) |
| `menuBarIcon` | ไอคอนในแถบเมนูและแผงที่เลื่อนลงมา | `true` |
| `fuzzyPinyin` | คู่พินอินแบบคลุมเครือ: `["z-zh", "n-l", "in-ing"]` (z-zh, c-ch, s-sh, n-l, f-h, r-l, an-ang, en-eng, in-ing, ian-iang, uan-uang) | `[]` |

## ความเป็นส่วนตัว

- การพิมพ์ (ภาษาอังกฤษและพินอิน) และการคำนวณด้วย `@calculate` ทำงานในเครื่องทั้งหมด เฉพาะเมื่อคุณกดปุ่มสั่งงานกับ `@improve`, `@translate` หรือ `@question` เท่านั้น ประโยคนั้นจึงจะถูกส่งไปยังผู้ให้บริการ AI ที่คุณเลือก (Bedrock ของคุณเอง หรือบริการที่คุณเพิ่มคีย์ไว้) เมื่อเลือก "Jargon" ไว้และตั้งค่ารายการศัพท์เฉพาะแล้ว รายการจะถูกส่งไปด้วย
- เมื่อใช้ AllInOneIME Cloud ประโยคจะผ่านเซิร์ฟเวอร์ของผู้พัฒนาไปยังผู้ให้บริการโมเดล (ปัจจุบันผ่าน OpenRouter): เซิร์ฟเวอร์เก็บเพียงจำนวนนับ ไม่เคยเก็บข้อความ การลงชื่อเข้าใช้จะเก็บเพียงที่อยู่อีเมลของคุณ
- เสียงจะถูกบันทึกเฉพาะขณะที่คุณกด ⌥ ขวาค้างไว้ และถูกรู้จำบน Mac ข้อความที่รู้จำได้จะถูกส่งเฉพาะในคำสั่งข้างต้น เมื่อคุณกดปุ่มสั่งงาน
- วิธีป้อนข้อมูลจะอ่านข้อความในคลิปบอร์ดหนึ่งครั้ง เฉพาะเมื่อคุณกด ⌃V หรือ ⌘V ในคำสั่ง เนื้อหาที่โปรแกรมจัดการรหัสผ่านทำเครื่องหมายว่าซ่อนไว้จะไม่ถูกอ่าน ข้อความจะแสดงในคำสั่งก่อน และเช่นเดิม จะถูกส่งเฉพาะเมื่อคุณกดปุ่มสั่งงาน macOS เวอร์ชันล่าสุดจะถามว่าอนุญาตให้ AllInOneIME อ่านคลิปบอร์ดหรือไม่: ให้อนุญาต หากไม่ต้องการให้ถามทุกครั้ง ให้ตั้งสิทธิ์การวางของ AllInOneIME เป็นอนุญาตเสมอใน System Settings → Privacy & Security
- ในช่องรหัสผ่าน macOS จะสลับไปใช้แป้นพิมพ์ของตัวเอง (U.S. หรือ ABC) และสลับกลับเมื่อคุณออกจากช่องนั้น เมื่อใดก็ตามที่แอปที่คุณพิมพ์อยู่เปิดการป้อนข้อมูลแบบปลอดภัย AllInOneIME จะไม่ประกอบข้อความและไม่สามารถบันทึกเสียงได้: ปุ่มจะเข้าไปตามที่พิมพ์ และขณะที่ระบบอยู่ในการป้อนข้อมูลแบบปลอดภัย (ช่องรหัสผ่าน Secure Keyboard Entry ของ Terminal ฯลฯ) จะไม่มีอะไรถูกส่งไปยัง AI
- `@note` และ `@reminder` ไม่ผ่าน AI: AllInOneIME ส่งข้อความให้เฉพาะ Notes และ Reminders บน Mac เครื่องนี้ และอ่านเวลาของการเตือนความจำบน Mac เช่นกัน (แอปเหล่านั้นจะซิงค์ไปยังอุปกรณ์อื่นของคุณหรือไม่ขึ้นอยู่กับบัญชีของแอป เช่น iCloud) จึงใช้ได้ระหว่างการป้อนข้อมูลแบบปลอดภัยด้วย
- `@open` ค้นหาบน Mac เครื่องนี้เท่านั้น และจะจำสิ่งที่คุณเปิดด้วยคำสั่งนี้ (200 รายการล่าสุด) ไว้ในค่ากำหนดของวิธีป้อนข้อมูลเอง (ไม่ใช่ใน config.json) เพื่อแสดงรายการเหล่านั้นก่อน
- เพื่อแสดงรายการโน้ตของคุณ แผงในแถบเมนูจะเก็บ id และบรรทัดแรก (ไม่เกิน 80 อักขระ) ของโน้ต 30 รายการล่าสุดที่บันทึกด้วย `@note` ไว้ในค่ากำหนดของวิธีป้อนข้อมูลเอง แม้ในขณะที่ปิดแผงอยู่
- `@py` และ `@js` รันเฉพาะเมื่อคุณกดปุ่มสั่งงาน และรันเฉพาะโค้ดที่คุณพิมพ์หรือวางเอง: คำตอบของ AI และผลลัพธ์ของคำสั่งอื่นจะไม่ถูกรันเป็นโค้ด `@py` ใช้ `python3` ของ Mac ซึ่งอ่านและเขียนไฟล์และออนไลน์ได้เหมือนใน Terminal ส่วน `@js` รันในโพรเซสแยกที่ไม่สามารถอ่านไฟล์ เข้าถึงเครือข่าย หรือรันโปรแกรมอื่นได้ ทั้งสองคำสั่งไม่รันระหว่างการป้อนข้อมูลแบบปลอดภัย
- บันทึก (log) ไม่เก็บสิ่งที่คุณพิมพ์ สำหรับวิธีป้อนข้อมูลจากภายนอกทุกตัว macOS จะเตือนว่า "The developer can access anything you type with this input source" (ผู้พัฒนาสามารถเข้าถึงทุกสิ่งที่คุณพิมพ์ด้วยแหล่งป้อนข้อมูลนี้) ซึ่งเป็นคำเตือนทั่วไปของระบบ

## การพัฒนา

```sh
make test         # unit tests, plus tests that run the real Rime engine
make pack         # the Chinese language pack: build/packs/zh-pinyin-<version>.tar.xz, its sha256, its packs.json entry
make packs        # all the language packs: Chinese, and Korean and Hindi from LanguagePacks/ (ko-hangul, hi-phonetic)
make selftest     # drives the input method through a simulated text field: real Bedrock calls, plus on-device recognition tested with synthesized speech
make realtest     # types into a real app's text field (needs the screen unlocked; takes over the foreground for about 1 minute)
make screenshots  # regenerates the screenshots in docs/
make cli && .build/release/allinoneime-cli --styles concise,jargon "this is a blocker bug your team need fix it asap"   # try polishing and rewrites in the terminal
make icon         # regenerates the app icon and the menu bar icon from Resources/AppIcon.png
make dmg          # the release installer, build/AllInOneIME-<version>.dmg (universal; signed if there's a Developer ID certificate, optionally notarized)
```

โครงสร้างโค้ด:

- `Sources/AllInOneIMECore`: ไคลเอนต์ Bedrock, SigV4, พรอมต์, state machine การป้อนข้อมูลสองระดับ (รวมถึงคำสั่ง @ และท่าทางการป้อนด้วยเสียง) ไม่ขึ้นกับ AppKit
- `Sources/AllInOneIMERime`: ตัวห่อ (wrapper) ของ librime
- `Sources/AllInOneIME`: วิธีป้อนข้อมูล InputMethodKit แผงตัวเลือก หน้าต่างการตั้งค่า การรู้จำเสียง
- `Sources/AllInOneIMESettings`: ตัวเปิด "AllInOneIME Settings"
- `Sources/AllInOneIMEInstaller`: "Install AllInOneIME" บนดิสก์อิมเมจ: ติดตั้ง อัปเดต และถอนการติดตั้ง

แพ็กภาษามีคลังของตัวเอง แยกจากปลั๊กอิน: repository [MicroZ-LLC/AllInOneIME-languages](https://github.com/MicroZ-LLC/AllInOneIME-languages) ให้บริการที่ https://languages.allinoneime.com/ และลงนามด้วยคีย์ของตัวเอง `make pack` สร้างไฟล์บีบอัด ซึ่งเผยแพร่เป็น release asset ที่นั่น (release `zh-pinyin-<version>`, `ko-hangul-<version>`, `hi-phonetic-<version>`) และ `swift Scripts/build-packs-index.swift <languages repo> build/packs/*.tar.xz.json` จะเขียน `packs.json` ที่นั่น และลงนามเป็น `packs.json.sig` ด้วยคีย์ของแพ็กภาษาจาก keychain (`allinoneime-languages-signing`) แอปจะอ่าน https://languages.allinoneime.com/packs.json ตรวจสอบลายเซ็น แล้วจึงตรวจขนาดและ SHA-256 ของไฟล์บีบอัด หากต้องการทดลองแพ็กจากเซิร์ฟเวอร์ในเครื่อง: `--test-key` ลงนามด้วยคีย์ทดสอบ และ `AllInOneIME --install-pack zh-pinyin --library http://127.0.0.1:8765/ --key <its public key> --packs-dir <folder>`

Bundle ID ยังคงเป็น `com.aipinyin.inputmethod.AIPinyin`: macOS ใช้ค่านี้เพื่อจดจำแหล่งป้อนข้อมูลที่เพิ่มไว้และสิทธิ์การใช้ไมโครโฟน การเปลี่ยนค่านี้จึงหมายถึงต้องเพิ่มวิธีป้อนข้อมูลและให้สิทธิ์ใหม่อีกครั้ง
