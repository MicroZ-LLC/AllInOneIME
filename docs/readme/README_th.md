# AllInOneIME

### คำสั่ง AI ในทุกช่องข้อความบน Mac ของคุณ

พิมพ์ `@improve`, `@translate` หรือ `@question` ในแอปใดก็ได้ กด ⏎ แล้วเลือกผลลัพธ์<br>

วิธีป้อนข้อมูล (input method) สำหรับ macOS ที่มีคำสั่ง AI ในทุกช่องข้อความ ขึ้นต้นประโยคด้วย `@` แล้วกด ⏎ เมื่อพิมพ์เสร็จ: `@improve` ขัดเกลาสิ่งที่คุณเขียนและเสนอแบบเขียนใหม่อีกหลายแบบ `@translate` แปลเป็นภาษาที่คุณเลือก `@question` ถามคำถาม `@agent` ส่งงานให้ coding agent (Claude Code, Gemini CLI, Kiro CLI …) และ `@open` ค้นหาไฟล์และแอป หรือเปิดที่อยู่เว็บ คุณยังกด ⌥ ขวาค้างไว้แล้วพูดได้ด้วย หากไม่มี `@` ปุ่มที่คุณกดจะส่งไปยังแอปตามปกติ นอกจากนี้ยังพิมพ์ภาษาจีน (พินอิน สร้างบน Rime และ rime-ice) ภาษาฝรั่งเศส ภาษาเกาหลี (ฮันกึล) และภาษาฮินดี (อักษรเทวนาครีจากอักษรละติน) ได้ และรันสคริปต์ของคุณเองเป็นคำสั่ง @ ได้

## วิธีใช้

หากไม่มี `@` ก็จะไม่เข้ามายุ่ง: ในโหมดภาษาอังกฤษ ตัวอักษรจะถูกพิมพ์โดยตรงและ ⏎ คือปุ่ม Return ไม่มีอะไรถูกส่งออนไลน์ การติดตั้งใหม่จะพิมพ์ภาษาอังกฤษ หากต้องการพิมพ์ภาษาจีน (พินอิน) ภาษาฝรั่งเศส ภาษาเกาหลี หรือภาษาฮินดีด้วย ให้เพิ่มภาษานั้นในการตั้งค่า (ดู [การป้อนข้อความและการแปล](#การป้อนข้อความและการแปล))

| ปุ่ม | หน้าที่ |
|---|---|
| พิมพ์พินอิน, Space / ตัวเลข | ในโหมดภาษาจีน: เลือกคำ เหมือนวิธีป้อนข้อมูลพินอินทั่วไป |
| `@` (ที่ต้นประโยค) | เปิดรายการคำสั่ง: คำสั่งที่ใช้บ่อยช่วงนี้ขึ้นก่อน ครั้งละ 5 รายการ เลื่อนด้วย ↑↓ ล้อเมาส์ หรือแทร็กแพด หรือพิมพ์ตัวอักษรเพื่อค้นหา (ชื่อที่พิมพ์ครบขึ้นก่อน ตามด้วยชื่อที่ขึ้นต้นด้วยตัวอักษรนั้น แล้วจึงเป็นชื่อที่มีตัวอักษรนั้นอยู่) ⏎, Tab, Space หรือตัวเลขเพื่อเลือก |
| ⏎ | รันคำสั่ง ใช้ได้แม้ยังไม่ได้เลือกพินอิน: พินอินจะถูกเลือกก่อน เหมือนกด Space |
| Space, ⏎ / ตัวเลข | เมื่อผลลัพธ์ขึ้นมาแล้ว: แทรกรายการที่ไฮไลต์อยู่ / รายการที่มีหมายเลขนั้น 0 คือข้อความต้นฉบับ ⏎ ยังแทรกได้แม้จะพิมพ์ข้อความต่อเนื่องไว้ครึ่งหนึ่ง (ข้อความนั้นจะถูกทิ้ง) |
| ⇧⏎ | เมื่อพิมพ์ข้อความต่อเนื่องหลังผลลัพธ์จาก AI: ส่งข้อความนั้น (คำถามถัดไปของบทสนทนา `@question` หรือการปรับแต่ง) ระหว่างพิมพ์คำสั่ง หรือเมื่อผลลัพธ์จาก AI ขึ้นแล้วแต่ยังไม่ได้พิมพ์อะไร: แทรกสิ่งที่คุณพิมพ์ตามที่เป็นอยู่ รวมถึง `@command` กับผลลัพธ์อื่น (`@open` การเตือนความจำ …) จะแทรกแถวที่ไฮไลต์อยู่ เหมือน ⏎ กับผลลัพธ์ของ `@config` และ `@doctor` การกด ⇧⏎ โดยไม่ได้พิมพ์อะไรจะไม่ทำอะไรเลย |
| ⌘C | คัดลอกผลลัพธ์ที่ไฮไลต์อยู่ (สำหรับ `@open` คือพาธ) แผงตัวเลือกยังคงเปิดอยู่ |
| ⌃V | ในคำสั่ง (เช่น หลัง `@improve `): ต่อข้อความจากคลิปบอร์ดไว้หลังสิ่งที่คุณพิมพ์ แทนที่จะวางลงในแอป หลายบรรทัดจะถูกรวมเป็นบรรทัดเดียว ครั้งละไม่เกิน 2000 อักขระ (`@note` คงการขึ้นบรรทัดใหม่ไว้และรับได้ถึง 20000) ใช้ได้ในทุกแอป หากไม่มีคำสั่ง ปุ่มจะส่งไปยังแอปตามปกติ |
| ⌘V | เหมือน ⌃V แต่บางแอปจัดการ ⌘V เอง (เทอร์มินัลอย่าง Ghostty, iTerm2 และ Terminal รวมถึง Notes) และวางลงในแอปตามปกติ ในแอปเหล่านั้นให้ใช้ ⌃V |
| Esc, ⌫ | กลับไปที่ประโยคเพื่อแก้ไขต่อ การพิมพ์เครื่องหมายวรรคตอนหรือตัวเลขหลังผลลัพธ์จะเขียนประโยคต่อ หลังการปรับแต่ง: กลับไปที่ผลลัพธ์ก่อนหน้านั้น |
| ตัวอักษร เมื่อผลลัพธ์จาก AI ขึ้นแล้ว | ข้อความต่อเนื่อง: หลัง `@question` คือคำถามถัดไป (ดู [บทสนทนา](#บทสนทนากับ-question-ใหม่)) หลัง `@improve` หรือคำสั่งพรอมต์คือคำสั่งปรับแต่ง เช่น `shorter` (ดู [การปรับแต่งผลลัพธ์](#การปรับแต่งผลลัพธ์-ใหม่)) ⇧⏎ จะส่งข้อความนั้น หลัง `@translate` ตัวอักษรจะเขียนประโยคต่อ และ ⏎ จะแปลประโยคนั้นใหม่ |
| ⌘⏎, ⌘1–⌘9 | ในบทสนทนา `@question`: แสดงที่ที่จะคุยต่อได้ (coding agent ที่ติดตั้งไว้ โดย agent ที่ `@agent` ส่งงานให้อยู่ก่อน; Claude, ChatGPT, Gemini; หรือคัดลอก) ⌘1, ⌘2 … เลือกหนึ่งที่ |
| คลิกที่แถว | ในแผงตัวเลือก: เลือกแถวนั้น เหมือนกดตัวเลขของแถว (คำ คำสั่งในรายการ ผลลัพธ์ ไฟล์ของ `@open` ผู้รับ แถวของส่วนขยาย) แถวที่อยู่ใต้ตัวชี้จะถูกไฮไลต์ ช่องข้อความยังคงโฟกัสอยู่ |
| แตะ Shift | เมื่อมีภาษาป้อนข้อมูลมากกว่าหนึ่งภาษา: สลับไปภาษาถัดไปตามลำดับ (อังกฤษ → จีน → ฝรั่งเศส → … แล้ววนกลับไปภาษาแรก) |
| กด ⌥ ขวาค้างไว้ | พูด ปล่อยเพื่อหยุด ใช้ภาษาที่คุณกำลังพิมพ์อยู่ (อังกฤษ จีน ฝรั่งเศส เกาหลี หรือฮินดี) ในคำสั่ง ข้อความจะต่อท้ายคำสั่ง ไม่เช่นนั้นจะถูกแทรกโดยตรง |

## คำสั่ง @ (เบต้า)

| คำสั่ง | หน้าที่ |
|---|---|
| `@improve` | ขัดเกลา: 1–3 คือสามแบบในภาษาเดียวกับประโยค ตั้งแต่ 4 ขึ้นไปคือสไตล์การเขียนใหม่ (เพิ่มและจัดลำดับได้ในการตั้งค่า) 0 คือต้นฉบับ ไม่แปล หากเปิด "@improve also translates" (@improve แปลด้วย) จะทำงานเหมือน `@translate @improve` |
| `@translate` | แปลเป็นภาษาที่คุณเพิ่มไว้ (การตั้งค่า → "Translate" ลากเพื่อจัดลำดับ) ภาษาละหนึ่งบรรทัด หากมีเพียงภาษาเดียวจะได้สามแบบ ภาษาเดียวกับประโยคจะถูกข้าม ใช้ `@translate @improve` ร่วมกันเพื่อแปลและเขียนใหม่ในคำขอเดียว |
| `@question` | ถามคำถาม คำตอบจะขึ้นในตัวเลือก ⏎ หรือ Space เพื่อแทรก ⌘C เพื่อคัดลอก พิมพ์ต่อแล้วกด ⇧⏎ เพื่อถามต่อ: แผงจะกลายเป็นบทสนทนาได้สูงสุด 5 รอบ จากนั้นจะเสนอให้คุยต่อใน Claude หรือ AI อื่น ถ้าไม่พิมพ์อะไรต่อท้าย จะแสดงคำถามล่าสุด 5 ข้อของคุณ ใหม่สุดขึ้นก่อน พิมพ์เพื่อกรองให้แคบลง (คำที่อยู่ตรงไหนก็ได้ในคำถาม ไม่สนตัวพิมพ์เล็กใหญ่ ภาษาจีนก็ได้) ตัวเลข, ↑↓ แล้ว ⏎ หรือคลิก จะแสดงคำตอบที่บันทึกไว้ของคำถามนั้นทันทีแบบออฟไลน์ เพื่อแทรกหรือคัดลอกตามปกติ กด ⌘R ตรงนั้นเพื่อถามใหม่และได้คำตอบใหม่ ถ้าไม่มีรายการที่ตรง หรือไม่ได้เลือกอะไร ⏎ จะถามสิ่งที่คุณพิมพ์ |
| `@agent` | ส่งงานให้ coding agent บน Mac ของคุณ ซึ่งเลือกได้ใน Settings → Agent: Claude Code (ค่าเริ่มต้น), Gemini CLI, Kiro CLI หรือคำสั่งของคุณเอง (สิ่งที่คุณพิมพ์จะต่อท้ายเป็นอาร์กิวเมนต์ตัวสุดท้าย) หน้านี้ยังแสดงด้วยว่าแต่ละตัวติดตั้งไว้หรือไม่และเริ่มทำงานอย่างไร Claude Code จะทำงานเบื้องหลังโดยค่าเริ่มต้น และแจ้งเตือนเมื่อเสร็จ (คลิกเพื่อเปิดเซสชันใน Terminal แล้วทำต่อ) หรือดูได้ที่ `@tasks` ปิด "Runs in the background and notifies me" (ทำงานเบื้องหลังและแจ้งเตือนฉัน) ใต้ Claude Code ในหน้านั้นเพื่อเปิดใน Terminal แทน agent อื่นจะเปิดใน Terminal โดยมีสิ่งที่คุณพิมพ์เป็นข้อความแรก แต่ละตัวใช้การลงชื่อเข้าใช้และการตั้งค่าของตัวเอง ครั้งแรกที่เปิด Terminal macOS จะถามว่าอนุญาตให้ AllInOneIME ควบคุม Terminal หรือไม่: คลิก OK (ก่อน 0.6.4 คำสั่งนี้ชื่อ `@claude`) |
| `@tasks` | แสดงรายการงาน Claude เบื้องหลัง (กำลังทำ / เสร็จแล้ว / รอคุณอยู่) พร้อมคำตอบล่าสุด ⏎ เปิดงานนั้นใน Terminal ⌘C คัดลอกคำตอบ |
| `@settings` | เปิดหน้าต่างการตั้งค่าทันที (แค่เลือกคำสั่งก็พอ) |
| `@config` | เปลี่ยนการตั้งค่าตามที่คุณอธิบาย: `@config output languages English and French`, `@config use Chinese in WeChat`, `@config candidates in a column` ⏎ จะแสดงสิ่งที่จะเปลี่ยน เดิม → ใหม่ ⏎ (หรือ 1) จะนำไปใช้ Esc ยกเลิก พิมพ์เพิ่มแล้วกด ⇧⏎ เพื่อปรับ ⌘Z หรือ `@config undo` จะเปลี่ยนกลับ ดู [เปลี่ยนการตั้งค่าด้วยการอธิบาย](#เปลี่ยนการตั้งค่าด้วยการอธิบาย-ใหม่) |

โค้ดของ `@py` และ `@js` พิมพ์ด้วยตัวอักษรภาษาอังกฤษ และเครื่องหมายวรรคตอนแบบเต็มความกว้าง (จากโหมดภาษาจีน) จะกลายเป็น ASCII ให้เขียนในบรรทัดเดียว โดยใช้ `;` คั่นระหว่างคำสั่ง โค้ดจะรันในโพรเซสแยก และถูกหยุดหลังจาก 10 วินาที หรือกด Esc เมื่อใดก็ได้ หากเกิดข้อผิดพลาด จะแสดงบรรทัดแรกของข้อผิดพลาด เช่น `ZeroDivisionError: division by zero` ผลลัพธ์ที่มีหลายบรรทัดจะถูกแทรกตามที่พิมพ์ออกมา ส่วนในเทอร์มินัลจะเข้าไปเป็นบรรทัดเดียว (เทอร์มินัลจะรันทุกบรรทัดที่ได้รับ) เทอร์มินัลภายในโปรแกรมแก้ไขโค้ด (VS Code, Cursor, JetBrains) ไม่สามารถแยกออกจากตัวโปรแกรมแก้ไขได้ ดังนั้นในที่นั้น ผลลัพธ์หลายบรรทัดของทุกคำสั่งจะเข้าไปตามเดิม ทั้งสองคำสั่งใช้ภายในประโยคของคำสั่งอื่นได้ด้วย: `@reply the answer is @py 2**100` หากโค้ดมีเว้นวรรค ให้ใส่ในเครื่องหมายคำพูด: `@question explain @py "sum(x * x for x in range(10))"` แต่กลับกันไม่ได้: โค้ดของ `@py` และ `@js` จะรันตรงตามที่คุณพิมพ์เสมอ และ `@commands` ที่อยู่ข้างในจะไม่ถูกรันก่อน

เมื่อ `@` ไม่ได้ตามด้วยคำสั่ง เช่น `@john` ตัว `@` จะถูกแทรกตามปกติ การ @-กล่าวถึงผู้อื่นในแอปแชตจึงยังใช้ได้ เมื่อพิมพ์ต่อจากตัวอักษร ตัวเลข `.` `_` หรือ `-` ทันที เช่นใน `bob@example.com` หรือ `ssh user@host` ตัว `@` จะเป็นแค่ข้อความ: ไม่มีรายการเปิดขึ้นมาในแอปใดเลย รวมถึงเทอร์มินัล ขณะที่รายการเปิดอยู่ ← → หรือปุ่มที่ไม่อาจอยู่ในชื่อคำสั่งได้ (`.`, `:`, `/`) จะปิดรายการ และคงสิ่งที่คุณพิมพ์ (`@`, `@im`) ไว้ตามเดิม ในเทอร์มินัล ← → จะปิดรายการเท่านั้น `@question`, `@improve` และ `@translate` จะส่งไปยัง Bedrock ของคุณเองเฉพาะเมื่อคุณกดปุ่มสั่งงานเท่านั้น `@open` ค้นหาบน Mac เครื่องนี้เท่านั้น `@note` และ `@reminder` ส่งไปยัง Notes และ Reminders บน Mac เครื่องนี้เท่านั้น `@agent` ใช้ agent ที่ติดตั้งบน Mac ของคุณ (ค่าเริ่มต้นคือคำสั่ง `claude` ของ Claude Code) และบัญชีของมันเอง และจะถามคุณก่อนตามปกติ ก่อนแก้ไขไฟล์หรือรันคำสั่ง หากไม่ได้ติดตั้ง agent นั้น จะไม่มี `@agent` ให้ใช้ `@imessage` อ่าน Contacts บน Mac เครื่องนี้เท่านั้น (ชื่อ หมายเลขโทรศัพท์ อีเมล) ไม่ผ่าน AI เลย และ Messages เป็นผู้ส่งข้อความ หากไม่มีแอป Messages จะไม่มีคำสั่งนี้ให้ใช้

### กับข้อความที่เลือก (ใหม่)

เลือกข้อความในแอปใดก็ได้ (ประโยคหนึ่งใน Notes ย่อหน้าหนึ่งใน Mail) พิมพ์ `@improve`, `@translate`, `@question` หรือคำสั่งอื่นที่รับข้อความ แล้วกด ⏎: คำสั่งจะทำงานกับส่วนที่เลือก และผลลัพธ์ที่คุณเลือกจะแทนที่ส่วนนั้น ระหว่างที่คุณพิมพ์ ส่วนที่เลือกจะคงอยู่อย่างเดิมและยังถูกเลือกอยู่: คำสั่งจะเขียนในแผงตัวเลือก ซึ่งบรรทัดแรกคือสิ่งที่คุณพิมพ์ และบรรทัดถัดไปคือ "On the selection: “…” (N characters)" (กับส่วนที่เลือก: N อักขระ) Esc, ⇧⏎ หรือการคลิกที่อื่นจะปล่อยข้อความไว้ตามเดิม การเปลี่ยนส่วนที่เลือกระหว่างนั้นก็เช่นกัน และจะยกเลิกคำสั่ง ข้อความที่พิมพ์หลังคำสั่งคือคำสั่งสำหรับ `@improve` และ `@translate` (`@translate ja`, `@improve more formal`) และคือคำถามสำหรับ `@question` (`@question what does this mean`) เกี่ยวกับส่วนที่เลือก `@open`, `@agent`, `@tasks`, `@settings`, `@reminder`, `@imessage`, `@reportissue` คำสั่งเทอร์มินัล และส่วนขยายแบบสคริปต์ไม่ใช้ส่วนที่เลือก: คำสั่งเหล่านี้รับสิ่งที่คุณพิมพ์ และส่วนที่เลือกยังคงอยู่อย่างเดิม สูงสุด 5000 อักขระ ไม่อ่านเลยระหว่างการป้อนข้อมูลแบบปลอดภัยหรือในเทอร์มินัล ถ้าทำงานผิดปกติในแอปใด ให้ปิดที่ Settings → General → "Use the selected text" (ใช้ข้อความที่เลือก)

### การปรับแต่งผลลัพธ์ (ใหม่)

ระหว่างที่ผลลัพธ์ของ `@improve` คำสั่งพรอมต์ (ของคุณเองหรือของปลั๊กอิน) หรือการเขียนใหม่ของข้อความที่เลือกแสดงอยู่ ให้พิมพ์สิ่งที่ต้องการเปลี่ยน เช่น `shorter`, `warmer`, `more formal`, `add a joke`, `in Japanese` หรือ `用更口语的说法` (ใช้พินอินได้ และแตะ Shift เพื่อสลับภาษา) แล้วกด ⇧⏎: ผลลัพธ์จะถูกส่งไปยัง AI อีกครั้งพร้อมคำสั่งของคุณ และผลลัพธ์ใหม่จะแทนที่ของเดิมในแผงเดียวกัน ⏎ จะแทรกผลลัพธ์ที่เลือกอยู่ แม้จะพิมพ์คำสั่งไว้ครึ่งหนึ่ง (คำสั่งนั้นจะถูกทิ้ง) ปรับแต่งซ้ำได้บ่อยเท่าที่ต้องการ บรรทัดบนสุดของแผงจะแสดงขั้นตอนต่าง ๆ ("Refined: shorter · more formal") และคุณเลือกแถวได้ทุกเมื่อตามปกติ ตัวอักษรตัวแรกจะเริ่มคำสั่ง (แสดงเป็น "refine › …" ที่ด้านบนของแผง) ขณะที่คำสั่งยังว่าง ตัวเลข Space และ ⏎ ใช้เลือกเหมือนเดิม และ ⇧⏎ จะแทรกสิ่งที่คุณพิมพ์ตามที่เป็นอยู่ การปรับแต่งเริ่มได้เมื่อผลลัพธ์ครบแล้ว: การพิมพ์ระหว่างที่ผลลัพธ์แรกยังทยอยมาจะเป็นการเขียนประโยคต่อเหมือนเดิม ระหว่างที่การปรับแต่งทำงานอยู่ คุณพิมพ์คำสั่งถัดไปไว้ก่อนได้ การปรับแต่งจะดำเนินต่อไป และ ⇧⏎ จะเริ่มการปรับแต่งถัดไปเมื่อผลลัพธ์มาถึง Esc จะล้างคำสั่ง แล้วย้อนกลับหนึ่งขั้นไปยังผลลัพธ์ก่อนการปรับแต่งครั้งล่าสุด (ระหว่างการปรับแต่ง: หยุดการปรับแต่ง) แล้วจึงกลับไปที่ประโยค ⌫ บนบรรทัดว่างจะย้อนกลับแบบเดียวกัน กับข้อความที่เลือก ผลลัพธ์ที่คุณเลือกยังคงแทนที่เฉพาะส่วนที่เลือกพอดี ซึ่งไม่ถูกแตะต้องจนถึงตอนนั้น การปรับแต่งที่ล้มเหลว (หรือถูกปฏิเสธระหว่างการป้อนข้อมูลแบบปลอดภัย) จะปล่อยผลลัพธ์ไว้ตามเดิม และคำสั่งของมันพร้อมให้ลองใหม่ด้วย ⇧⏎ การปรับแต่งแบบเดียวกันกับผลลัพธ์เดียวกันจะตอบจากแคช `@translate` ไม่มีการปรับแต่ง: การพิมพ์หลังผลลัพธ์ของมันจะเขียนประโยคต่อ และ ⏎ จะแปลประโยคนั้นใหม่

### บทสนทนากับ @question (ใหม่)

เมื่อ `@question` ตอบแล้ว สิ่งที่คุณพิมพ์ต่อคือคำถามถัดไป: ⇧⏎ จะถามคำถามนั้นพร้อมคำถามและคำตอบก่อนหน้า และแผงจะขยายเป็นบทสนทนา รอบก่อน ๆ แสดงเป็นแถว Q / A สีจาง คำตอบล่าสุดอยู่ด้านล่าง บรรทัดบนสุดบอกว่ารอบถัดไปคือรอบที่เท่าไร ("question 2/5 › …") แทรกคำตอบใดก็ได้: ด้วยตัวเลขของคำตอบนั้น (1–5), ↑↓ แล้ว ⏎ หรือคลิก คำตอบล่าสุดถูกเลือกไว้ และ ⌘C คัดลอกคำตอบที่เลือก ⏎ จะแทรกคำตอบแม้จะพิมพ์คำถามไว้ครึ่งหนึ่ง (คำถามนั้นจะถูกทิ้ง) Esc จะล้างสิ่งที่คุณพิมพ์ แล้วย้อนกลับหนึ่งรอบ ที่รอบแรกจะออกเหมือนเดิม แผงจะขยายได้ถึงประมาณครึ่งหน้าจอ แล้วจึงเลื่อน โดยรายการล่าสุดอยู่ล่างสุด

หลังจาก 5 รอบ (`questionRounds` ในไฟล์ตั้งค่า, 2–10) บรรทัดของคำถามถัดไปจะเปลี่ยนเป็น "5 rounds in: continue in Claude or another AI" (คุยมา 5 รอบแล้ว: คุยต่อใน Claude หรือ AI อื่น) พร้อมตัวเลือกที่มีหมายเลข ⌘1, ⌘2 … ⌘⏎ จะแสดงตัวเลือกเหล่านี้ได้ทุกรอบ (ขณะที่คำตอบยังทยอยมา จะไม่ทำอะไรและไม่ส่งไปถึงแอป) สิ่งที่คุณพิมพ์ตอนนั้นคือข้อความแรกที่ปลายทาง มีเพียง ⌘1, ⌘2 … เท่านั้นที่ส่งข้อความนั้น (⇧⏎ จะไม่ถามอะไรอีกและไม่เปิดอะไร) คำถามเกี่ยวกับข้อความที่เลือกจะนำข้อความนั้นไปด้วย โดยอ้างอิงเป็นบล็อกแยก ตัวเลือก:

- **coding agent ที่ติดตั้งไว้** บน Mac เครื่องนี้ แต่ละตัวแสดงตามชื่อ: agent ที่ `@agent` ส่งงานให้มาก่อน (⌘1) แล้วจึงเป็นตัวอื่น ๆ (Claude Code, Gemini CLI, Kiro CLI หรือคำสั่งของคุณเองจาก Settings → Agent) แต่ละตัวจะเปิดเซสชันแบบโต้ตอบใน Terminal โดยเริ่มแบบเดียวกับที่ `@agent` เริ่ม และเริ่มด้วยบทสนทนาและ "Let's continue this discussion" ตัวที่ไม่ได้ติดตั้งจะไม่แสดง
- **Claude** หรือ **ChatGPT** บนเว็บ โดยกรอกบทสนทนาไว้ให้แล้ว (บทสนทนาที่ยาวจะไปอยู่ในคลิปบอร์ด: วางได้เลย)
- **Gemini** บนเว็บ บทสนทนาอยู่ในคลิปบอร์ดให้วาง
- **Copy the conversation** (คัดลอกบทสนทนา) ในรูปแบบ Markdown (**Q:** / **A:**)

เลือกได้ว่าจะแสดงอันไหนและเรียงอย่างไร (อันแรกคือค่าเริ่มต้น): Settings → General → "Continue a conversation in" (คุยต่อที่; `questionContinueIn` ในไฟล์ตั้งค่า) ถ้ามีมากกว่า 5 ที่ ⌘6 … ⌘9 จะเลือกที่เหลือ "@agent's agent" (agent ของ @agent) ในรายการนั้นคือ agent ที่เลือกไว้ใน Settings → Agent โดยแสดงตามชื่อ ส่วน agent ที่ยังไม่ได้ติดตั้งในตอนนี้จะคงตำแหน่งเดิมไว้ในรายการเมื่อคุณแก้ไขรายการ เมื่อใช้ Apple Intelligence บน Mac เครื่องนี้ บทสนทนาที่ยาวจะไม่พอดีกับบริบทขนาดเล็กของมัน: คำตอบที่เก่าที่สุดจะถูกย่อ จากนั้นรอบที่เก่าที่สุดจะถูกตัดออก และแผงจะแสดง "earlier rounds shortened" (ย่อรอบก่อนหน้าแล้ว) บทสนทนาจะถูกบันทึกไว้ในคำถามล่าสุดภายใต้คำถามแรกของมัน และเมื่อเลือกจะแสดงรอบต่าง ๆ เพื่อให้คุยต่อได้

### คำถามล่าสุด (ใหม่)

`@question` ที่ไม่มีอะไรพิมพ์ต่อท้ายจะแสดงคำถามล่าสุด 5 ข้อของคุณ ใหม่สุดขึ้นก่อน พร้อมเวลาที่ถาม ("3 hours ago") พิมพ์เพื่อกรองให้แคบลง: ทุกคำที่อยู่ตรงไหนก็ได้ในคำถาม ไม่สนตัวพิมพ์เล็กใหญ่ (ภาษาจีนที่ไม่มีช่องว่างก็ได้) ตัวเลข, ↑↓ แล้ว ⏎ หรือคลิก จะแสดงคำตอบที่บันทึกไว้ของคำถามนั้นทันทีโดยไม่ต้องออนไลน์: Space หรือ ⏎ เพื่อแทรก ⌘C เพื่อคัดลอก ⌘R เพื่อถามใหม่และได้คำตอบใหม่ (สำหรับบทสนทนา: คำถามล่าสุดของบทสนทนานั้น) Esc เพื่อกลับไปที่รายการ บทสนทนาที่บันทึกไว้จะแสดงทุกรอบ: พิมพ์เพื่อคุยต่อ ถ้าไม่มีรายการที่ตรง หรือไม่ได้เลือกอะไร ⏎ จะถามสิ่งที่คุณพิมพ์ คำตอบใหม่ของคำถามเดียวกัน หรือบทสนทนาที่คุยต่อ จะแทนที่ของที่บันทึกไว้

- เก็บไว้บน Mac เครื่องนี้เท่านั้น (ดูความเป็นส่วนตัว): ไม่เก็บระหว่างการป้อนข้อมูลแบบปลอดภัย และไม่เก็บคำถามเกี่ยวกับข้อความที่เลือกเลย
- Settings → General → "Remember recent questions" (จดจำคำถามล่าสุด) ใช้ปิดฟีเจอร์นี้ (`rememberQuestions` ในไฟล์ตั้งค่า) การปิดที่นั่นจะลบคำถามเหล่านั้นด้วย หากปิดผ่าน `@config` คำถามจะยังเก็บไว้ เพื่อให้การเลิกทำคืนทุกอย่างกลับไปเหมือนเดิมพอดี (หน้าตัวอย่างของคำสั่งจะบอกไว้) "Clear (N)" (ล้าง) ใช้ลบคำถามเหล่านั้น

### โน้ตและการเตือนความจำ

`@note` สร้างโน้ตใหม่ โดยบรรทัดแรกเป็นชื่อเรื่อง หลังจากคัดลอกข้อความแล้ว ⌃V หลัง `@note ` (หรือ ⌘V นอกเทอร์มินัล) จะบันทึกข้อความพร้อมการขึ้นบรรทัดใหม่ ซึ่งแสดงเป็น ↵ ในคำสั่ง หากคุณออกจากช่องข้อความ (คลิกที่อื่น สลับแอป) หรือกด ⇧⏎ (แทรกตามที่พิมพ์) ก่อนที่โน้ตที่มีการขึ้นบรรทัดใหม่จะถูกบันทึก โน้ตนั้นจะไม่ถูกพิมพ์ลงในแอป (ในเทอร์มินัล แต่ละบรรทัดจะถูกรันเป็นคำสั่ง) แต่จะถูกใส่ไว้ในคลิปบอร์ดแทน ("The note wasn't saved; its text is on the clipboard" – โน้ตไม่ได้ถูกบันทึก ข้อความอยู่ในคลิปบอร์ด) โน้ตที่มีบรรทัดเดียวจะถูกแทรกตามที่พิมพ์

`@reminder` อ่านเวลาอย่าง `tomorrow at 3pm`, `in 2 hours`, `in 3 days at 3pm`, `on the 15th`, `this weekend`, `in 1 month`, `next month` (วันที่ 1 ของเดือนนั้น), `end of the year` ได้ (รวมถึงเวลาที่เขียนเป็นภาษาจีน) วันและเวลาแยกกันได้ (`tomorrow call Bob at 5`) สัปดาห์เริ่มวันจันทร์ เวลาที่ไม่มี am หรือ pm (`at 5`) หมายถึงเวลานั้นครั้งถัดไป และจะไม่อยู่ระหว่างเที่ยงคืนถึง 6 โมงเช้า เวลาที่ผ่านไปแล้วในวันนี้จะหมายถึงพรุ่งนี้ แต่ช่วงของวันที่ยังไม่จบ (`this afternoon`, `tonight`) หมายถึงวันนี้ แบบทั้งวัน วันที่ที่ผ่านไปแล้วในปีนี้จะหมายถึงปีหน้า หากเขียนให้ทำซ้ำ (`standup every Monday at 9`) จะถูกเพิ่มเพียงครั้งเดียว สำหรับครั้งถัดไป: คำเหล่านั้นยังอยู่ในชื่อเรื่อง และแถวจะแสดงว่า "once only" (ครั้งเดียวเท่านั้น) แถวยืนยันจะแสดงเวลาที่อ่านได้ เช่น "tomorrow 3:00 PM" (ตามการตั้งค่า 12/24 ชั่วโมงของ Mac) หากไม่ถูกต้อง Esc จะกลับไปที่ข้อความ หากไม่มีเวลาหรือวันที่ ก็จะไม่มีเวลากำหนด ("no date" – ไม่มีวันที่)

`@stock` และคำสั่งทำนองเดียวกันภายในสองคำสั่งนี้จะไม่ถูกรัน: ข้อความจะถูกบันทึกตามที่เขียน (การพิมพ์ `@` ในนั้นจะไม่เปิดรายการคำสั่ง) ครั้งแรก macOS จะถามว่าอนุญาตให้ AllInOneIME ควบคุม Notes (`@note`) หรือเข้าถึง Reminders (`@reminder`) หรือไม่: ให้อนุญาต หากคุณไม่ได้อนุญาต ให้อนุญาต AllInOneIME ที่ System Settings → Privacy & Security → Automation (Notes) หรือ → Reminders เมื่อบันทึกไม่สำเร็จ (เช่น ไม่มีสิทธิ์) การแจ้งเตือนจะบอกสาเหตุ และข้อความจะกลับมาอยู่ในคำสั่งเพื่อให้แก้ไขและส่งอีกครั้ง เมื่อคุณต้องแก้ไขบางอย่างก่อน (สิทธิ์ บัญชี) ข้อความจะถูกใส่ไว้ในคลิปบอร์ดด้วย (การไปที่ System Settings จะดึงโฟกัสออกจากช่องข้อความ) หากคุณย้ายไปช่องข้อความอื่นหรือกำลังพิมพ์อย่างอื่นอยู่ ข้อความจะถูกใส่ไว้ในคลิปบอร์ดแทน ("Not saved; the text is on the clipboard." – ไม่ได้บันทึก ข้อความอยู่ในคลิปบอร์ด)

### คำสั่งของคุณเอง

ในการตั้งค่า ที่ "Custom @ Commands" (คำสั่ง @ แบบกำหนดเอง) ให้คลิก "Add Command…" (เพิ่มคำสั่ง): ตั้งชื่อและเลือกสิ่งที่คำสั่งทำ (คำสั่งสำหรับ AI โปรแกรม โปรแกรมใน Terminal หรือหน้าเว็บ) หรือเริ่มจากตัวอย่าง คำสั่งของคุณจะอยู่ถัดจากคำสั่งในตัว ชื่อต้องเป็นตัวอักษรภาษาอังกฤษเท่านั้นและซ้ำกับชื่อคำสั่งในตัวไม่ได้ และใช้ได้ตั้งแต่ประโยคถัดไป คำสั่งเหล่านี้เก็บไว้ใน `customCommands` ในไฟล์การตั้งค่า (`~/.config/allinoneime/config.json`) ซึ่งคุณแก้ไขเองได้ด้วย:

```json
"customCommands": [
  { "name": "python", "type": "run", "argv": ["python3", "-c", "{input}"], "summary": "Run Python" },
  { "name": "bc", "type": "run", "argv": ["bc", "-l"], "stdin": "{input}\n" },
  { "name": "sh", "type": "terminal", "argv": ["zsh", "-c", "{input}"] },
  { "name": "reply", "type": "prompt", "prompt": "Write a short, polite reply to the user's message." },
  { "name": "google", "type": "link", "url": "https://www.google.com/search?q={input}" }
]
```

| `type` | หน้าที่ |
|---|---|
| `prompt` | ส่งไปยัง AI โดยใช้ `prompt` เป็นคำสั่ง คำตอบจะปรากฏในตัวเลือก เพื่อแทรกหรือคัดลอก (⌘C) |
| `run` | รัน `argv` เบื้องหลัง สิ่งที่โปรแกรมพิมพ์ออกมาจะปรากฏในตัวเลือก (หลายบรรทัดจะถูกแทรกตามที่พิมพ์ ในเทอร์มินัลจะเป็นบรรทัดเดียว) หากเกิดข้อผิดพลาด จะแสดงบรรทัดสุดท้ายของผลลัพธ์ |
| `terminal` | รัน `argv` ในหน้าต่าง Terminal ใหม่ ไม่มีการแทรกข้อความ |
| `link` | ใส่ข้อความลงในที่อยู่เว็บ `url` และเปิดในเบราว์เซอร์เริ่มต้น ไม่มีการแทรกข้อความ |

- `{input}` จะถูกแทนด้วยสิ่งที่คุณเขียนหลังคำสั่ง และจะอยู่ภายในอาร์กิวเมนต์เดียวที่มันอยู่เสมอ: ไม่มีเชลล์เข้ามาเกี่ยวข้อง หากต้องการเชลล์ ให้ระบุไว้ เหมือน `sh` ด้านบน (`zsh -c`)
- `stdin`: สิ่งที่ส่งไปยังอินพุตมาตรฐานของโปรแกรม โดย `{input}` ก็ถูกแทนที่ด้วย
- `url` ของ `link` ต้องเป็น `https://` มี `{input}` หนึ่งครั้ง หลัง `?` หรือ `#` ข้อความจะถูกเข้ารหัส (เว้นวรรคเป็น `%20` ขึ้นบรรทัดใหม่เป็น `%0A`) ไม่เกิน 4000 อักขระ
- `run` และ `terminal` พิมพ์ตัวอักษรภาษาอังกฤษโดยค่าเริ่มต้น (เหมือน `@open` ในโหมดภาษาจีน ภาษาจีนจะกลับมาหลังจากนั้น) และเครื่องหมายวรรคตอนแบบเต็มความกว้างจะกลายเป็น ASCII ตั้ง `"ascii": false` เพื่อคงข้อความตามที่พิมพ์
- โปรแกรมจะรันในโฟลเดอร์โฮมของคุณ โดยใช้ PATH ของ login shell ของคุณ (จึงพบโปรแกรมที่ติดตั้งผ่าน Homebrew, pyenv และ nvm) `run` จะหยุดโปรแกรมหลังจาก 10 วินาที (`timeoutSeconds`) หรือเมื่อพิมพ์ผลลัพธ์ออกมามากเกินไป Esc หยุดได้ทุกเมื่อ
- `summary` คือคำอธิบายในรายการคำสั่ง (ไม่บังคับ)
- หากไม่พบโปรแกรมใน `argv` (เช่น ไม่มี `python3`) จะไม่มีคำสั่งนั้นให้ใช้ และ `@python …` จะถูกแทรกเป็นข้อความ เมื่อติดตั้งโปรแกรมแล้ว คำสั่งจะปรากฏในช่องข้อความถัดไป

`run` และ `terminal` รันโค้ดบน Mac ของคุณ: เพิ่มเฉพาะคำสั่งที่คุณเขียนเองและไว้ใจเท่านั้น คำสั่งเหล่านี้ก็รันเฉพาะเมื่อคุณกดปุ่มสั่งงาน และไม่รันระหว่างการป้อนข้อมูลแบบปลอดภัย (secure input)

### ส่วนขยายแบบสคริปต์

เพิ่มคำสั่ง @ ของคุณเองในรูปแบบโปรแกรม: สคริปต์ภาษาใดก็ได้ (bash, Python, Node, Swift, …) ที่มีข้อมูลเมตาไม่กี่บรรทัดในคอมเมนต์ วางไว้ใน `~/.config/allinoneime/extensions` หรือในโฟลเดอร์ที่คุณเพิ่มไว้ใน "Settings → Custom Commands → Script Extensions" Raycast Script Commands ใช้ได้ทันทีโดยไม่ต้องแก้ไข และโฟลเดอร์ที่มีสคริปต์เหล่านั้นอยู่แล้วจะถูกพบผ่าน Spotlight

```bash
#!/bin/bash
# @allinoneime.schemaVersion 1
# @allinoneime.title Flights
# @allinoneime.argument1 {"type": "text", "placeholder": "from city"}
# @allinoneime.argument2 {"type": "text", "placeholder": "to city"}

echo "Flights from $1 to $2"
```

`flights.sh` คือ `@flights` เขียนอาร์กิวเมนต์ต่อท้าย คั่นด้วยจุลภาค: `@flights beijing, new york` จะรันโดยมี `beijing` และ `new york` เป็น `$1` และ `$2` (จุลภาคที่เกินมาจะอยู่ในอาร์กิวเมนต์ตัวสุดท้าย) หากอาร์กิวเมนต์ที่จำเป็นว่างอยู่ จะแจ้งว่าขาดอะไรแทนที่จะรัน สิ่งที่สคริปต์พิมพ์ออกมาจะถูกใช้ตามค่า `output` ของมัน:

| `output` | สิ่งที่เกิดขึ้น |
|---|---|
| `insert` (ค่าเริ่มต้น) | ทั้งหมด และแต่ละบรรทัด สำหรับแทรก |
| `show` | แสดงในแผงขณะที่พิมพ์ออกมา (ความคืบหน้า) ไม่มีการแทรกข้อความ ออกจากช่องข้อความแล้วจะทำงานต่อเบื้องหลัง (พร้อมกันได้สูงสุดสี่รายการ) |
| `list` | รายการในรูปแบบ Script Filter JSON ของ Alfred ซึ่งรันใหม่ขณะคุณพิมพ์ การเลือกแถวจะแทรก เปิด (ที่อยู่เว็บ ไฟล์ หรือโฟลเดอร์ ไม่ใช่สิ่งที่รันได้) คัดลอก หรือรันขั้นตอนที่สอง |
| `silent` | แสดงบรรทัดสุดท้ายใกล้เคอร์เซอร์ ไม่มีการแทรกข้อความ |

คำสั่งยังสามารถไม่รับอินพุต (`input none`: กด ⏎ ที่ชื่อเพื่อรัน) รันแบบ `background` และแจ้งเตือนเมื่อเสร็จ (ระหว่างนั้นแผงในแถบเมนูจะแสดงรายการไว้) แสดง `status` ข้างชื่อในรายการคำสั่ง หรือถามก่อน (`confirm`) ได้ คำสั่งจะรันในโฟลเดอร์ของตัวเอง โดยใช้ PATH ของ login shell ของคุณและตัวแปร `ALLINONEIME_*`: ภาษาของอินเทอร์เฟซและภาษาที่ป้อน แอปที่คุณกำลังพิมพ์ และข้อความ **bundle** คือโฟลเดอร์ที่มี `extension.json` ระบุคำสั่งต่าง ๆ ของมัน: คำสั่งเหล่านั้นใช้โค้ดและค่ากำหนดร่วมกัน ซึ่ง Settings จะแสดงไว้ (รหัสผ่านเก็บใน keychain) Settings แสดงรายการทุกคำสั่งพร้อมสวิตช์ และสคริปต์ที่ไม่ได้รวมไว้พร้อมเหตุผล

โหมดของ Raycast จับคู่ดังนี้: `fullOutput` → `show`, `compact` และ `silent` → `silent`, `inline` ที่มี `refreshTime` → status โปรโตคอลทั้งหมดอยู่ใน [docs/extensions.md](../extensions.md) และ [Examples/extensions](../../Examples/extensions) มีตัวอย่างของแต่ละประเภท ส่วนขยายรันโค้ดบน Mac ของคุณ: ใช้เฉพาะที่คุณไว้ใจ ส่วนขยายจะรันเฉพาะเมื่อคุณรันมัน (status หรือ list จะรันขณะคุณพิมพ์) ไม่รันระหว่างการป้อนข้อมูลแบบปลอดภัย และจะหยุดเมื่อวิธีป้อนข้อมูลปิดลง

#### แหล่งที่มาของส่วนขยาย (ใหม่)

bundle อาจมาจากรีโพสิทอรี Git ของคุณเองหรือของทีม และอัปเดตจากที่นั่นต่อไปได้ Settings → Custom Commands → Extension Sources → **Add from Link…** (เพิ่มจากลิงก์): วางที่อยู่ของรีโพสิทอรี (`git@github.com:you/my-extensions.git`, `ssh://…`, `https://…` จะระบุ branch โฟลเดอร์ของ bundle ในรีโพสิทอรี และ tag หรือ commit ที่จะตรึงไว้ด้วยก็ได้) AllInOneIME จะ clone ด้วย **การตั้งค่า git และ SSH ของคุณเอง** (คีย์ agent ~/.ssh/config และ credential helper) ดังนั้นรีโพสิทอรีส่วนตัวจะใช้ได้เหมือนใน Terminal แอปไม่เคยถามหรือเก็บรหัสผ่าน สำเนาที่ clone มาจะอยู่ใน `~/Library/Application Support/AllInOneIME/Sources/`: เข้าไปในโฟลเดอร์พักที่ซ่อนอยู่ก่อน ไม่เคยเข้าไปในโฟลเดอร์ส่วนขยายโดยตรง (อย่าใส่ชื่อผู้ใช้ รหัสผ่าน หรือโทเค็นในที่อยู่ https: credential helper ของ git จะเก็บไว้ให้)

- **ตรวจทานก่อน** ก่อนที่จะโหลดอะไร คุณจะเห็น bundle ทุกคำสั่ง (ชื่อ หัวเรื่อง คำอธิบาย เอาต์พุต) โปรแกรมที่คำสั่งเหล่านั้นรัน ค่ากำหนดของ bundle และ commit ภายใต้คำเตือน "This source isn't signed: it will run programs from <address>" (แหล่งนี้ไม่ได้ลงนาม: จะรันโปรแกรมจากที่อยู่นั้น) มีเพียง **Enable** (เปิดใช้) เท่านั้นที่เพิ่มแหล่งนี้ Cancel (ยกเลิก) จะลบสำเนาที่ clone มา คุณตรวจทานแต่ละแหล่งเพียงครั้งเดียว
- **คุณเป็นผู้ตัดสินใจใช้อัปเดต** วันละครั้ง (และไม่นานหลังจากวิธีป้อนข้อมูลเริ่มทำงาน) จะ fetch แหล่งนั้นเพื่อดูว่ามีอะไรใหม่: Settings จะแสดง "N updates" (N อัปเดต) พร้อม commit ต่าง ๆ (หัวเรื่อง ผู้เขียน วันที่) และป้ายบนหน้านั้น ไม่มีอะไรเปลี่ยนจนกว่าคุณจะคลิก **Update** (อัปเดต) ซึ่งทำเพียง fast-forward และไม่รัน hook ใด ๆ การ force push ทำให้ต้องตรวจทานแหล่งนั้นใหม่: **Re-clone** (clone ใหม่) จะแสดงให้ดู และมีเพียง Enable ที่จะนำประวัติที่ถูกเขียนใหม่มาใช้ (ระหว่างนั้นเวอร์ชันที่ตรวจทานแล้วยังทำงานต่อไป) แหล่งที่ตรึงไว้กับ tag หรือ commit จะไม่ถูกตรวจ ปิดการตรวจรายวันได้เป็นรายแหล่ง (`autoCheck`)
- **ข้อผิดพลาด** เป็นข้อความของ git เอง พร้อม "This uses your own git and SSH setup; check that `git ls-remote <url>` works in Terminal" (ส่วนนี้ใช้การตั้งค่า git และ SSH ของคุณเอง: ตรวจสอบว่าคำสั่งนั้นทำงานใน Terminal) และข้อความเตือนของคุณเองอยู่ข้างใต้ถ้าคุณตั้งไว้ (`authHint` ในไฟล์ตั้งค่า)
- **Remove** (นำออก) จะย้ายสำเนาที่ clone มาไปที่ถังขยะ ค่ากำหนดของ bundle จะเก็บไว้สำหรับครั้งหน้า
- จากเทอร์มินัล: `AllInOneIME --add-source <url> [--path …] [--branch …] [--pin …]` (พิมพ์รายการตรวจทานแล้วเปิดใช้ และรันอีกครั้งหลัง force push) `--update-sources` (fast-forward ทุกแหล่งที่ตรวจทานแล้วและไม่ได้ตรึงไว้) `--list-extensions` (บน `~/Library/Input Methods/AllInOneIME.app/Contents/MacOS/AllInOneIME`)
- จะโหลดเฉพาะโค้ดที่ตรวจทานแล้ว: โฟลเดอร์ของแหล่งที่อยู่ในรายการโหลดแต่ยังไม่ได้ตรวจทานบน Mac เครื่องนี้ (ไฟล์ตั้งค่าที่คัดลอกมา) จะไม่ถูกโหลด git ไม่เคยรอคำตอบ: ไม่มีเทอร์มินัลและไม่มีการถาม ดังนั้นคีย์ของโฮสต์ที่ไม่รู้จักหรือการขอรหัสผ่านจะล้มเหลวทันที

ไฟล์ตั้งค่าเก็บแหล่งเหล่านี้เป็น `extensionSources` โครงสร้างของรีโพสิทอรีอยู่ใน [docs/extensions.md](../extensions.md#10-extension-sources)

### ปลั๊กอิน

ปลั๊กอินคือคำสั่ง `@` สำเร็จรูปสำหรับสิ่งที่ไม่ใช่ทุกคนต้องใช้ เช่น `@stock AAPL 600519 700` สำหรับราคาหุ้น เมื่อติดตั้งแล้วจะทำงานเหมือนคำสั่งอื่น ๆ "Plugins" ในการตั้งค่าจะแสดงสิ่งที่ติดตั้งไว้ และแต่ละตัวส่งข้อความของคุณไปที่ใด และใช้ถอดปลั๊กอินออกได้ ปลั๊กอินคือ JavaScript ที่รันในโพรเซสแยก: เข้าถึงได้เฉพาะเว็บไซต์ที่ประกาศไว้ (HTTPS) และไม่สามารถอ่านไฟล์หรือรันโปรแกรมอื่นได้ "Browse Library…" (เรียกดูคลัง) ใต้ Plugins ในการตั้งค่าจะติดตั้งปลั๊กอินจาก [คลังปลั๊กอิน](https://github.com/MicroZ-LLC/AllInOneIME-plugins): ก่อนติดตั้งจะแสดงว่าปลั๊กอินติดต่อเว็บไซต์ใดบ้าง ดัชนีของคลังมีการลงนาม และทุกไฟล์ต้องตรงกับดัชนี เมื่อมีเวอร์ชันใหม่กว่าจะมีปุ่ม "Update" ไม่มีอะไรอัปเดตเอง ปลั๊กอินของคุณเองวางไว้ใน `~/.config/allinoneime/plugins/` ("Open Plugins Folder"): เป็นปลั๊กอินในเครื่อง ซึ่งคลังจะไม่เขียนทับ ปลั๊กอินแบบ "Link" ไม่รันโค้ด: ใส่ข้อความลงในที่อยู่เว็บแล้วเปิดในเบราว์เซอร์ เช่น `@x nice weather today` ซึ่งเปิดหน้าเขียนโพสต์ของ X โดยกรอกข้อความไว้ให้แล้ว ส่วนจะโพสต์หรือไม่ก็ขึ้นอยู่กับคุณบนหน้านั้น คลังมีปลั๊กอินแบบนี้สี่ตัว (`@x`, `@threads`, `@bsky`, `@weibo`) `@xe` แปลงสกุลเงิน: `@xe 100 USD CNY`, `@xe 1000 JPY EUR` ได้หนึ่งบรรทัดพร้อมวันที่ของอัตราแลกเปลี่ยน (อัตราจาก ExchangeRate-API) `@calculator` เป็นเครื่องคิดเลขที่ใช้งานแบบออฟไลน์ได้ `@calculator 23*17` → `391` (ก่อน 0.6.5 คือ `@calculate` ที่มีในตัว) และ `@calendar` คำนวณวันที่: `@calendar +10` → "Tue, Oct 27 · in 10 days" วิธีเขียนปลั๊กอิน: [docs/plugins.md](../plugins.md)

คำสั่งที่ดึงข้อมูล (ปลั๊กอินและโปรแกรม) ใช้ภายในประโยคได้ด้วย: `@reply tell her @stock AAPL is up today` คำสั่งข้างในจะรันก่อน ผลลัพธ์จะเข้าไปแทนที่ตำแหน่งของมัน แล้วคำสั่งข้างนอกจึงทำงานกับผลนั้น อาร์กิวเมนต์คือคำที่ตามหลังคำสั่ง บวกกับรหัสตัวพิมพ์ใหญ่หรือตัวเลขที่ตามมาทันที (`@stock AAPL TSLA`, `@stock 600519 700`) คำที่เป็นตัวพิมพ์เล็กจะเป็นจุดสิ้นสุด (`@stock SNDK is good to buy` จะค้นหา SNDK) เครื่องหมายคำพูดใช้ระบุอาร์กิวเมนต์อย่างแน่ชัด: `@stock "aapl tsla"` ปลั๊กอิน `@calculator` ก็ใช้ภายในประโยคได้เช่นกัน: `@reply the total is @calculator 23*17 dollars` ภายใน `@agent` และคำสั่งเทอร์มินัล คำสั่งเหล่านี้จะไม่ถูกรัน: คำสั่งเหล่านั้นจะได้รับข้อความตามที่เขียน (การพิมพ์ `@` ในนั้นจะไม่เปิดรายการคำสั่ง)

### ปุ่มสั่งงาน

ค่าเริ่มต้นคือ ⏎ เปลี่ยนได้ที่ "Action key" (ปุ่มสั่งงาน) ในการตั้งค่า (`actionKey` ในไฟล์การตั้งค่า): ⏎, "Tap ⌥" (แตะ ⌥ ข้างใดก็ได้: กดแล้วปล่อยทันที การกด ⌥ ขวาค้างไว้ยังคงใช้สำหรับพูด) ⌥Space หรือ Space (กด Space อีกครั้งหลังจากเลือกคำแล้ว สองครั้งในโหมดภาษาอังกฤษ) ไม่ว่าปุ่มสั่งงานจะเป็นปุ่มใด คำสั่ง @ ก็รันด้วย ⏎ ได้เช่นกัน หาก ⌥Space เป็นปุ่มลัดของ Alfred, Raycast หรือแอปทำนองเดียวกันอยู่แล้ว แอปเหล่านั้นจะได้รับปุ่มก่อน

### การพิมพ์ผลลัพธ์ทีละตัว

เปิด "Type results out" (พิมพ์ผลลัพธ์ทีละตัว) ใน Settings → General (`typeOut` ในไฟล์ตั้งค่า) แล้วผลลัพธ์ของคำสั่งจะถูกพิมพ์ลงในแอปทีละอักขระเหมือนคนพิมพ์ แทนที่จะใส่เข้าไปทีเดียว คำที่เลือกด้วยพินอินยังคงใส่เข้าไปทีเดียว แถบเลื่อนกำหนดความเร็ว ตั้งแต่ 6 วินาทีต่ออักขระถึง 40 อักขระต่อวินาที (`typeOutRate`) และ "Speed up and slow down (like a person)" (เร่งและผ่อนความเร็วเหมือนคน) จะพิมพ์เป็นช่วง ๆ ด้วยความเร็วที่เปลี่ยนไป (`typeOutVaries`) Esc หยุดตรงที่พิมพ์อยู่ ปุ่มอื่นใดจะพิมพ์ส่วนที่เหลือทีเดียว

"Make occasional typos and fix them" (พิมพ์ผิดบ้างแล้วแก้, `typeOutMistakes`) ทำให้ดูเหมือนคนมากขึ้นอีก: บางครั้งกดปุ่มข้าง ๆ ปุ่มที่ถูก แล้วรู้ตัวภายในสามตัวอักษร ลบแล้วพิมพ์ใหม่ พิมพ์ตัวอักษรหรือช่องว่างซ้ำสองครั้งแล้วลบ หรือพิมพ์คำสั้น ๆ ลบ แล้วพิมพ์ใหม่ มีไม่กี่ครั้งต่อ 100 อักขระ ไม่เกิดติดกันสองครั้ง และไม่เกิดที่ต้นบรรทัด ในโค้ด ที่อยู่เว็บและอีเมล และตัวเลข การพิมพ์ผิดเป็นเพียงตัวอักษรหรือตัวเลขที่ผิดหนึ่งตัว ซึ่งแก้ทันที (ไม่พิมพ์วงเล็บ เครื่องหมายคำพูด หรือช่องว่างผิด ซึ่งโปรแกรมแก้ไขจะจับคู่หรือย่อหน้าให้) ตัวอักษรที่ผิดคือปุ่มข้างเคียงบนรูปแบบแป้นพิมพ์ของคุณ (QWERTY, AZERTY, QWERTZ…) ภาษาจีน ญี่ปุ่น และเกาหลีจะแค่ลังเล (พิมพ์สองอักขระ ลบ แล้วพิมพ์ใหม่) ไม่มีอักขระผิด

ในช่องที่ดึงการพิมพ์ผิดกลับได้ (มุมมองข้อความของ Apple เช่น TextEdit และ Notes เบราว์เซอร์ และโปรแกรมแก้ไขส่วนใหญ่): เมื่อพิมพ์จนจบ หรือกดปุ่มอื่นเพื่อพิมพ์ส่วนที่เหลือทีเดียว ข้อความจะตรงกับผลลัพธ์ทุกตัว Esc (หรือการออกจากช่อง) ระหว่างที่กำลังพิมพ์ผิดจะเอาส่วนที่ผิดออกก่อน ช่องจึงมีส่วนต้นของผลลัพธ์ที่ถูกต้องตรงทุกตัว ถ้าเคอร์เซอร์ขยับขณะที่ส่วนที่พิมพ์ผิดยังแสดงอยู่ (การคลิก) ส่วนที่ผิดจะถูกเอาออกตรงตำแหน่งเดิม และส่วนที่เหลือจะพิมพ์โดยไม่มีการพิมพ์ผิด

ไม่มีการพิมพ์ผิดในเทอร์มินัล และในแอปที่ไม่บอกวิธีป้อนข้อมูลว่าเคอร์เซอร์อยู่ที่ไหน ทุกครั้ง การพิมพ์ผิดครั้งแรกจะเป็นแบบง่าย (ตัวอักษรผิดหนึ่งตัว แก้ในครั้งเดียว) จนกว่าช่องนั้นจะแสดงว่าดึงการพิมพ์ผิดกลับได้ ขณะที่ส่วนที่พิมพ์ผิดแสดงอยู่ วิธีป้อนข้อมูลจะตรวจก่อนกดทุกปุ่มว่าช่องมีสิ่งที่มันพิมพ์ไว้ ช่องที่ไม่สนใจตำแหน่งที่ต้องแทนที่ข้อความจะดึงการพิมพ์ผิดกลับไม่ได้: ที่นั่นการพิมพ์ผิดครั้งแรกจะค้างอยู่ ข้อความจึงคลาดไปหนึ่งอักขระ (หลัง Esc หรือปุ่มอื่นด้วย) และแอปนั้นจะไม่มีการพิมพ์ผิดอีก Settings → General แสดงรายชื่อแอปเหล่านั้นใต้สวิตช์การพิมพ์ผิด "Forget apps where typos couldn't be fixed" (ลืมแอปที่แก้การพิมพ์ผิดไม่ได้) ให้แอปเหล่านั้นลองใหม่ได้

### การตั้งค่ารายแอป (ใหม่)

Settings → Apps ให้แอปหนึ่งมีการตั้งค่าของตัวเอง ทุกข้อเป็นตัวเลือก สิ่งที่แอปไม่ได้ตั้งจะเป็นไปตามการตั้งค่าสำหรับทุกแอป:

| การตั้งค่า | ตัวอย่าง | ในไฟล์ตั้งค่า |
| --- | --- | --- |
| ภาษาป้อนข้อมูลที่ช่องข้อความของแอปเริ่มต้นใช้ | Slack ใช้ภาษาอังกฤษ WeChat ใช้พินอิน | `inputLanguage` |
| สไตล์การเขียนใหม่ที่ `@improve` เสนอในแอปนั้น | Mail แบบทางการและสุภาพ Slack แบบสบาย ๆ | `rewriteStyles` |
| พิมพ์ผลลัพธ์ทีละตัวหรือไม่ | เปิดในแอปแชต ปิดใน Mail | `typeOut` |
| ไม่ใช้ AI ในแอปนี้ | `@improve`, `@translate`, `@question`, `@agent` และคำสั่งพรอมต์ของคุณจะไม่ส่งอะไรเลยในแอปนั้นและแจ้งให้ทราบ การพิมพ์และคำสั่งอื่นยังใช้ได้ | `noAI` |

"Add App…" (เพิ่มแอป) แสดงแอปที่คุณพิมพ์เมื่อเร็ว ๆ นี้ หรือเลือกแอปหนึ่งใน /Applications ในเมนูป้อนข้อมูล "This App: <ชื่อ>" มีสวิตช์ด่วนสำหรับแอปที่คุณกำลังพิมพ์ (No AI, Type Results Out ภาษาที่ใช้เริ่มต้น) ในไฟล์ตั้งค่า สิ่งเหล่านี้อยู่ใต้ `appProfiles` ตาม bundle ID: `"appProfiles": {"com.tinyspeck.slackmacgap": {"inputLanguage": "en", "rewriteStyles": ["casual"], "noAI": false}}` bundle ID จับคู่โดยไม่สนตัวพิมพ์เล็กใหญ่ (`com.apple.Mail` คือ `com.apple.mail` ของ Mail) `@reportissue` นับจำนวนแอปที่ตั้งค่าอะไรไว้ โดยไม่ระบุชื่อแอปเลย

- ภาษาที่ใช้เริ่มต้นทำงานเหมือนภาษาป้อนข้อมูลเริ่มต้น: ช่องข้อความจะใช้ภาษานั้นเมื่อกลายเป็นช่องที่ใช้งาน และการสลับด้วย Shift หลังจากนั้นจะคงอยู่สำหรับช่องของแอปนั้นจนกว่าการตั้งค่าจะเปลี่ยน
- เมื่อเปิด No AI คำสั่ง AI ยังคงอยู่ในรายการ @ การเรียกใช้จะแสดงการแจ้งเตือนและเก็บสิ่งที่คุณเขียนไว้ คำสั่งเทอร์มินัลของคุณเอง (`"type": "terminal"`) รันโปรแกรม ไม่ใช่ AI จึงยังใช้ได้ในแอปนั้น

### เปลี่ยนการตั้งค่าด้วยการอธิบาย (ใหม่)

`@config` เปลี่ยนประโยคให้เป็นการตั้งค่า: `@config output languages English and French`, `@config 微信里用中文，邮件里语气正式一点`, `@config candidates in a column`, `@config turn off the typos`, `@config use Claude` ⏎ จะแสดงสิ่งที่จะเปลี่ยนในแผงตัวเลือก แถวละรายการ เดิม → ใหม่ โดยใช้ชื่อเดียวกับใน Settings ("Translation languages: English, Japanese → English, French", "Apps · WeChat · Starts in: Same as everywhere → Chinese") ตอนนี้ยังไม่มีอะไรถูกเปลี่ยนหรือพิมพ์ ⏎ (หรือ 1) จะนำไปใช้ทั้งหมด Esc ยกเลิก และพิมพ์เพิ่มแล้วกด ⇧⏎ จะปรับข้อเสนอ ("เพิ่มภาษาเยอรมันด้วย" การกด ⇧⏎ โดยไม่ได้พิมพ์อะไรจะไม่ทำอะไร และ ⏎ จะนำข้อเสนอที่แสดงอยู่ไปใช้) หลังนำไปใช้แล้ว กด ⌘Z ขณะที่ข้อความยืนยันยังแสดงอยู่ หรือใช้ `@config undo` ภายใน 10 นาทีถัดไป จะคืนค่าเดิมของการตั้งค่าเหล่านั้นให้ตรงทุกค่า

- **สิ่งที่เปลี่ยนได้:** ภาษาที่แปลและภาษาที่ป้อน (และภาษาเริ่มต้น) สไตล์การเขียนใหม่ การจัดวางตัวเลือก การพิมพ์ผลลัพธ์ออกมา (เปิด/ปิด ความเร็ว การเร่งและชะลอ การพิมพ์ผิด) การใช้ข้อความที่เลือก การจดจำคำถาม การซ่อนข้อมูลที่ละเอียดอ่อน (เปิด/ปิด สิ่งที่ซ่อน คำที่จะเพิ่ม) การตรวจหาอัปเดต การตั้งค่ารายแอป (แอปที่เรียกตามชื่อที่คุณใช้ ค้นหาจากแอปของคุณด้วยชื่อหรือ bundle ID) และผู้ให้บริการ AI: ใช้รายไหน profile ของ Bedrock (จาก `~/.aws`) และ region โมเดลที่แอปรู้จักสำหรับผู้ให้บริการนั้น และ base URL ที่เข้ากันได้กับ OpenAI (เฉพาะ `https://`)
- **สิ่งที่ไม่แตะต้องเลย:** API key และทุกอย่างใน keychain คำสั่งที่กำหนดเอง โฟลเดอร์และแหล่งที่มาของส่วนขยาย ปลั๊กอิน รายการศัพท์เฉพาะ ทุกอย่างที่รันโปรแกรม และการตั้งค่าอื่นทั้งหมด แถวเหล่านั้นจะถูกปฏิเสธพร้อมเหตุผล และส่วนที่เหลือยังนำไปใช้ได้
- **ตรวจสอบแบบเดียวกับใน Settings:** ภาษาที่ไม่ใช่ภาษา ภาษาที่แปลเกิน 5 ภาษา ค่าที่อยู่นอกช่วง แอปที่ระบุไม่ได้ หรือภาษาที่ยังไม่ได้ติดตั้งชุดภาษา ("needs the Korean language pack: download it in Settings → Input" คือต้องมีชุดภาษาเกาหลี ให้ดาวน์โหลดใน Settings → Input) จะถูกปฏิเสธทีละแถว ไฟล์ตั้งค่าที่ไม่ถูกต้องจะไม่ถูกเขียนเลย
- **คีย์:** จะไม่สลับไปใช้ผู้ให้บริการที่ไม่มีคีย์ (ไม่มีทั้งใน keychain และในเชลล์ของคุณ): แถวนั้นจะเขียนว่า "Gemini API needs an API key: ⏎ opens Settings to add it (never sent to the AI); you can switch to it there" (Gemini API ต้องใช้ API key: ⏎ จะเปิด Settings ให้เพิ่มคีย์ ซึ่งจะไม่ถูกส่งให้ AI และสลับไปใช้ได้ที่นั่น) และการนำไปใช้จะเปิด Settings → AI Provider พร้อมแผ่นเล็ก ๆ สำหรับใส่คีย์นั้น (Save เพื่อบันทึก หรือ Save and Use เพื่อบันทึกแล้วสลับไปใช้) ขณะที่แถวอื่นยังนำไปใช้ได้ตามปกติ เมื่อมีคีย์ ผู้ให้บริการจะสลับไป Test Connection จะทำงานและแสดงผลใต้ข้อความยืนยัน คีย์ที่พิมพ์ไว้ในประโยคจะถูกตัดออกก่อนส่งอะไรออกไป
- **ใช้บน Mac เครื่องนี้ก่อน:** จะใช้ Apple Intelligence ทุกครั้งที่ Mac เครื่องนี้มี (macOS 26) ไม่ว่าคุณเลือกผู้ให้บริการรายไหน และแม้ยังไม่ได้ตั้งค่าผู้ให้บริการเลย โดยจำกัดอยู่ที่การตั้งค่าและค่าที่อนุญาต และค้นหาแอป profile ของ AWS และชุดภาษาของคุณได้ ถ้าไม่มี ผู้ให้บริการของคุณจะเป็นผู้ตอบ คำขอมีเพียงการตั้งค่าที่อนุญาตและค่าปัจจุบันของการตั้งค่าเหล่านั้น (ไม่มีคีย์ และไม่มีคำที่คุณซ่อน) และการซ่อนข้อมูลที่ละเอียดอ่อนมีผลเหมือนกับคำขออื่น ๆ

### ตรวจสอบการตั้งค่าเครื่อง (ใหม่)

`@doctor` ⏎ จะตรวจสอบการตั้งค่าบน Mac เครื่องนี้ภายในหนึ่งถึงสองวินาที (ระหว่างนั้นจะแสดงการทดสอบการเชื่อมต่อ) แล้วแสดงผลในแผงตัวเลือก แถวละรายการ ✗ ปัญหาขึ้นก่อน ตามด้วย ⚠ คำเตือน แล้วจึง ✓ สิ่งที่ปกติ แต่ละรายการมีวิธีแก้สั้น ๆ: วิธีป้อนข้อมูล (ติดตั้งแล้ว เปิดใช้แล้ว อยู่ในแหล่งป้อนข้อมูลของคุณ) ผู้ให้บริการ AI (บันทึกคีย์ไว้แล้ว หรือพบข้อมูลรับรองของ profile ของ Bedrock โดยไม่อ่านหรือแสดงออกมา Test Connection และ Apple Intelligence) สิทธิ์ต่าง ๆ (การช่วยการเข้าถึง ไมโครโฟนถ้าคุณใช้การป้อนตามคำบอก การควบคุมโน้ต เตือนความจำ Terminal และข้อความ ซึ่งถาม macOS โดยไม่มีหน้าต่างถาม) การป้อนข้อมูลแบบปลอดภัย ชุดภาษาของภาษาที่คุณป้อน `config.json` (อ่านได้หรือไม่ คีย์ที่ไม่รู้จัก ค่าที่อยู่นอกช่วง ภาษาซ้ำ ภาษาที่แปลเกิน 5 ภาษา) ส่วนขยายและปลั๊กอินที่โหลดไม่สำเร็จ อัปเดต และข้อผิดพลาดล่าสุดในบันทึกของแอปเอง

แถวที่มีวิธีแก้จะมีหมายเลข: ตัวเลข (หรือคลิก) จะแสดงสิ่งที่วิธีแก้นั้นจะทำในหน้าตัวอย่างของ `@config` และ ⏎ จะนำไปใช้ ⏎ บนรายการจะแก้รายการที่ปลอดภัยทั้งหมดในครั้งเดียว (ซ่อมการตั้งค่า นำภาษาที่ซ้ำออก เปิดใช้วิธีป้อนข้อมูลอีกครั้ง) การเปิดบานหน้าต่างของการตั้งค่าระบบ การดาวน์โหลดชุดภาษา Check for Updates (ซึ่งเปิด Settings) และช่องใส่คีย์ใน Settings ต้องเลือกทีละรายการ การเปลี่ยนการตั้งค่าเลิกทำได้เหมือนของ `@config` (⌘Z, `@config undo`) ไม่มีวิธีแก้ใดที่ลบข้อมูลของคุณหรือแตะต้องคีย์

`@doctor <question>` (`@doctor why doesn't translate work`) จะรันการตรวจ จากนั้น AI จะอธิบายสาเหตุที่น่าจะเป็นจากผลการตรวจ และทำเครื่องหมายวิธีแก้ที่แนะนำ (⏎ ยังคงนำไปใช้เฉพาะรายการที่ปลอดภัย รายการอื่นเลือกตามหมายเลข) ในแอปที่ตั้งเป็น No AI การตรวจยังคงทำงาน และปฏิเสธเฉพาะคำถาม ใช้ Apple Intelligence เมื่อ Mac เครื่องนี้มี ซึ่งจะเรียกการตรวจที่ต้องใช้เป็นเครื่องมือ ถ้าไม่มีจะใช้ผู้ให้บริการของคุณ และแผงจะแจ้งไว้ สิ่งที่ส่งออกไปมีเพียงผลการตรวจ (ไม่มีพาธที่เลย `~` ไม่มีคีย์ และไม่มีข้อความของคุณ) และคำถามของคุณ การตรวจอย่างเดียวจะไม่ส่งอะไรนอกจากคำขอ Test Connection (เฉพาะเมื่อผู้ให้บริการมีคีย์หรือข้อมูลรับรองให้ทดสอบ)

## แผงในแถบเมนู

<img src="../en/panel-swipe.png" width="520" alt="แผงในแถบเมนู: พื้นหลังกระจกฝ้า มีโน้ต การเตือนความจำ และงาน Claude อยู่บนการ์ด แถวที่ถูกปัดไปทางซ้ายแสดงปุ่ม Remove">

คลิกไอคอนของ AllInOneIME ในแถบเมนู (เครื่องหมาย ∞ กับเคอร์เซอร์ แบบไม่มีกรอบ ส่วนแบบมีกรอบคือแหล่งป้อนข้อมูล) แล้วแผงจะเลื่อนลงมาใต้ไอคอน คลิกที่อื่นเพื่อปิด:

- Notes: โน้ตที่บันทึกด้วย `@note` 5 รายการล่าสุด คลิกเพื่อเปิดใน Notes
- Reminders: การเตือนความจำที่ยังไม่เสร็จในรายการ AllInOneIME ของ Reminders (`@reminder` เพิ่มลงในรายการนั้น) รายการที่ถึงกำหนดเร็วที่สุดมาก่อน แสดง 8 รายการ คลิกวงกลมเพื่อทำเครื่องหมายว่าเสร็จ หรือคลิกชื่อเรื่องเพื่อเปิด Reminders
- Claude Tasks: เหมือน `@tasks` คืองาน Claude เบื้องหลัง (สิ่งที่ `@agent` ส่งต่อให้ Claude Code) ได้ถึง 30 รายการ แสดงครั้งละ 5: เลื่อนเพื่อดูเพิ่ม หรือค้นหาชื่อเรื่องและคำตอบในช่องค้นหา พร้อมความคืบหน้าและบรรทัดแรกของคำตอบล่าสุด คลิกเพื่อเปิดใน Terminal และทำต่อ

ปัดแถว (โน้ต การเตือนความจำ หรืองาน) ไปทางซ้ายด้วยสองนิ้วเพื่อแสดงปุ่ม "Remove" (เอาออก) หรือปัดจนสุดเพื่อเอาออกทันที หากใช้เมาส์ ให้คลิกขวาที่แถว การเอาออกเป็นเพียงการนำออกจากแผง: โน้ตยังอยู่ใน Notes การเตือนความจำยังอยู่ใน Reminders (ยังไม่เสร็จ) งานยังอยู่ใน Claude Code

ส่วนหัวแสดงจำนวน (เช่น "2 reminders · 1 task running" งานที่รอคุณอยู่จะนับแยก เช่น "1 waiting for you") และปุ่มรีเฟรช แผงจะไม่ดึงโฟกัสออกจากแอปที่คุณกำลังพิมพ์: การทำเครื่องหมายการเตือนความจำว่าเสร็จหรือการรีเฟรชจะคงแอปนั้นไว้ด้านหน้า มีเพียงช่องค้นหาของงาน Claude เท่านั้นที่รับแป้นพิมพ์เมื่อถูกคลิก ไอคอนแสดงอยู่โดยค่าเริ่มต้น ปิดได้ที่ "Menu Bar Panel" ในการตั้งค่า

แผงอ่านอะไร และเมื่อใด:

- Notes: รายการเป็นบันทึกของแผงเอง (เก็บไว้แม้แผงจะปิดอยู่) และจะไม่เปิดแอป Notes ขึ้นมาเลย: แผงจะตรวจดู Notes เพื่อหาชื่อเรื่องที่แก้ไขและโน้ตที่ถูกลบ ก็ต่อเมื่อ Notes เปิดอยู่แล้ว และ AllInOneIME เคยได้รับอนุญาตให้ควบคุม Notes มาก่อนเท่านั้น
- Reminders: รายการ AllInOneIME จะถูกอ่านเมื่อแผงเลื่อนลงมา ทุก 60 วินาที และเมื่อการเตือนความจำเปลี่ยนแปลง แผงจะไม่ทำให้ macOS ขอสิทธิ์เข้าถึงด้วยตัวเอง: หาก macOS ยังไม่เคยถามคุณ แผงจะแสดง "Allow Access to Reminders" และมีเพียงปุ่มนั้นที่จะขอสิทธิ์ หากคุณปฏิเสธไปแล้ว แผงจะแสดง "Open System Settings"
- งาน Claude: แผงรัน `claude agents` เฉพาะขณะที่เปิดอยู่เท่านั้น: หนึ่งครั้งเมื่อเลื่อนลงมา เมื่อกด Refresh และเมื่อ `@agent` ส่งต่องาน และทุก 15 วินาทีขณะที่ยังมีงานไม่เสร็จ แต่จะหยุดเมื่องานทั้งหมดเสร็จแล้ว คำตอบล่าสุดอ่านจากส่วนท้ายของบันทึกการสนทนา (transcript) ของ Claude Code บน Mac เครื่องนี้ (`~/.claude/projects`) และเฉพาะเมื่อบันทึกนั้นมีการเปลี่ยนแปลง
- ขณะที่แผงปิดอยู่ จะไม่มีสิ่งใดในนี้ทำงาน แผงจะเก็บเพียงบันทึกของโน้ตที่ `@note` บันทึกไว้

## การป้อนข้อความและการแปล

ในการตั้งค่า:

- **Input languages** (ภาษาที่ป้อน): หนึ่งถึงห้าภาษาจากภาษาอังกฤษ ภาษาจีน (พินอิน) ภาษาฝรั่งเศส ภาษาเกาหลี และภาษาฮินดี เพิ่มด้วยปุ่ม + (แสดงอยู่เสมอ และจะเป็นสีเทาเมื่อครบห้าภาษา) การติดตั้งใหม่เริ่มด้วยภาษาอังกฤษเพียงภาษาเดียว ช่องข้อความใหม่เริ่มด้วยภาษาแรก แตะ Shift เพื่อไปภาษาถัดไปตามลำดับ หากมีภาษาเดียว Shift จะไม่สลับ
  - **ภาษาฝรั่งเศส** พิมพ์ด้วยรูปแบบแป้นพิมพ์ของตัวเอง: AZERTY เว้นแต่คุณจะเลือกแบบอื่นบนการ์ดของภาษานี้ ปุ่ม dead key (^, ¨, `, ´, ~) ก็ประกอบอักขระจากรูปแบบนั้นด้วย
  - **ภาษาเกาหลี** พิมพ์ฮันกึลด้วยรูปแบบ 2-set (Dubeolsik) แต่ละพยางค์ประกอบขึ้นขณะคุณพิมพ์ (g k s → 한) Shift ให้ ㄲ ㄸ ㅃ ㅆ ㅉ และ ㅒ ㅖ
  - **ภาษาฮินดี**: พิมพ์คำตามเสียงอ่านด้วยอักษรละติน แล้วได้อักษรเทวนาครี (namaste → नमस्ते) คำที่ใช้บ่อยจะสะกดตามที่ภาษาฮินดีเขียน นอกนั้น Space แทรกการสะกดแบบแรก ตัวเลขแทรกแบบอื่น ⏎ แทรกตัวอักษรตามที่พิมพ์ และ "." คือเครื่องหมายทัณฑะ (।)
  - ชื่อคำสั่ง ข้อความของ `@open` และโค้ด (`@py`, `@js`) พิมพ์ด้วยอักษรละตินไม่ว่าจะใช้ภาษาใด แล้วภาษานั้นจะกลับมาหลังคำสั่ง
  - `@improve` คงประโยคภาษาเกาหลี ฮินดี หรือฝรั่งเศสไว้ในภาษาเดิม และ `@translate` แปลเป็นภาษาของคุณ (ภาษาฝรั่งเศสจะแยกออกจากภาษาอังกฤษได้เมื่อเป็นหนึ่งในภาษาที่คุณป้อน)
- **Language packs** (แพ็กภาษา): แอปมาพร้อมภาษาอังกฤษ (และภาษาฝรั่งเศส ซึ่งต้องการเพียงรูปแบบแป้นพิมพ์ของ macOS) ภาษาจีน เกาหลี และฮินดีเป็นแพ็กที่คุณดาวน์โหลดเมื่อเพิ่มภาษานั้น: การเพิ่มภาษาจีน (พินอิน) จะดาวน์โหลดพจนานุกรม (ประมาณ 34 MB หรือ 125 MB เมื่อแตกไฟล์) พร้อมแถบความคืบหน้า และพินอินใช้ได้ทันทีที่ดาวน์โหลดเสร็จ โดยไม่ต้องรีสตาร์ต แพ็กภาษาเกาหลี (ตารางปุ่มและวิธีที่จาโมประกอบเป็นพยางค์) และแพ็กภาษาฮินดี (ตัวอักษรและคำที่ใช้บ่อย) มีขนาดเพียงไม่กี่กิโลไบต์ แพ็กเป็นข้อมูลล้วน (พจนานุกรม ตาราง และสคีมา ไม่มีโค้ด) ระบุอยู่ในดัชนีที่มีการลงนาม และตรวจสอบกับ SHA-256 ก่อนใช้งาน เหมือนปลั๊กอิน การ์ดของแต่ละภาษาแสดงแพ็กของภาษานั้น (เวอร์ชัน ขนาด แหล่งที่มา) พร้อมปุ่ม "Delete…" และการนำภาษาออกจะเสนอให้ลบแพ็กของภาษานั้นด้วย การอัปเดตจาก 0.6.1 หรือก่อนหน้านั้นจะคงภาษาจีนไว้โดยไม่ต้องดาวน์โหลด: ตัวติดตั้งจะเก็บพจนานุกรมที่มากับเวอร์ชันเก่าไว้
- **การจัดเรียงตัวเลือก**: สำหรับการเลือกคำ ตัวเลือกพินอินและฮินดีจะเรียงข้างกันโดยค่าเริ่มต้น (Horizontal) เหมือนวิธีป้อนข้อมูลของระบบเอง: ← → เพื่อเลือก และ ↑↓ (หรือ - =) เพื่อเปลี่ยนหน้า เลือก Vertical ในหน้า Input ใต้ภาษาป้อนข้อมูล เพื่อให้เรียงลงมาทีละแถว (↑↓ เพื่อเลือก) รายการคำสั่ง @ และผลลัพธ์จะเรียงแนวตั้งเสมอ
- **Fuzzy pinyin** (พินอินแบบคลุมเครือ เมื่อป้อนภาษาจีน): เสียงที่คุณไม่ได้แยกแยะ พิมพ์แบบใดก็ได้ เช่น z ↔ zh, n ↔ l, in ↔ ing ที่หน้า "Input" เลือก "Chinese (pinyin)" ในแถบภาษาที่ป้อน เปิด "Fuzzy pinyin" และเลือกคู่เสียง พจนานุกรมจะถูกนำไปใช้ใหม่ภายในหนึ่งถึงสองวินาที ฟีเจอร์นี้เขียน `rime_ice.custom.yaml` ในโฟลเดอร์ผู้ใช้ของ Rime และจะไม่เขียนทับไฟล์ของคุณเองที่อยู่ในนั้น
- **Translate (@translate)**: เพิ่มภาษาที่จะแปลไป (สเปน ฝรั่งเศส เยอรมัน ญี่ปุ่น เกาหลี จีน ฮินดี เบงกาลี ทมิฬ และภาษาหลักอื่น ๆ ของอินเดีย…) แล้วลากเพื่อจัดลำดับ ภาษาฮินดีที่พิมพ์ด้วยอักษรละติน ("aap kaise ho") จะได้กลับมาเป็นอักษรเทวนาครี `@translate` เขียนภาษาละหนึ่งบรรทัดตามลำดับนี้ (หากมีเพียงภาษาเดียวจะได้สามแบบ) ภาษาเดียวกับประโยคจะถูกข้าม การติดตั้งใหม่จะแปลเป็นภาษาแรกในรายการภาษาที่ต้องการของ Mac ที่ไม่ใช่ภาษาอังกฤษ หากมีเพียงภาษาอังกฤษ `@translate` จะเปิดหน้านี้ให้เพิ่มภาษา
- **Keyboard layouts** (รูปแบบแป้นพิมพ์): ภาษาฝรั่งเศสพิมพ์ด้วยรูปแบบที่เลือกไว้บนการ์ดของภาษานั้น (`keyboardLayouts` ในไฟล์การตั้งค่า) สำหรับภาษาอื่น ขณะใช้วิธีป้อนข้อมูลนี้ macOS จะคงรูปแบบแป้นพิมพ์ละตินล่าสุดของคุณไว้ (AZERTY, QWERTZ, Spanish, US International…) คุณจึงพิมพ์ได้ตามปกติ รวมถึง `@` ไม่ว่ารูปแบบของคุณจะวางไว้ที่ใด และ dead key ก็ประกอบอักขระในข้อความของคำสั่งได้ด้วย (⌥E แล้ว E → é, ^ แล้ว e → ê) รูปแบบที่ไม่มีอักษรละติน (รัสเซีย Hindi InScript) ใช้ภายใต้วิธีป้อนข้อมูลไม่ได้: สลับไปใช้ด้วย ⌃Space หรือวาง (⌃V) หรือบอกให้พิมพ์ (dictation) ข้อความลงในคำสั่ง
- `@improve` ขัดเกลาและเขียนใหม่โดยไม่แปล ใช้ `@translate @improve` ร่วมกันเพื่อแปลและเขียนใหม่ในคำขอเดียว เปิด "@improve also translates" ในการตั้งค่าเพื่อให้ `@improve` ทำเช่นนั้นเสมอ

## สไตล์การเขียนใหม่

หลังบรรทัด 1–3 คือแบบเขียนใหม่ **ในภาษาที่คุณพิมพ์**: เขียนใหม่เป็นภาษาอังกฤษสำหรับภาษาอังกฤษ เขียนใหม่เป็นภาษาจีนสำหรับภาษาจีน เลือกสไตล์ใดก็ได้ในการตั้งค่า:

- Polish (ขัดเกลา): น้ำเสียงเดิม เป็นธรรมชาติมากขึ้น
- Concise (กระชับ)
- Formal (เป็นทางการ): สำหรับหัวหน้าและลูกค้า
- Casual (เป็นกันเอง)
- Tactful (ถนอมน้ำใจ)
- Jargon (ศัพท์เฉพาะ): ภาษาแบบ Amazon ในภาษาอังกฤษ (bandwidth, circle back…) ศัพท์เฉพาะของบริษัทเทคโนโลยีใหญ่ในภาษาจีน ข่าวร้ายจะถูกพูดให้เบาลง เช่น "this is a blocker bug" → "Oh! Looks like your team has the bandwidth to fix this minor issue!"

แบบเขียนใหม่ที่เปลี่ยนแค่เครื่องหมายวรรคตอน หรือซ้ำกับบรรทัดอื่น จะไม่แสดง

### รายการศัพท์เฉพาะ (คำศัพท์ของคุณเอง)

Jargon ไม่มีรายการคำศัพท์ในตัว คุณเตรียมรายการของคุณเองได้ (เช่น วลีที่ทีมของคุณใช้) และโมเดลจะเลือกใช้คำเหล่านั้นก่อน ในตัวเลือก บรรทัด Jargon จะระบุความหมายของคำที่ใช้

รายการเป็นไฟล์ข้อความ หนึ่งคำต่อหนึ่งบรรทัด จะตามด้วยความหมายหรือไม่ก็ได้ โดยคั่นด้วย "=" ทวิภาค (:) หรือ Tab (คุณคัดลอกสองคอลัมน์จากสเปรดชีตมาวางได้) บรรทัดที่ขึ้นต้นด้วย `#` คือคอมเมนต์:

```
PRFAQ = a new-feature proposal: the press release and FAQ, written first
COE = an incident review
two-way door = a decision you can undo at any time
```

ที่ "Rewrite Styles → Jargon list" ในการตั้งค่า คลิก "New" เพื่อสร้างรายการว่างที่ `~/.config/allinoneime/jargon.txt` และเปิดขึ้นมา หากคุณมีไฟล์รายการอยู่แล้ว คลิก "Choose File…" เพื่อใช้ไฟล์นั้นในตำแหน่งเดิม (`jargonFile` ในไฟล์การตั้งค่า) การเปลี่ยนแปลงมีผลทันที จะอ่านเพียง 150 คำแรกเท่านั้น เมื่อเลือก "Jargon" ไว้ รายการจะถูกส่งไปยัง Bedrock พร้อมกับทุกคำขอ

## การป้อนด้วยเสียง

<img src="../en/voice.png" width="340" alt="กด ⌥ ขวาค้างไว้เพื่อพูด">

กด ⌥ ขวาค้างไว้แล้วพูด เมื่อปล่อย ข้อความจะถูกแทรก ระบบจะรู้จำเสียงในภาษาที่คุณกำลังพิมพ์ (อังกฤษ จีน ฝรั่งเศส เกาหลี หรือฮินดี) หากคุณพิมพ์คำสั่งก่อน (เช่น `@improve `, `@question `) แล้วจึงพูด ข้อความจะต่อท้ายคำสั่งและ ⏎ จะรันคำสั่งนั้น คุณยังกด ⏎ โดยไม่ปล่อย ⌥ ขวาเพื่อรันทันทีที่พูดจบได้ด้วย เสียงจะถูกรู้จำบน Mac ด้วยระบบรู้จำเสียงในตัวของ macOS (SpeechAnalyzer) และไม่มีการอัปโหลดเสียง ต้องใช้ macOS 26 ขึ้นไป

ครั้งแรก:

- macOS จะถามว่าอนุญาตให้ AllInOneIME ใช้ไมโครโฟนหรือไม่ คุณยังคลิก "Allow Microphone" ในการตั้งค่าไว้ล่วงหน้าได้ด้วย
- หาก Mac เครื่องนี้ยังไม่มีโมเดลเสียงสำหรับภาษานั้น จะดาวน์โหลดให้อัตโนมัติหนึ่งครั้ง คุณยังดาวน์โหลดได้ในการตั้งค่าด้วย

การบันทึกเสียงจะเริ่มหลังจากคุณกดปุ่มค้างไว้ประมาณ 0.2 วินาทีเท่านั้น ดังนั้นการแตะ ⌥ ขวาสั้น ๆ จะไม่เปิดไมโครโฟน (เมื่อตั้งปุ่มสั่งงานเป็น "Tap ⌥" การแตะจะเป็นการสั่งงาน) หากคุณกดปุ่มอื่นขณะกดค้างไว้ (ปุ่มลัด ⌥, ⌥←) จะนับเป็นปุ่มลัดและไม่มีการบันทึกเสียงเช่นกัน การกดปุ่มอื่นใดขณะกำลังบันทึกจะยกเลิกการบันทึก

## การติดตั้ง

การใช้งานต้องใช้ macOS 14 ขึ้นไป ส่วนการป้อนด้วยเสียงต้องใช้ macOS 26 ขึ้นไป ตัวติดตั้งเป็นแบบ universal: ใช้ได้กับ Mac ทั้งที่ใช้ Apple silicon และ Intel จนถึงตอนนี้ทดสอบบน macOS 27 กับ Apple silicon เท่านั้น (บิลด์ Intel ทดสอบผ่านการทดสอบตัวเองภายใต้ Rosetta เท่านั้น)

1. ดาวน์โหลด `AllInOneIME-<version>.dmg` จาก [Releases](https://github.com/MicroZ-LLC/AllInOneIME/releases/latest) (จากที่นั่นเท่านั้น) แล้วเปิดไฟล์
2. ดับเบิลคลิก "Install AllInOneIME" ข้างใน แล้วคลิก "Install" วิธีป้อนข้อมูลจะถูกติดตั้งไปที่ `~/Library/Input Methods` และ "AllInOneIME Settings" ไปที่ `~/Applications` สำหรับผู้ใช้คนนี้เท่านั้น ไม่ต้องใช้รหัสผ่านผู้ดูแลระบบ
3. ตัวติดตั้งลงนามด้วย Developer ID และได้รับการรับรอง (notarize) จาก Apple ดังนั้นในครั้งแรก macOS จะถามเพียงว่าจะเปิดแอปที่ดาวน์โหลดจากอินเทอร์เน็ตหรือไม่: คลิก "เปิด" (เวอร์ชันก่อน 0.6.3 ไม่ได้รับการรับรอง: แต่ละเวอร์ชันต้องอนุญาตหนึ่งครั้งที่ การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย → เปิดต่อไป)

หลังจากนั้น AllInOneIME จะถูกเปิดใช้งานและอยู่ในแหล่งป้อนข้อมูลของคุณ สลับไปใช้ด้วย Ctrl+Space (ปุ่ม 🌐 จะสลับได้ก็ต่อเมื่อตั้ง "Press 🌐 key to" เป็น "Change Input Source" ใน System Settings → Keyboard) หากตัวติดตั้งบอกให้คุณเพิ่มเอง แสดงว่า Mac เครื่องนี้ไม่อนุญาตให้โปรแกรมเปิดใช้งาน ให้เพิ่มเองหนึ่งครั้ง: System Settings → Keyboard → Text Input → Input Sources → Edit… → + (ซ้ายล่าง) → English → AllInOneIME (จะพิมพ์พินอินได้ด้วยเมื่อคุณเพิ่มภาษาจีนที่ "Input" ในการตั้งค่าของแอป)

หาก Ctrl+Space ไม่พาคุณไปที่ AllInOneIME หรือสลับกลับเป็น U.S. หลังจากผ่านไปสักพัก ให้รันตัวติดตั้งอีกครั้ง: ตัวติดตั้งจะเพิ่ม AllInOneIME กลับเข้าไปในแหล่งป้อนข้อมูลของคุณ

การอัปเดต: Settings → About → Check for Updates (ตรวจหาอัปเดต) เมื่อมีเวอร์ชันใหม่ About จะแจ้งพร้อมสิ่งที่ใหม่ (และมีหนึ่งบรรทัดในแผงในแถบเมนู) "Update to <version>" (อัปเดตเป็น <เวอร์ชัน>) จะดาวน์โหลด ตรวจสอบกับข้อมูลอัปเดตที่ลงนามด้วยคีย์สำหรับรีลีสของ AllInOneIME ติดตั้ง แล้วรีสตาร์ตวิธีป้อนข้อมูล การตั้งค่า แพ็กภาษา คำที่เรียนรู้ และส่วนขยายของคุณยังคงอยู่ และถ้ามีอะไรผิดพลาด จะนำเวอร์ชันเดิมของคุณกลับมา AllInOneIME ตรวจเองวันละครั้งในเบื้องหลัง (ปิดได้ด้วย "Check for updates automatically" ใน About) ไม่มีอะไรถูกติดตั้งจนกว่าคุณจะคลิก ใช้ได้ตั้งแต่ 0.6.3 สำหรับการอัปเดตเวอร์ชันที่เก่ากว่า หรือถ้าคุณต้องการ ให้ติดตั้งดิสก์อิมเมจของเวอร์ชันใหม่ทับลงไปโดยไม่ต้องถอนการติดตั้งก่อน ก่อนอัปเกรด อ่าน[บันทึกการเปลี่ยนแปลง](../../CHANGELOG.md): มีการเปลี่ยนแปลงของแต่ละเวอร์ชันและหมายเหตุการอัปเกรด

การอัปเดตเป็น 0.6.3 จากเวอร์ชันก่อนหน้า: 0.6.3 เป็นเวอร์ชันแรกที่ลงนามด้วย Developer ID ดังนั้น keychain จึงยังไม่รู้จักว่าเป็นแอปที่บันทึกคีย์ของคุณไว้ ครั้งแรกที่ต้องใช้คีย์แต่ละตัวที่บันทึกไว้ (API key การลงชื่อเข้าใช้ AllInOneIME Cloud รหัสผ่านของส่วนขยาย) macOS จะถามรหัสผ่านสำหรับเข้าสู่ระบบของคุณ: ใส่รหัสผ่านแล้วคลิก "Always Allow" (อนุญาตเสมอ) หลังจากนั้นจะไม่ถามอีก รวมถึงหลังการอัปเดตครั้งต่อ ๆ ไป คีย์ของ Amazon Bedrock อยู่ใน `~/.aws/credentials` ซึ่งไม่ได้รับผลกระทบ การช่วยการเข้าถึง (การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย → การช่วยการเข้าถึง) ซึ่งใช้สำหรับการวางลงในเทอร์มินัลและการอ่านข้อความที่เลือก ก็ต้องทำอีกหนึ่งขั้นตอนเช่นกัน: ถ้ามี AllInOneIME อยู่ในรายการ ให้นำออก แล้วเปิดใหม่เมื่อระบบถาม

หากคุณเคยติดตั้ง AIPinyin (ชื่อเดิมของ AllInOneIME) ก็ติดตั้งได้เลย: AIPinyin.app เดิมและตัวเปิดการตั้งค่าของมันจะถูกลบออก และรายการในแหล่งป้อนข้อมูลของคุณจะเปลี่ยนเป็นชื่อใหม่ โดยไม่ต้องเพิ่มใหม่ การตั้งค่า รายการศัพท์เฉพาะ และคำที่เรียนรู้ไว้จะย้ายไปยังโฟลเดอร์ใหม่ (`~/.config/allinoneime` และอื่น ๆ) เมื่อเปิดครั้งแรก และโฟลเดอร์เดิมแต่ละโฟลเดอร์จะถูกเก็บไว้เป็นลิงก์ไปยังโฟลเดอร์ใหม่

หากต้องการถอนการติดตั้ง ให้เปิด "Install AllInOneIME" แล้วคลิก "Uninstall…" การตั้งค่าและคำที่เรียนรู้ไว้จะยังอยู่

### การบิลด์จากซอร์สโค้ด

การบิลด์ต้องใช้ Xcode 26 ขึ้นไป เนื่องจากการป้อนด้วยเสียงใช้ macOS 26 SDK

```sh
git clone https://github.com/MicroZ-LLC/AllInOneIME.git
cd AllInOneIME
make install
```

`make install` ดาวน์โหลด librime และพจนานุกรม rime-ice แล้วตรวจสอบ บิลด์ และติดตั้งไปยังตำแหน่งเดียวกัน พร้อมเพิ่มลงในแหล่งป้อนข้อมูลของคุณด้วยวิธีเดียวกัน แอปที่ติดตั้งจะไม่มีพจนานุกรมภาษาจีน (พจนานุกรมเหล่านั้นคือแพ็กภาษาจีน): การติดตั้งที่มีพจนานุกรมอยู่แล้วจะเก็บไว้เป็นแพ็ก ไม่เช่นนั้น `make install-pack` จะติดตั้งแพ็กจากพจนานุกรมใน checkout โดยไม่ต้องดาวน์โหลด `make status` แสดงเวอร์ชันที่ติดตั้ง (`version:`) และอยู่ในแหล่งป้อนข้อมูลของคุณหรือไม่ (`listed:`) ถอนการติดตั้ง: `make uninstall`

## การตั้งค่า AI

การแปลและการเขียนใหม่จะส่งไปยังผู้ให้บริการ AI ที่เลือกไว้ใน Settings → AI Provider การติดตั้งใหม่จะเริ่มด้วย AllInOneIME Cloud: ลงชื่อเข้าใช้แล้วจะได้คำขอฟรี 20 ครั้งต่อวัน บน Mac ที่มี Apple Intelligence ก็สามารถทำงานบน Mac เครื่องนี้แทนได้ โดยไม่ต้องมีบัญชี (ดู "Apple Intelligence บน Mac เครื่องนี้" ด้านล่าง) หรือใช้ผู้ให้บริการของคุณเอง โดยค่าใช้จ่ายเรียกเก็บจากบัญชีของคุณ: Amazon Bedrock ในบัญชี AWS ของคุณ, Claude API, Gemini หรือบริการที่เข้ากันได้กับ OpenAI (ดู "ผู้ให้บริการ AI อื่น" ด้านล่าง)

### Amazon Bedrock

1. เปิดใช้ Bedrock ใน AWS console และตรวจสอบว่าคุณใช้โมเดลที่เลือกได้ ค่าเริ่มต้นคือ Claude Haiku 4.5 ครั้งแรกที่ใช้โมเดลของ Anthropic คุณต้องกรอกแบบฟอร์มกรณีการใช้งานหนึ่งครั้ง
2. ใช้ AWS profile ที่ได้รับอนุญาต `bedrock:InvokeModelWithResponseStream`: คีย์แบบคงที่ใน `~/.aws/credentials` หรือ profile ที่ได้ข้อมูลรับรองชั่วคราว (`credential_process` role หรือ SSO ดู "AWS profile" ด้านล่าง)
3. เปิด "AllInOneIME Settings": หาได้ใน Spotlight หรือใน Applications หรือเปิดจากไอคอนของวิธีป้อนข้อมูลในแถบเมนู → "Settings…" เลือก profile, region และโมเดล แล้วคลิก "Test Connection" (ทดสอบการเชื่อมต่อ) "Language" ที่ด้านบนของหน้าต่างการตั้งค่าเลือกได้ระหว่าง English หรือ Chinese โดยค่าเริ่มต้น ("System") จะตามระบบ (ภาษาจีนหากภาษาจีนอยู่ก่อนภาษาอังกฤษในภาษาที่ต้องการของระบบ นอกนั้นเป็นภาษาอังกฤษ) หน้าต่างการตั้งค่า คำแนะนำในแผงตัวเลือก และเมนูป้อนข้อมูลจะเป็นไปตามค่านี้ทั้งหมด

#### AWS profile

ใช้ได้ทุก profile ที่ AWS CLI ใช้ได้โดยไม่ต้องถามอะไรคุณ จาก `~/.aws/config` และ `~/.aws/credentials` (หรือไฟล์ที่ `AWS_CONFIG_FILE` และ `AWS_SHARED_CREDENTIALS_FILE` ในเชลล์ของคุณระบุ) ภายใน profile หนึ่ง จะใช้แหล่งแรกที่ profile นั้นมี ตามลำดับของ AWS CLI (profile ที่มีทั้ง `role_arn` และคีย์ถือเป็น role):

| ประเภท | ใน profile | การรีเฟรช |
| --- | --- | --- |
| Role | `role_arn` คู่กับ `source_profile` (เป็นประเภทใดก็ได้ ต่อเป็นทอด ๆ ได้ด้วย profile ที่อ้างถึงตัวเองจะใช้คีย์ของตัวเอง) หรือ `credential_source = Environment`; `role_session_name`, `external_id`, `duration_seconds` | ขอใหม่ผ่าน STS `AssumeRole` (ใน `region` ของ profile หรือ us-east-1 ถ้าไม่มี) 5 นาทีก่อนหมดอายุ |
| SSO | `sso_account_id`, `sso_role_name` คู่กับ `sso_session` และส่วน `[sso-session …]` ของมัน (หรือแบบเก่า `sso_start_url`, `sso_region`) | ขอใหม่ด้วยการลงชื่อเข้าใช้ที่แคชไว้ 5 นาทีก่อนหมดอายุ |
| คีย์แบบคงที่ | `aws_access_key_id`, `aws_secret_access_key` (และ `aws_session_token`) ใน `~/.aws/credentials` | อ่านใหม่ทุกคำขอ |
| `credential_process` | `credential_process = /usr/local/bin/my-creds --profile dev` (แยกเหมือนคำสั่งเชลล์ รันโดยไม่ผ่านเชลล์ ใช้ PATH ของ login shell ในโฟลเดอร์ส่วนตัวของคุณ นานสุด 60 วินาที) | รันใหม่ 5 นาทีก่อน `Expiration` ของมัน ถ้าไม่มี จะรันใหม่เมื่อ AWS ปฏิเสธข้อมูลรับรอง |
| คีย์แบบคงที่ | คีย์ชุดเดียวกันใน `~/.aws/config` | อ่านใหม่ทุกคำขอ |

เมื่อใช้ profile "default" (หรือไม่ได้เลือก) คีย์ในเชลล์ของคุณจะมาก่อน เหมือนที่ AWS CLI ใช้: `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY` และ `AWS_SESSION_TOKEN` profile ที่คุณระบุชื่อจะไม่ปนกับคีย์เหล่านี้เลย `AWS_REGION` (หรือ `AWS_DEFAULT_REGION`) ในเชลล์มีผลเหนือ `region` ของ profile เหมือนใน AWS CLI และช่อง Region ใน Settings มีผลเหนือทั้งสองอย่าง

- **อัตโนมัติ:** ข้อมูลรับรองที่มีวันหมดอายุจะเก็บไว้ในหน่วยความจำ (ไม่เขียนลงดิสก์เลย) และขอใหม่ 5 นาทีก่อนหมดอายุ เมื่อเหลือไม่ถึง 10 นาที คำขอจะใช้ของเดิมไปก่อนและขอใหม่ในเบื้องหลัง การพิมพ์จึงไม่ต้องรอ คำขอที่มาพร้อมกันจะรอการขอใหม่ครั้งเดียว เมื่อ Bedrock ตอบว่าข้อมูลรับรองหมดอายุ (`ExpiredTokenException` …) จะขอใหม่และส่งคำขออีกเพียงครั้งเดียว
- **SSO:** AllInOneIME ใช้การลงชื่อเข้าใช้ที่ AWS CLI เก็บไว้ใน `~/.aws/sso/cache` (อ่านอย่างเดียว) และลงชื่อเข้าใช้แทนคุณไม่ได้ เพราะต้องใช้เบราว์เซอร์ เมื่อการลงชื่อเข้าใช้หมดอายุ แผงตัวเลือกจะแสดง "SSO sign-in expired: run aws sso login --profile X" (การลงชื่อเข้าใช้ SSO หมดอายุ: ให้รัน aws sso login --profile X): รันคำสั่งนั้นใน Terminal (Settings มี Copy Command และ Open in Terminal และ `@doctor` มีคำสั่งให้คัดลอก) แล้ว AllInOneIME จะใช้การลงชื่อเข้าใช้ใหม่เอง
- **ไม่รองรับ:** `mfa_serial` (วิธีป้อนข้อมูลถามรหัส MFA จากคุณไม่ได้: ให้ใช้ `credential_process` หรือ SSO หรือให้ CLI ของคุณแคชข้อมูลรับรองไว้) `credential_source = Ec2InstanceMetadata` หรือ `EcsContainer` (ไม่มีบน Mac) และ web identity
- **ข้อจำกัดที่ทราบ:** จาก login shell จะใช้เพียง PATH และตัวแปรไฟล์ของ AWS (`AWS_CONFIG_FILE`, `AWS_SHARED_CREDENTIALS_FILE`) รวมถึงสำหรับ `credential_process` ด้วย (ไม่ใช้สภาพแวดล้อมส่วนอื่น) AllInOneIME ไม่ต่ออายุโทเค็นของ `sso_session` (ไม่ใช้ refresh token ของ CLI: แคช SSO อ่านอย่างเดียว) ดังนั้นเมื่อโทเค็นในแคชหมดอายุ ให้รัน `aws sso login` (AWS CLI ก็ต่ออายุให้ทุกครั้งที่คุณใช้งาน)
- **Settings → AI Provider** แสดงทุก profile พร้อมประเภท ("dev — Role via base") และบอกว่าข้อมูลรับรองของ profile ที่เลือกจะหมดอายุเมื่อไร ("Role via base: credentials expire at 15:30", "SSO (signed in until 18:00)") หรือควรทำอะไร Test Connection จะขอข้อมูลรับรองใหม่ตลอดทั้งสาย และ `@doctor` รายงานแบบเดียวกัน
- จะรันโปรแกรมและขอข้อมูลรับรองจาก AWS (`sts.<region>.amazonaws.com`, `portal.sso.<region>.amazonaws.com`) เฉพาะเมื่อคำขอหรือ Test Connection ต้องใช้เท่านั้น: ไม่เคยทำเพื่อแสดงรายการ profile และไม่เคยทำเพื่อ `@config`

### ผู้ให้บริการ AI อื่น: Claude API, Gemini, บริการที่เข้ากันได้กับ OpenAI

คุณไม่จำเป็นต้องใช้ AWS: เลือกผู้ให้บริการที่ "AI Provider" ในการตั้งค่า วาง API key คลิก "Save" แล้วคลิก "Test Connection"

| ผู้ให้บริการ | โมเดลเริ่มต้น | API key |
|---|---|---|
| Claude API | `claude-haiku-5-5` (เร็วที่สุด ถูกที่สุด ส่วน Sonnet 5.5 และ Opus 5.5 รอบคอบกว่าแต่ช้ากว่าและแพงกว่า) | [Claude Console](https://platform.claude.com) |
| Gemini API | `gemini-3.8-flash` | Google AI Studio |
| เข้ากันได้กับ OpenAI | `gpt-6-luna` ของ OpenAI (หรือ `gpt-5.4-mini`) "Common Services…" มี DeepSeek, Qwen, Kimi, Zhipu GLM, SiliconFlow, OpenRouter และ Ollama บน Mac เครื่องนี้: เลือกบริการแล้ว base URL จะถูกกรอกให้ จากนั้นใส่ชื่อโมเดล | คีย์ของบริการนั้น ตั้ง Base URL เป็นที่อยู่ของบริการ เช่น `https://api.deepseek.com/v1` หรือ `http://localhost:11434/v1` สำหรับ Ollama บน Mac เครื่องนี้ |

- API key เก็บไว้ใน keychain ของระบบ ไม่เคยเก็บในไฟล์การตั้งค่า หากไม่มีคีย์ในนั้น จะใช้ `ANTHROPIC_API_KEY`, `GEMINI_API_KEY` (หรือ `GOOGLE_API_KEY`) และ `OPENAI_API_KEY` จากเชลล์ของคุณ
- แถว API key จะบอกว่ามีคีย์ตั้งไว้หรือไม่: "✓ Saved · ends in a1b2" (บันทึกแล้ว · ลงท้ายด้วย a1b2: อักขระ 4 ตัวสุดท้าย ซึ่งเก็บไว้คู่กับคีย์ จึงไม่ต้องอ่านคีย์เพื่อแสดง) พร้อม Replace… (แทนที่) และ Remove… (นำออก), "✓ From $OPENAI_API_KEY" (จาก $OPENAI_API_KEY) สำหรับคีย์จากเชลล์ หรือ "No API key yet" (ยังไม่มี API key) พร้อมช่องให้วางคีย์
- "Thinking" (การคิด) ตั้งไว้ต่ำโดยค่าเริ่มต้น: วิธีป้อนข้อมูลต้องรอทุกประโยค และการคิดน้อยลงก็เร็วขึ้น เลือก "Not set" สำหรับโมเดลที่ไม่รองรับตัวเลือกนี้
- เมื่อเลือก Claude Opus 5.5 หรือ Sonnet 5.5 คำขอจะมีกลไกสำรองเมื่อถูกปฏิเสธของ Claude API (`fallbacks: "default"`): เมื่อตัวจำแนกความปลอดภัยปฏิเสธ เซิร์ฟเวอร์จะลองใหม่ด้วยโมเดลอื่น
- ในไฟล์การตั้งค่า: `provider` (`"bedrock"`, `"anthropic"`, `"gemini"`, `"openai"`) และ `model`, `baseURL`, `effort` และ `temperature` ภายใต้ `anthropic`, `gemini` และ `openai` (ค่าที่ไม่ได้ตั้งจะใช้ค่าเริ่มต้น)

### Apple Intelligence บน Mac เครื่องนี้ (macOS 26)

บน Mac ที่มี Apple Intelligence (Apple silicon, macOS 26 ขึ้นไป และเปิดใน การตั้งค่าระบบ → Apple Intelligence และ Siri) ให้เลือก "Apple Intelligence (on this Mac)" ใน "AI Provider": ไม่ต้องใช้คีย์ ไม่มีค่าใช้จ่าย และไม่มีสิ่งที่คุณพิมพ์ออกจาก Mac โดยใช้โมเดลที่มีมาใน macOS (เฟรมเวิร์ก Foundation Models) พร้อมคำสั่งและรูปแบบคำตอบเหมือนผู้ให้บริการอื่น แต่ใช้เฉพาะตัวอย่างที่เขียนด้วยภาษาของประโยคนั้นเอง (โมเดลขนาดเล็กลอกภาษาของตัวอย่างง่ายเกินไป)

- เป็นโมเดลขนาดเล็ก: บริบทประมาณ 4K โทเค็น (8K บน macOS 27) ย่อหน้ายาว ๆ จึงอาจยาวเกินไป และรองรับภาษาน้อยกว่า (อังกฤษ จีน ญี่ปุ่น เกาหลี ฝรั่งเศส เยอรมัน สเปน และอีกไม่กี่ภาษา ไม่รวมฮินดี) ทั้งสองกรณีจะแจ้งให้ทราบ ผลลัพธ์ด้อยกว่าโมเดลบนคลาวด์ และคำตอบของ `@question` เกี่ยวกับข้อเท็จจริงและโค้ดมักผิด
- ในที่ที่ใช้ไม่ได้ จะแสดงเป็นสีจางพร้อมเหตุผล (Mac เครื่องนี้ไม่รองรับ ปิดอยู่ โมเดลยังไม่พร้อม) และในการตั้งค่ามีลิงก์ไปยัง การตั้งค่าระบบ → Apple Intelligence และ Siri ก่อน macOS 26 จะไม่แสดงในรายการ
- "Output tokens", temperature และระยะหมดเวลาใน "Model Settings" มีผลกับโมเดลนี้ ในไฟล์ตั้งค่า: `"provider": "apple"`

### การซ่อนข้อมูลที่ละเอียดอ่อน (ใหม่)

Settings → AI Provider → Privacy → "Hide sensitive information before sending" (ซ่อนข้อมูลที่ละเอียดอ่อนก่อนส่ง ปิดอยู่โดยค่าเริ่มต้น): ก่อนที่คำขอจะไปถึง AI สิ่งที่พบในข้อความของคุณจะถูกแทนที่บน Mac ด้วยตัวยึดตำแหน่ง เช่น `[EMAIL_1]` (ค่าเดียวกัน ตัวยึดตำแหน่งเดียวกัน) และผลลัพธ์จะได้ค่าจริงกลับคืนก่อนแสดงหรือแทรก แผงจะแสดง "2 items hidden from the AI" (ซ่อน 2 รายการจาก AI) แต่ละประเภทปิดได้:

| ประเภท | ตัวอย่าง | ในไฟล์ตั้งค่า |
| --- | --- | --- |
| ที่อยู่อีเมล | `bob@example.com` | `emails` |
| หมายเลขโทรศัพท์ | `+1 (555) 123-4567`, `138 0013 8000` | `phones` |
| หมายเลขบัตรชำระเงิน (ตรวจด้วย Luhn) | `4111 1111 1111 1111` | `cards` |
| API key และโทเค็น | คำนำหน้าที่รู้จัก เช่น `sk-` หรือ `ghp_` สตริงสุ่มยาว ๆ | `keys` |
| ที่อยู่ IP | `203.0.113.42`, `2001:db8::1` | `ips` |
| คำของคุณเอง ไม่สนตัวพิมพ์เล็กใหญ่ | ชื่อรหัส เช่น `Project Atlas` ชื่อคน | `customWords` |

- ใช้กับ `@improve`, `@translate`, `@question` คำสั่งพรอมต์และปลั๊กอินพรอมต์ของคุณ และการปรับแต่งผลลัพธ์ของคำสั่งเหล่านั้น (ตัวยึดตำแหน่งเดียวกัน) กับผู้ให้บริการทุกราย รวมถึง AllInOneIME Cloud และ Apple Intelligence รายการในรายการศัพท์เฉพาะที่มีค่าที่ต้องซ่อนจะไม่ถูกส่ง
- รู้จักค่าที่มีรูปแบบ แต่รู้จักชื่อหรือที่อยู่ไม่ได้ จึงควรเพิ่มสิ่งเหล่านั้นเป็นคำของคุณเอง `@agent` ปลั๊กอินที่ดึงข้อมูลจากเว็บไซต์ (`@stock`) หรือเปิดเว็บไซต์ (`@x`) และส่วนขยายแบบสคริปต์จะส่งข้อความตามที่พิมพ์ ดูเพิ่มเติมที่ความเป็นส่วนตัว
- ในไฟล์ตั้งค่า: `"redaction": {"enabled": true, "customWords": ["Project Atlas"]}`

การตั้งค่าทั้งหมดเก็บไว้ใน `~/.config/allinoneime/config.json` หลังจากเปลี่ยนแปลง การแปลครั้งถัดไปจะใช้การตั้งค่าใหม่ โดยไม่ต้องรีสตาร์ต คีย์ที่เพิ่มเข้ามาใหม่:

| คีย์ | หน้าที่ | ค่าเริ่มต้น |
|---|---|---|
| `inputLanguages` | ภาษาที่ป้อน หนึ่งถึงห้าภาษา ภาษาแรกคือค่าเริ่มต้น: `"en"` อังกฤษ, `"zh"` จีน (พินอิน), `"fr"` ฝรั่งเศส, `"ko"` เกาหลี, `"hi"` ฮินดี เช่น `["en", "zh"]`, `["fr", "en", "ko"]` ภาษาจีน เกาหลี และฮินดีใช้ได้เมื่อติดตั้งแพ็กแล้ว | `["en"]` (การติดตั้งใหม่) |
| `keyboardLayouts` | รูปแบบแป้นพิมพ์ที่ภาษาที่ป้อนใช้ ระบุตามรหัสภาษา (ขณะนี้มีเฉพาะภาษาฝรั่งเศส): `{"fr": "com.apple.keylayout.French-PC"}` | ฝรั่งเศส: `com.apple.keylayout.French` (AZERTY) |
| `outputLanguages` | ภาษาที่ `@translate` แปลไป ตามลำดับ: `["es", "fr", "de"]`, … | `["en"]` |

| `uiLanguage` | ภาษาของอินเทอร์เฟซ (หน้าต่างการตั้งค่า คำแนะนำในแผงตัวเลือก เมนู): `"zh"`, `"en"` | `null` (ตามระบบ) |

## ความเป็นส่วนตัว

- การพิมพ์ (ภาษาอังกฤษและพินอิน) และการคำนวณด้วยปลั๊กอิน `@calculator` ทำงานในเครื่องทั้งหมด เฉพาะเมื่อคุณกดปุ่มสั่งงานกับ `@improve`, `@translate` หรือ `@question` เท่านั้น ประโยคนั้นจึงจะถูกส่งไปยังผู้ให้บริการ AI ที่คุณเลือก (Bedrock ของคุณเอง หรือบริการที่คุณเพิ่มคีย์ไว้) เมื่อเลือก "Jargon" ไว้และตั้งค่ารายการศัพท์เฉพาะแล้ว รายการจะถูกส่งไปด้วย การปรับแต่งผลลัพธ์ (คำสั่งที่พิมพ์หลังผลลัพธ์ แล้ว ⇧⏎) จะส่งคำขอเดิมอีกครั้งพร้อมผลลัพธ์ที่แสดงอยู่และคำสั่งของคุณ ส่วนคำถามต่อเนื่อง (⇧⏎) จะส่งบทสนทนาจนถึงตอนนั้นไปด้วย
- `@config` และ `@doctor <question>` จะส่งข้อความไปยังโมเดลเมื่อคุณกด ⏎: ใช้ Apple Intelligence บน Mac เครื่องนี้ทุกครั้งที่ใช้ได้ (ไม่มีอะไรออกจาก Mac) ถ้าไม่ได้จะใช้ผู้ให้บริการของคุณ `@config` จะส่งประโยคของคุณ (คีย์ที่พิมพ์ไว้ในประโยคจะถูกตัดออกก่อน) พร้อมค่าปัจจุบันของการตั้งค่าที่คำสั่งนี้เปลี่ยนได้: ไม่มีคีย์ และไม่มีคำที่คุณซ่อนจาก AI (มีเพียงจำนวนคำ) และส่งชื่อ profile ของ AWS เฉพาะเมื่อประโยคเกี่ยวกับ AWS หรือ Bedrock `@doctor <question>` จะส่งคำถามของคุณพร้อมผลการตรวจที่ปิดบังแล้ว: ไม่มีพาธที่เลย `~` ไม่มีคีย์ และบรรทัดในบันทึกจะเป็นวลีที่กำหนดไว้ตายตัว การซ่อนข้อมูลที่ละเอียดอ่อนมีผลกับทั้งสองคำสั่งเหมือนกับคำขออื่น ๆ การตรวจอย่างเดียว (`@doctor` ที่ไม่มีอะไรต่อท้าย) จะไม่ส่งอะไรนอกจากคำขอ Test Connection และส่งเฉพาะเมื่อผู้ให้บริการมีคีย์หรือข้อมูลรับรองให้ทดสอบ
- การคุยบทสนทนา `@question` ต่อที่อื่น (⌘1 … หลังรอบสุดท้าย หรือ ⌘⏎) จะส่งบทสนทนาพร้อมสิ่งที่คุณพิมพ์ไปยังบริการที่คุณเลือก: coding agent บน Mac เครื่องนี้ (Claude Code, Gemini CLI, Kiro CLI หรือของคุณเอง ซึ่งแต่ละตัวใช้บัญชีและบริการของตัวเอง), claude.ai, chatgpt.com หรือ gemini.google.com ผ่านที่อยู่เว็บหรือผ่านคลิปบอร์ด บทสนทนาจะถูกส่งไปตามที่คุณเห็น: ค่าที่ถูกซ่อนจากคำขอที่ส่งให้ AI (ดูด้านล่าง) จะอยู่ในนั้นตามจริง เพราะคุณเป็นผู้เลือกส่งไปที่นั่นเอง ไม่มีอะไรถูกส่งไปไหนจนกว่าคุณจะเลือก "Copy the conversation" เพียงแค่ใส่บทสนทนาไว้ในคลิปบอร์ด
- เมื่อใช้ AllInOneIME Cloud ประโยคจะผ่านเซิร์ฟเวอร์ของผู้พัฒนาไปยังผู้ให้บริการโมเดล (ปัจจุบันผ่าน OpenRouter): เซิร์ฟเวอร์เก็บเพียงจำนวนนับ ไม่เคยเก็บข้อความ การลงชื่อเข้าใช้จะเก็บเพียงที่อยู่อีเมลของคุณ
- ซ่อนข้อมูลที่ละเอียดอ่อน (Settings → AI Provider → Privacy ปิดอยู่โดยค่าเริ่มต้น): ก่อนคำขอใดจะถูกส่งออกไป (`@improve`, `@translate`, `@question` คำสั่งพรอมต์และปลั๊กอินพรอมต์ของคุณ กับผู้ให้บริการทุกรายรวมถึง AllInOneIME Cloud) ที่อยู่อีเมล หมายเลขโทรศัพท์ หมายเลขบัตรชำระเงิน (ตรวจด้วย Luhn) API key และโทเค็น (`sk-`, `sk-ant-`, `AKIA…`, `ghp_`, `xox…` และสตริงสุ่มยาว ๆ) ที่อยู่ IP และคำของคุณเอง (ชื่อรหัส ชื่อคน) จะถูกแทนที่บน Mac ด้วยตัวยึดตำแหน่ง เช่น `[EMAIL_1]`, `[PHONE_1]`, `[ITEM_1]` ค่าเดียวกันได้ตัวยึดตำแหน่งเดียวกัน ผลลัพธ์จากโมเดลจะได้ค่าจริงกลับคืนก่อนแสดงหรือแทรก และแผงจะแสดง "2 items hidden from the AI" ผลลัพธ์ที่โมเดลเปลี่ยนตัวยึดตำแหน่งจนจำไม่ได้จะแสดงตามที่เขียน พร้อมเครื่องหมาย "⚠ placeholder changed" รายการในรายการศัพท์เฉพาะที่มีค่าที่ถูกซ่อนจะไม่ถูกส่ง แต่ละประเภทปิดได้ รูปแบบเต็มความกว้าง (`zhang＠example.com`, `１３８…`) ก็พบได้ และค่าหรือวลีอาจถูกแบ่งด้วยการขึ้นบรรทัดใหม่ รู้จักค่าที่มีรูปแบบ เช่น อีเมล หมายเลข และคีย์ แต่รู้จักชื่อหรือที่อยู่ไม่ได้ (เพิ่มเป็นคำของคุณเอง) และรู้จักตัวอักษรหน้าตาคล้ายกันจากตัวอักษรระบบอื่นไม่ได้ ใช้กับคำขอที่ส่งไปยังบริการ AI ของคุณ `@agent` ปลั๊กอินที่ดึงข้อมูลจากเว็บไซต์ (`@stock`) หรือเปิดเว็บไซต์ (`@x`) และส่วนขยายแบบสคริปต์จะส่งข้อความตามที่พิมพ์ ในไฟล์ตั้งค่า: `redaction` (`enabled`, `emails`, `phones`, `cards`, `keys`, `ips`, `customWords`)
- เสียงจะถูกบันทึกเฉพาะขณะที่คุณกด ⌥ ขวาค้างไว้ และถูกรู้จำบน Mac ข้อความที่รู้จำได้จะถูกส่งเฉพาะในคำสั่งข้างต้น เมื่อคุณกดปุ่มสั่งงาน
- วิธีป้อนข้อมูลจะอ่านข้อความในคลิปบอร์ดหนึ่งครั้ง เฉพาะเมื่อคุณกด ⌃V หรือ ⌘V ในคำสั่ง เนื้อหาที่โปรแกรมจัดการรหัสผ่านทำเครื่องหมายว่าซ่อนไว้จะไม่ถูกอ่าน ข้อความจะแสดงในคำสั่งก่อน และเช่นเดิม จะถูกส่งเฉพาะเมื่อคุณกดปุ่มสั่งงาน macOS เวอร์ชันล่าสุดจะถามว่าอนุญาตให้ AllInOneIME อ่านคลิปบอร์ดหรือไม่: ให้อนุญาต หากไม่ต้องการให้ถามทุกครั้ง ให้ตั้งสิทธิ์การวางของ AllInOneIME เป็นอนุญาตเสมอใน System Settings → Privacy & Security
- ในช่องรหัสผ่าน macOS จะสลับไปใช้แป้นพิมพ์ของตัวเอง (U.S. หรือ ABC) และสลับกลับเมื่อคุณออกจากช่องนั้น เมื่อใดก็ตามที่แอปที่คุณพิมพ์อยู่เปิดการป้อนข้อมูลแบบปลอดภัย AllInOneIME จะไม่ประกอบข้อความและไม่สามารถบันทึกเสียงได้: ปุ่มจะเข้าไปตามที่พิมพ์ และขณะที่ระบบอยู่ในการป้อนข้อมูลแบบปลอดภัย (ช่องรหัสผ่าน Secure Keyboard Entry ของ Terminal ฯลฯ) จะไม่มีอะไรถูกส่งไปยัง AI
- `@note` และ `@reminder` ไม่ผ่าน AI: AllInOneIME ส่งข้อความให้เฉพาะ Notes และ Reminders บน Mac เครื่องนี้ และอ่านเวลาของการเตือนความจำบน Mac เช่นกัน (แอปเหล่านั้นจะซิงค์ไปยังอุปกรณ์อื่นของคุณหรือไม่ขึ้นอยู่กับบัญชีของแอป เช่น iCloud) จึงใช้ได้ระหว่างการป้อนข้อมูลแบบปลอดภัยด้วย
- `@reportissue` (และ "Report an Issue…") ไม่ส่งอะไรเอง: จะเปิดหน้าสร้าง issue ใหม่ของ GitHub ในเบราว์เซอร์ พร้อมหัวข้อที่คุณพิมพ์ และเวอร์ชัน ภาษา ประเภทผู้ให้บริการ และจำนวนที่ระบุไว้ข้างต้น ซึ่งแสดงในแผงตัวเลือกก่อน ไม่มีอะไรไปถึง GitHub จนกว่าคุณจะคลิก Submit ที่นั่น
- `@open` ค้นหาบน Mac เครื่องนี้เท่านั้น และจะจำสิ่งที่คุณเปิดด้วยคำสั่งนี้ (200 รายการล่าสุด) ไว้ในค่ากำหนดของวิธีป้อนข้อมูลเอง (ไม่ใช่ใน config.json) เพื่อแสดงรายการเหล่านั้นก่อน
- สำหรับ "Add App…" ใน Settings → Apps วิธีป้อนข้อมูลจะเก็บ bundle ID ของ 12 แอปล่าสุดที่คุณพิมพ์ ไว้ในค่ากำหนดของตัวเอง ไม่เก็บอย่างอื่นเกี่ยวกับแอปเหล่านั้น
- `@question` จดจำคำถามล่าสุด 5 ข้อของคุณพร้อมคำตอบและเวลาที่ถาม เฉพาะบน Mac เครื่องนี้ ใน `~/Library/Application Support/AllInOneIME/recent-questions.json` (อ่านได้เฉพาะบัญชีผู้ใช้ของคุณ) เพื่อแสดงใต้ `@question` คำตอบที่บันทึกไว้จะแสดงจากที่นั่นโดยไม่ต้องออนไลน์ ไม่เก็บอะไรระหว่างการป้อนข้อมูลแบบปลอดภัย และไม่เก็บคำถามเกี่ยวกับข้อความที่เลือกเลย (คำตอบของคำถามเหล่านั้นเกี่ยวกับส่วนที่เลือก ซึ่งจะไปอยู่บนดิสก์) การปิด "Remember recent questions" ใน Settings → General จะลบคำถามเหล่านั้นด้วย ส่วนการปิดผ่าน `@config` (`rememberQuestions` ในไฟล์ตั้งค่า) จะเก็บไว้ เพื่อให้เลิกทำได้ตรงทุกอย่าง "Clear" ใช้ลบคำถามเหล่านั้น
- เพื่อแสดงรายการโน้ตของคุณ แผงในแถบเมนูจะเก็บ id และบรรทัดแรก (ไม่เกิน 80 อักขระ) ของโน้ต 30 รายการล่าสุดที่บันทึกด้วย `@note` ไว้ในค่ากำหนดของวิธีป้อนข้อมูลเอง แม้ในขณะที่ปิดแผงอยู่
- `@py` และ `@js` รันเฉพาะเมื่อคุณกดปุ่มสั่งงาน และรันเฉพาะโค้ดที่คุณพิมพ์หรือวางเอง: คำตอบของ AI และผลลัพธ์ของคำสั่งอื่นจะไม่ถูกรันเป็นโค้ด `@py` ใช้ `python3` ของ Mac ซึ่งอ่านและเขียนไฟล์และออนไลน์ได้เหมือนใน Terminal ส่วน `@js` รันในโพรเซสแยกที่ไม่สามารถอ่านไฟล์ เข้าถึงเครือข่าย หรือรันโปรแกรมอื่นได้ ทั้งสองคำสั่งไม่รันระหว่างการป้อนข้อมูลแบบปลอดภัย
- การตรวจหาอัปเดต: วันละครั้ง (เว้นแต่ปิด "Check for updates automatically") AllInOneIME จะดาวน์โหลด https://allinoneime.com/update.json และลายเซ็นของไฟล์ คำขอไม่มีตัวระบุใด ๆ และไม่มีสิ่งที่คุณพิมพ์ อัปเดตจะถูกดาวน์โหลดจากรีลีสบน GitHub เฉพาะเมื่อคุณคลิก Update
- แหล่งที่มาของส่วนขยาย: git จะรันบน Mac ของคุณในนามของคุณ เฉพาะกับแหล่งที่คุณเพิ่มไว้: fetch วันละครั้งสำหรับแหล่งที่ตรวจเอง (ไม่มีสำหรับแหล่งที่ตรึงไว้) และเมื่อคุณคลิก Check Now, Update หรือ Re-clone git จะติดต่อเฉพาะโฮสต์ของรีโพสิทอรี โดยลงชื่อเข้าด้วยการตั้งค่า git และ SSH ของคุณเอง ไม่มีสิ่งที่คุณพิมพ์ถูกส่งไปด้วย
- บันทึก (log) ไม่เก็บสิ่งที่คุณพิมพ์ สำหรับวิธีป้อนข้อมูลจากภายนอกทุกตัว macOS จะเตือนว่า "The developer can access anything you type with this input source" (ผู้พัฒนาสามารถเข้าถึงทุกสิ่งที่คุณพิมพ์ด้วยแหล่งป้อนข้อมูลนี้) ซึ่งเป็นคำเตือนทั่วไปของระบบ

## การพัฒนา

```sh
make test         # unit tests, plus tests that run the real Rime engine
make pack         # the Chinese language pack: build/packs/zh-pinyin-<version>.tar.xz, its sha256, its packs.json entry
make packs        # all the language packs: Chinese, and Korean and Hindi from LanguagePacks/ (ko-hangul, hi-phonetic)
make selftest     # drives the input method through a simulated text field: real Bedrock calls, plus on-device recognition tested with synthesized speech
make realtest     # types into a real app's text field (needs the screen unlocked; takes over the foreground for about 1 minute)
make screenshots  # regenerates the screenshots in docs/
make cli && .build/release/allinoneime-cli --styles concise,jargon "this is a blocker bug your team need fix it asap"   # try polishing and rewrites in the terminal
make icon         # regenerates the app icon and the menu bar icon from Resources/AppIcon.png
make dmg          # the release installer, build/AllInOneIME-<version>.dmg (universal; signed if there's a Developer ID certificate, optionally notarized), and the in-app update, build/AllInOneIME-<version>-update.zip
make update-test  # the in-app updater end to end: a temporary install, a test server on 127.0.0.1, a test key (never the installed app)
```

`make selftest` และ `make realtest` ไม่ขึ้นกับการตั้งค่าของคุณ การทดสอบตัวเองใช้ไฟล์ตั้งค่าของตัวเอง (Amazon Bedrock โดยใช้ AWS profile และ region จากของคุณ ส่วนอื่นทั้งหมดเป็นค่าเริ่มต้น) การทดสอบในแอปจริงจะตั้งผู้ให้บริการเป็น Bedrock ระหว่างที่รัน แล้วคืนค่าของคุณ สิ่งที่ตรวจไม่ได้ในตอนนั้นจะถูกข้าม ไม่ถือว่าล้มเหลว: การตรวจ Bedrock แบบสดเมื่อไม่มีข้อมูลรับรองสำหรับ profile นั้น และทุกอย่างที่พิมพ์ขณะเปิดการป้อนข้อมูลแบบปลอดภัย (หน้าจอล็อกอยู่ ช่องรหัสผ่าน) บรรทัดสุดท้ายนับการตรวจที่ผ่าน ล้มเหลว และถูกข้าม มีเพียงความล้มเหลวที่ทำให้การรันล้มเหลว และการรันที่มีการข้ามจะจบด้วย INCOMPLETE หรือ SKIPPED เมื่อไม่มีอะไรที่ต้องพิมพ์ได้รันเลย (BLOCKED: การทดสอบในแอปจริงเริ่มขณะหน้าจอล็อกอยู่) ไม่มีทางจบด้วย PASSED

โครงสร้างโค้ด:

- `Sources/AllInOneIMECore`: ไคลเอนต์ Bedrock, SigV4, พรอมต์, state machine การป้อนข้อมูลสองระดับ (รวมถึงคำสั่ง @ และท่าทางการป้อนด้วยเสียง) ไม่ขึ้นกับ AppKit
- `Sources/AllInOneIMERime`: ตัวห่อ (wrapper) ของ librime
- `Sources/AllInOneIME`: วิธีป้อนข้อมูล InputMethodKit แผงตัวเลือก หน้าต่างการตั้งค่า การรู้จำเสียง
- `Sources/AllInOneIMESettings`: ตัวเปิด "AllInOneIME Settings"
- `Sources/AllInOneIMEInstaller`: "Install AllInOneIME" บนดิสก์อิมเมจ: ติดตั้ง อัปเดต และถอนการติดตั้ง

แพ็กภาษามีคลังของตัวเอง แยกจากปลั๊กอิน: repository [MicroZ-LLC/AllInOneIME-languages](https://github.com/MicroZ-LLC/AllInOneIME-languages) ให้บริการที่ https://languages.allinoneime.com/ และลงนามด้วยคีย์ของตัวเอง `make pack` สร้างไฟล์บีบอัด ซึ่งเผยแพร่เป็น release asset ที่นั่น (release `zh-pinyin-<version>`, `ko-hangul-<version>`, `hi-phonetic-<version>`) และ `swift Scripts/build-packs-index.swift <languages repo> build/packs/*.tar.xz.json` จะเขียน `packs.json` ที่นั่น และลงนามเป็น `packs.json.sig` ด้วยคีย์ของแพ็กภาษาจาก keychain (`allinoneime-languages-signing`) แอปจะอ่าน https://languages.allinoneime.com/packs.json ตรวจสอบลายเซ็น แล้วจึงตรวจขนาดและ SHA-256 ของไฟล์บีบอัด หากต้องการทดลองแพ็กจากเซิร์ฟเวอร์ในเครื่อง: `--test-key` ลงนามด้วยคีย์ทดสอบ และ `AllInOneIME --install-pack zh-pinyin --library http://127.0.0.1:8765/ --key <its public key> --packs-dir <folder>`

การออกเวอร์ชัน (ตัวอัปเดตในแอปอ่าน https://allinoneime.com/update.json ซึ่งลงนามด้วยคีย์เฉพาะของรีลีส):

1. เพิ่มเลขเวอร์ชัน (`AppVersion.swift` และ Info.plist ทั้งสามไฟล์ `AppVersionTests` ตรวจว่าตรงกัน) และอัปเดตบันทึกการเปลี่ยนแปลง
2. `make dmg NOTARY_PROFILE=<profile>`: `build/AllInOneIME-<version>.dmg` พร้อม `.sha256` ของมัน และ `build/AllInOneIME-<version>-update.zip` (แอปทั้งสอง แบบเดียวกับที่ตัวติดตั้งในดิสก์อิมเมจมี) แอปและอิมเมจลงนามด้วยใบรับรอง Developer ID Application ใน keychain และอิมเมจได้รับการรับรองด้วยโปรไฟล์ keychain ของ `xcrun notarytool` นั้นแล้ว staple
3. อัปโหลดทั้งสองไฟล์ไปยังรีลีส `v<version>` บน GitHub แล้วเผยแพร่
4. `make update-manifest UPDATE_SUMMARY_EN="…" UPDATE_SUMMARY_ZH="…"` (อย่างละหนึ่งถึงสองประโยค): เขียน `site/public/update.json` (เวอร์ชัน บิลด์ และ macOS ขั้นต่ำที่อ่านจากแอป ที่อยู่ ขนาด และ SHA-256 ของไฟล์ ที่อยู่ของบันทึกประจำรีลีส และสรุป) แล้วลงนามเป็น `update.json.sig` ด้วยคีย์จาก keychain สำหรับเข้าสู่ระบบ (`allinoneime-releases-signing` macOS อาจขอให้อนุญาตการเข้าถึง) commit ทั้งสองไฟล์
5. ปรับใช้เว็บไซต์ (`cd site && npx wrangler@4 deploy`) เฉพาะเมื่อไฟล์ของรีลีสดาวน์โหลดได้แล้ว: แอปตรวจวันละครั้ง และ `AllInOneIME --check-update` แสดงสิ่งที่แอปเห็น

แอปตรวจลายเซ็นของ manifest ด้วยกุญแจสาธารณะที่มีอยู่ในแอปก่อนอ่าน ไม่ติดตั้งเวอร์ชันที่ไม่ใหม่กว่าเด็ดขาด ดาวน์โหลดผ่าน https จาก allinoneime.com หรือไฟล์รีลีสบน GitHub ของรีโพสิทอรีเท่านั้น และติดตั้งไฟล์บีบอัดเฉพาะเมื่อขนาดและ SHA-256 ตรงกับ manifest bundle ID เวอร์ชัน และลายเซ็นโค้ดของแอปทั้งสองผ่านการตรวจ และวิธีป้อนข้อมูลใหม่เริ่มทำงานได้ จากนั้นวิธีป้อนข้อมูลจะส่งต่องานให้ไฟล์ปฏิบัติการของตัวเองในฐานะตัวช่วย (`--apply-update`) ซึ่งจะรอให้วิธีป้อนข้อมูลปิด สลับแอปแบบเดียวกับตัวติดตั้ง (ย้ายของเก่าไว้ข้าง ๆ และนำกลับถ้ามีอะไรล้มเหลว) แล้วลงทะเบียนตัวใหม่ หากต้องการลองกับเซิร์ฟเวอร์ในเครื่อง: `make update-test` หรือ `--test-key` กับ `Scripts/build-update-manifest.swift` และ `AllInOneIME --install-update --manifest-url http://127.0.0.1:<port>/update.json --key <its public key> --target-dir <folder>`

Bundle ID ยังคงเป็น `com.aipinyin.inputmethod.AIPinyin`: macOS ใช้ค่านี้เพื่อจดจำแหล่งป้อนข้อมูลที่เพิ่มไว้และสิทธิ์การใช้ไมโครโฟน การเปลี่ยนค่านี้จึงหมายถึงต้องเพิ่มวิธีป้อนข้อมูลและให้สิทธิ์ใหม่อีกครั้ง
