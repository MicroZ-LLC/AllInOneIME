# AllInOneIME

### ИИ-команды в любом текстовом поле на вашем Mac.

Наберите `@improve`, `@translate` или `@question` в любом приложении, нажмите ⏎ и выберите результат.<br>
Не нужно копировать текст в окно чата и переключаться между приложениями. Ваш собственный поставщик ИИ, ваши собственные ключи.

> [!NOTE]
> AllInOneIME пока не заверен (notarized) Apple: при первом запуске разрешите его в "System Settings → Privacy & Security → Open Anyway" (Системные настройки → Конфиденциальность и безопасность → Всё равно открыть). Скачивайте его только из [GitHub Releases](https://github.com/MicroZ-LLC/AllInOneIME/releases) или с [allinoneime.com](https://allinoneime.com).

Метод ввода для macOS с ИИ-командами в любом текстовом поле. Начните предложение с `@` и, закончив, нажмите ⏎: `@improve` шлифует написанное и предлагает несколько вариантов переписывания, `@translate` переводит на выбранные вами языки, `@question` задаёт вопрос, `@claude` передаёт задачу Claude Code, а `@open` находит файлы и приложения или открывает веб-адрес. Можно также удерживать правую ⌥ и говорить. Без `@` нажатия клавиш, как обычно, уходят в приложение. Он также печатает на китайском (пиньинь, на основе Rime и rime-ice), французском, корейском (хангыль) и хинди (деванагари из латинских букв) и запускает ваши собственные скрипты как @-команды.

## Как пользоваться

Без `@` метод ввода не мешает: в английском режиме буквы вводятся напрямую, а ⏎ — это Return; ничего не уходит в сеть. После новой установки доступен только английский; чтобы печатать также на китайском (пиньинь), французском, корейском или хинди, добавьте язык в настройках (см. [Ввод и перевод](#ввод-и-перевод)).

| Клавиша | Что делает |
|---|---|
| Ввод пиньиня, пробел / цифры | В китайском режиме: выбор слов, как в любом методе ввода пиньинем |
| `@` (в начале предложения) | Открывает список команд: сначала те, что чаще всего использовались в последнее время, по 5 за раз, прокрутка — ↑↓, колесом мыши или трекпадом; или наберите буквы, чтобы найти команду (сначала имена, которые с них начинаются, затем те, что их содержат). Выбор — ⏎, Tab, пробел или цифра |
| ⏎ | Выполняет команду. Работает, даже если пиньинь ещё не выбран: сначала он выбирается, как по пробелу |
| Пробел, ⏎ / цифры | Когда результаты появились: вставить выделенный / с этим номером; 0 — исходный текст |
| ⌘C | Копирует выделенный результат (для `@open` — путь); панель кандидатов остаётся открытой |
| ⌃V | В команде (например, после `@improve `): добавляет текст из буфера обмена после набранного, вместо того чтобы вставлять его в приложение. Несколько строк сливаются в одну, до 2000 символов за раз (`@note` сохраняет переносы строк и принимает до 20000). Работает в любом приложении; без команды клавиша, как обычно, уходит в приложение |
| ⌘V | Как ⌃V, но некоторые приложения обрабатывают ⌘V сами (терминалы, такие как Ghostty, iTerm2 и Terminal, а также Notes) и, как обычно, вставляют текст в приложение; там используйте ⌃V |
| Esc, ⌫ | Возврат к предложению для дальнейшего редактирования; набор просто продолжает его |
| Короткое нажатие Shift | Если языков ввода несколько: следующий по порядку (английский → китайский → французский → …, затем снова первый) |
| Удерживать правую ⌥ | Говорите, отпустите, чтобы закончить. На языке, на котором вы печатаете (английский, китайский, французский, корейский или хинди). В команде текст добавляется после неё; иначе вставляется сразу |

## Команды @ (бета)

| Команда | Что делает |
|---|---|
| `@improve` | Шлифовка: 1–3 — три варианта на языке самого предложения, с 4 и дальше — стили переписывания (добавляются и упорядочиваются в настройках), 0 — исходный текст. Без перевода; если включено "@improve also translates" (@improve также переводит), работает как `@translate @improve` |
| `@translate` | Переводит на добавленные вами языки (настройки → "Translate", порядок меняется перетаскиванием), по строке на каждый, три варианта, если язык один; язык самого предложения пропускается. `@translate @improve` вместе переводят и переписывают за один запрос |
| `@question` | Задать вопрос; ответ появляется среди кандидатов, ⏎ или пробел вставляет его, ⌘C копирует |
| `@claude` | Передаёт задачу Claude Code: по умолчанию в фоне, с уведомлением по завершении (нажмите на него, чтобы открыть сессию в Terminal и продолжить), или смотрите `@tasks`. Используется ваш собственный Claude Code (команда `claude`) с его входом в аккаунт и настройками. Выключите "@claude runs in the background" (@claude работает в фоне) в настройках, чтобы он, как раньше, открывался в Terminal. Когда он впервые открывает Terminal, macOS спрашивает, может ли AllInOneIME управлять Terminal: нажмите OK |
| `@tasks` | Показывает фоновые задачи Claude (в работе / готово / ждёт вас) с их последними ответами; ⏎ открывает задачу в Terminal, ⌘C копирует ответ |
| `@settings` | Сразу открывает окно настроек (достаточно выбрать команду) |
| `@open` | По мере ввода показывает подходящие файлы, папки и приложения (Spotlight). Можно указать несколько ключевых слов через пробел: каждое должно быть в пути, хотя бы одно — в имени (имя стандартной папки относится и к её содержимому: `downloads pdf` находит PDF-файлы в «Загрузках»). Приложения и стандартные папки находятся и по китайским названиям, а китайский интерфейс так их и показывает. Первым идёт то, что вы открывали через `@open`, затем приложения и эти папки, затем недавно использованные или изменённые файлы; если по именам найдено не больше двух файлов и ни одного такого приложения или папки, файлы в вашей домашней папке ищутся ещё и по содержимому, такие строки помечены "content"; если больше ничего нет, ⏎ показывает их списком для выбора, а не открывает первый. С веб-адресом (`github.com`, `localhost:3000`, `https://…`) первая строка — "open in the browser" (открыть в браузере), и поиск по содержимому не выполняется; файл именно с таким именем (скажем, `MANIFEST.in`) идёт первым. Текст, начинающийся с `~/` или `/`, — это путь: Tab дополняет его и заходит в папки; ⏎ открывает, ⌘C копирует путь |
| `@note` | Сохраняет текст в приложение Notes (Заметки), в папку AllInOneIME (создаётся, если её нет); ничего не вставляется. Вставленный текст сохраняет переносы строк, до 20000 символов |
| `@reminder` | Добавляет напоминание в приложение Reminders (Напоминания), в список AllInOneIME. Укажите время в тексте; оно распознаётся на Mac, а строка показывает, что распознано: ⏎ или пробел добавляет, Esc возвращает к редактированию. Если указано время, в этот момент сработает сигнал; если только дата — напоминание на весь день |
| `@calculate` | Считает на этом Mac; результат появляется среди кандидатов, ⏎ или пробел вставляет его: `@calculate 23*17` → `391`. Работает и внутри предложения: `@reply the total is @calculate 23*17 dollars` |
| `@py` | Выполняет строку Python (`python3` вашего Mac) и вставляет результат: значение последнего выражения в коде, например `@py 2**100`, `@py import math; math.sqrt(2)`, а иначе — то, что было выведено. Не предлагается без `python3` (он есть в инструментах командной строки Xcode) |
| `@js` | Выполняет строку JavaScript и вставляет то же самое: значение последнего выражения или то, что вывел `console.log`, например `@js [1, 2, 3].map(x => x * 2)`. Используется встроенный в macOS JavaScriptCore, поэтому ничего устанавливать не нужно; он не может читать файлы, выходить в сеть или запускать другие программы |
| `@imessage` | Отправляет iMessage: введите имя, номер телефона или e-mail (китайское имя — также пиньинем, полностью или по начальным буквам) и выберите получателя в панели кандидатов (сначала те, кому вы недавно писали; полный номер или адрес тоже подойдёт), затем напишите сообщение (команды внутри него, например `@stock AAPL`, выполняются первыми). ⏎ показывает в панели "Send to Alex (…): message", повторное ⏎ отправляет, Esc возвращает к редактированию; в текстовое поле ничего не вводится. В первый раз macOS спрашивает, может ли AllInOneIME получить доступ к Contacts (Контакты) и управлять Messages (Сообщения): нажмите OK в обоих случаях |

Пример: `@q` ⏎, наберите `what is quantum computing`, ⏎. `@note books to read: The Three-Body Problem` ⏎ сохраняет заметку. `@reminder call Bob tomorrow at 3pm` ⏎, проверьте распознанное время, затем снова ⏎, чтобы добавить напоминание. После выбора команды можно также удерживать правую ⌥ и говорить. В китайском режиме `@open` и `@calculate` на время переключаются на английские буквы и возвращаются к китайскому, когда вы закончите.

Код для `@py` и `@js` набирается английскими буквами, а полноширинная пунктуация (из китайского режима) превращается в ASCII; пишите его в одну строку, разделяя инструкции `;`. Он выполняется в отдельном процессе и останавливается через 10 секунд или в любой момент по Esc; при ошибке показывается её первая строка, например `ZeroDivisionError: division by zero`. Многострочный вывод вставляется так, как был напечатан; в терминал он попадает одной строкой (терминал выполняет каждую полученную строку). Терминал внутри редактора (VS Code, Cursor, JetBrains) невозможно отличить от самого редактора, поэтому там многострочный вывод любой команды вставляется как есть. Обе команды работают и внутри предложения другой команды: `@reply the answer is @py 2**100`; код с пробелами заключайте в кавычки: `@question explain @py "sum(x * x for x in range(10))"`. Наоборот — нет: код `@py` и `@js` всегда выполняется точно так, как вы его набрали, и `@commands` внутри него заранее не выполняются.

![Набор @ открывает список команд; @question и вопрос, затем ⏎ — и ответ](../en/commands.png)

![@open находит приложения по мере ввода; если текст начинается с /, это путь: папка показывается списком, Tab дополняет](../en/open.png)

Если после `@` нет команды, как в `@john`, `@` вставляется как обычно, поэтому упоминания людей через @ в чатах по-прежнему работают. `@question`, `@improve` и `@translate` отправляют текст в ваш собственный Bedrock, только когда вы нажимаете клавишу действия; `@open` ищет только на этом Mac; `@note` и `@reminder` передают текст только в Notes и Reminders на этом Mac; `@claude` использует Claude Code, установленный на вашем Mac (команда `claude`), и его собственный аккаунт и, как обычно, спрашивает вас, прежде чем менять файлы или выполнять команды. Если Claude Code не установлен, `@claude` не предлагается. `@imessage` читает Contacts только на этом Mac (имена, номера телефонов, адреса e-mail), никогда не обращается к ИИ, а сообщение отправляет Messages; без приложения Messages команда не предлагается.

`@calculate` работает на этом Mac без сети: `+ - * /` (а также `× ÷`), `^` или `**` для степеней, скобки, проценты (`50%` — это 0.5, `200*5%` — 10; как на калькуляторе, прибавляемый или вычитаемый процент берётся от того, что стоит перед ним: `100+10%` — 110, `100-10%` — 90), функции `sqrt abs round floor ceil ln log exp sin cos tan min max pow` (`log` — по основанию 10, углы в радианах, `round(x, 2)` оставляет два знака после запятой) и константы `pi` (`π`) и `e`. Полноширинные цифры и знаки тоже работают. Арифметика точная, десятичная, поэтому `0.1+0.2` — это `0.3`; в результатах не более 15 значащих цифр, а целые числа длиной до 38 цифр выписываются полностью (`2^100` → `1267650600228229401496703205376`).

### Заметки и напоминания

`@note` создаёт новую заметку; её первая строка — заголовок. Скопировав текст, нажмите ⌃V после `@note ` (или ⌘V, вне терминалов) — он сохранится с переносами строк, которые в команде показаны как ↵. Если вы покинете текстовое поле (щёлкнете в другом месте, переключитесь в другое приложение) или нажмёте ⇧⏎ (вставить как набрано) до того, как заметка с переносами строк сохранится, она не будет введена в приложение (в терминале каждая строка выполнилась бы как команда): вместо этого текст попадёт в буфер обмена ("The note wasn't saved; its text is on the clipboard" — заметка не сохранена, её текст в буфере обмена). Однострочная заметка вставляется как набрана.

`@reminder` понимает время вроде `tomorrow at 3pm`, `in 2 hours`, `in 3 days at 3pm`, `on the 15th`, `this weekend`, `in 1 month`, `next month` (его 1-е число), `end of the year` (и время на китайском тоже). День и время могут стоять раздельно (`tomorrow call Bob at 5`); неделя начинается с понедельника. Время без am или pm (`at 5`) — ближайшее такое, но никогда не между полуночью и 6 утра; время, которое сегодня уже прошло, переносится на завтра, но ещё не закончившаяся часть дня (`this afternoon`, `tonight`) — это сегодня, на весь день; дата, которая в этом году уже прошла, относится к следующему году. Повторяющееся напоминание (`standup every Monday at 9`) добавляется один раз, на ближайший срок: слова остаются в заголовке, а строка сообщает "once only" (только один раз). Строка подтверждения показывает распознанное время, например "tomorrow 3:00 PM" (в соответствии с 12/24-часовым форматом Mac); если оно неверно, Esc возвращает к тексту. Если в тексте нет ни времени, ни даты, у напоминания их тоже нет ("no date").

`@stock` и подобные команды внутри этих двух не выполняются: текст сохраняется как написан (набор `@` там не открывает список команд). В первый раз macOS спрашивает, может ли AllInOneIME управлять Notes (`@note`) или получить доступ к Reminders (`@reminder`): разрешите. Если вы этого не сделали, разрешите AllInOneIME в "System Settings → Privacy & Security → Automation" (Системные настройки → Конфиденциальность и безопасность → Автоматизация) (Notes) или → "Reminders". Если сохранить не удалось (скажем, нет разрешения), уведомление объясняет причину, а текст возвращается в команду, чтобы вы исправили и отправили его снова; когда сначала нужно что-то исправить (разрешение, аккаунт), текст также кладётся в буфер обмена (переход в System Settings забирает фокус у текстового поля). Если вы уже перешли в другое текстовое поле или набираете что-то другое, текст вместо этого попадает в буфер обмена ("Not saved; the text is on the clipboard.").

### Свои команды

В настройках, в разделе "Custom @ Commands" (свои @-команды), нажмите "Add Command…" (добавить команду): задайте имя и выберите, что команда делает (инструкция для ИИ, программа, программа в Terminal или веб-страница), или начните с примера. Ваши команды идут после встроенных; имена — только из английских букв и не могут совпадать с именем встроенной команды; команды работают со следующего предложения. Они хранятся в `customCommands` в файле конфигурации (`~/.config/allinoneime/config.json`), который можно редактировать и вручную:

```json
"customCommands": [
  { "name": "python", "type": "run", "argv": ["python3", "-c", "{input}"], "summary": "Run Python" },
  { "name": "bc", "type": "run", "argv": ["bc", "-l"], "stdin": "{input}\n" },
  { "name": "sh", "type": "terminal", "argv": ["zsh", "-c", "{input}"] },
  { "name": "reply", "type": "prompt", "prompt": "Write a short, polite reply to the user's message." },
  { "name": "google", "type": "link", "url": "https://www.google.com/search?q={input}" }
]
```

| `type` | Что делает |
|---|---|
| `prompt` | Отправляет текст ИИ с `prompt` в качестве инструкции; ответ появляется среди кандидатов, его можно вставить или скопировать (⌘C) |
| `run` | Запускает `argv` в фоне; то, что программа выводит, появляется среди кандидатов (несколько строк вставляются как напечатаны, в терминале — одной строкой). При ошибке показывается её последняя строка |
| `terminal` | Запускает `argv` в новом окне Terminal; ничего не вставляется |
| `link` | Подставляет текст в веб-адрес `url` и открывает его в браузере по умолчанию; ничего не вставляется |

- `{input}` заменяется тем, что вы написали после команды, и всегда остаётся внутри того единственного аргумента, где стоит: оболочка (shell) не участвует. Если нужна оболочка, укажите её явно, как в `sh` выше (`zsh -c`).
- `stdin`: что подаётся на стандартный ввод программы; `{input}` здесь тоже заменяется.
- `url` у `link` должен начинаться с `https://` и содержать `{input}` один раз, после `?` или `#`; текст кодируется (пробел — `%20`, перевод строки — `%0A`), не более 4000 символов.
- `run` и `terminal` по умолчанию вводят английские буквы (как `@open`; в китайском режиме китайский затем возвращается), а полноширинная пунктуация превращается в ASCII. Укажите `"ascii": false`, чтобы сохранить текст как набран.
- Программы запускаются в вашей домашней папке с PATH вашей оболочки входа (поэтому находятся программы, установленные через Homebrew, pyenv и nvm). `run` останавливает программу через 10 секунд (`timeoutSeconds`) или если она выводит слишком много; Esc останавливает её в любой момент.
- `summary` — описание в списке команд (необязательно).
- Если программа из `argv` не найдена (скажем, нет `python3`), команда не предлагается, и `@python …` вставляется как текст; когда программа установлена, команда появляется в следующем текстовом поле.

`run` и `terminal` выполняют код на вашем Mac: добавляйте только команды, которые написали сами и которым доверяете. Они тоже выполняются только по нажатию клавиши действия и никогда — во время безопасного ввода.

### Расширения-скрипты

Добавляйте свои @-команды в виде программ: скрипт на любом языке (bash, Python, Node, Swift, …) с несколькими строками метаданных в комментариях. Положите его в `~/.config/allinoneime/extensions` или в папку, которую добавите в "Settings → Custom Commands → Script Extensions". Raycast Script Commands работают как есть, а папки, где они уже лежат, находятся через Spotlight.

```bash
#!/bin/bash
# @allinoneime.schemaVersion 1
# @allinoneime.title Flights
# @allinoneime.argument1 {"type": "text", "placeholder": "from city"}
# @allinoneime.argument2 {"type": "text", "placeholder": "to city"}

echo "Flights from $1 to $2"
```

`flights.sh` — это `@flights`. Аргументы пишутся после команды через запятую: `@flights beijing, new york` запускает скрипт с `beijing` и `new york` в качестве `$1` и `$2` (лишние запятые остаются в последнем аргументе); если обязательный аргумент пуст, вместо запуска сообщается, чего не хватает. То, что скрипт выводит, используется так, как указано в его `output`:

| `output` | Что происходит |
|---|---|
| `insert` (по умолчанию) | Весь вывод и каждая строка отдельно — для вставки |
| `show` | Показывается в панели по мере вывода (прогресс); ничего не вставляется. Если покинуть поле, скрипт продолжает работать в фоне (до четырёх одновременно) |
| `list` | Список в формате JSON Script Filter из Alfred, перезапускается по мере ввода; выбор строки вставляет, открывает (веб-адрес, файл или папку; никогда то, что было бы запущено), копирует или запускает второй шаг |
| `silent` | Последняя строка вывода рядом с курсором; ничего не вставляется |

Команда также может не принимать ввод (`input none`: ⏎ на её имени запускает её), выполняться в фоне (`background`) и уведомлять вас о завершении (тем временем панель в строке меню показывает её в списке), показывать `status` рядом со своим именем в списке команд или сначала спрашивать подтверждение (`confirm`). Она запускается в своей папке с PATH вашей оболочки входа и переменными `ALLINONEIME_*`: язык интерфейса и язык ввода, приложение, в котором вы печатаете, текст. **Пакет** (bundle) — это папка с файлом `extension.json`, где перечислены его команды: у них общий код и общие параметры, которые показываются в настройках (пароли хранятся в связке ключей). Настройки показывают каждую команду с переключателем, а также пропущенные скрипты с указанием причины.

Режимы Raycast соответствуют так: `fullOutput` → `show`, `compact` и `silent` → `silent`, `inline` с `refreshTime` → статус. Полный протокол описан в [docs/extensions.md](../extensions.md); в [Examples/extensions](../../Examples/extensions) есть по одному примеру каждого вида. Расширения выполняют код на вашем Mac: используйте только те, которым доверяете. Они выполняются только тогда, когда вы их запускаете (статус или список — по мере ввода), никогда во время безопасного ввода и останавливаются, когда метод ввода завершает работу.

### Плагины

Плагины — это готовые `@`-команды для того, что нужно не всем, например `@stock AAPL 600519 700` для биржевых котировок. Установленные, они работают как любая команда; раздел "Plugins" в настройках показывает, что установлено и куда каждый плагин отправляет ваш текст, и позволяет удалять плагины. Плагины — это JavaScript, выполняемый в отдельном процессе: они могут обращаться только к заявленным ими сайтам (HTTPS) и не могут читать файлы или запускать другие программы. "Browse Library…" (обзор библиотеки) в разделе "Plugins" настроек устанавливает их из [библиотеки плагинов](https://github.com/MicroZ-LLC/AllInOneIME-plugins): перед установкой показывается, к каким сайтам обращается плагин; индекс библиотеки подписан, и каждый файл должен ему соответствовать. Для более новой версии появляется кнопка "Update" (обновить); само по себе ничего не обновляется. Ваши собственные плагины лежат в `~/.config/allinoneime/plugins/` ("Open Plugins Folder"): это локальные плагины, библиотека их никогда не перезаписывает. Плагины-«ссылки» не выполняют код: они подставляют текст в веб-адрес и открывают его в браузере, как `@x nice weather today`, который открывает редактор постов X с уже заполненным текстом; публиковать или нет — решаете вы на странице. В библиотеке их четыре (`@x`, `@threads`, `@bsky`, `@weibo`). `@xe` конвертирует валюты: `@xe 100 USD CNY`, `@xe 1000 JPY EUR`, одна строка с датой курса (курсы от ExchangeRate-API). Как написать свой: [docs/plugins.md](../plugins.md).

Команды, которые что-то получают (плагины и программы), работают и внутри предложения: `@reply tell her @stock AAPL is up today`. Сначала выполняются внутренние, их вывод встаёт на их место, а внешняя команда работает с результатом. Аргумент — это слово после команды плюс идущие сразу за ним коды в верхнем регистре или числа (`@stock AAPL TSLA`, `@stock 600519 700`); слово в нижнем регистре завершает его (`@stock SNDK is good to buy` ищет SNDK). Кавычки задают его точно: `@stock "aapl tsla"`. `@calculate` тоже работает внутри предложения; его аргумент — всё выражение после него, включая пробелы, до следующего текста: `@reply the total is @calculate 23 * 17 dollars`. Внутри `@claude` и терминальных команд они не выполняются: те получают текст как написан (набор `@` там не открывает список команд).

### Клавиша действия

По умолчанию ⏎; изменить её можно в "Action key" (клавиша действия) в настройках (`actionKey` в конфигурации): ⏎, "Tap ⌥" (короткое нажатие ⌥ с любой стороны: нажать и сразу отпустить; удержание правой ⌥ по-прежнему служит для голоса), ⌥Space или Space (нажмите пробел ещё раз после того, как слова выбраны; в английском режиме — дважды). Какой бы ни была клавиша действия, @-команды выполняются и по ⏎. Если ⌥Space уже назначено сочетанием для Alfred, Raycast и т. п., оно сначала достаётся им.

## Панель в строке меню

<img src="../en/panel-swipe.png" width="520" alt="Панель в строке меню: матовое стекло, заметки, напоминания и задачи Claude на карточках; строка, сдвинутая влево, показывает кнопку Remove">

Нажмите значок AllInOneIME в строке меню (знак ∞ с курсором, без рамки; значок в рамке — это источник ввода), и под ним раскроется панель; щелчок в другом месте её закрывает:

- "Notes" (заметки): заметки, сохранённые через `@note`, 5 самых новых; нажмите на заметку, чтобы открыть её в Notes.
- "Reminders" (напоминания): ещё не выполненные напоминания из списка AllInOneIME в Reminders (`@reminder` добавляет именно в этот список), сначала ближайшие по сроку, показано 8; нажмите на кружок, чтобы отметить напоминание выполненным, или на заголовок, чтобы открыть Reminders.
- "Claude Tasks" (задачи Claude): как в `@tasks`, фоновые задачи Claude (то, что передаёт `@claude`), до 30, по 5 на экране: прокрутите, чтобы увидеть больше, или ищите по их заголовкам и ответам в поле поиска; с ходом выполнения и первой строкой последнего ответа; нажмите на задачу, чтобы открыть её в Terminal и продолжить.

Сдвиньте строку (заметку, напоминание или задачу) двумя пальцами влево, чтобы показать её кнопку "Remove" (удалить), или до конца, чтобы сразу удалить; мышью — щёлкните по ней правой кнопкой. Удаление лишь убирает строку из панели: заметка остаётся в Notes, напоминание — в Reminders (невыполненным), задача — в Claude Code.

В заголовке — счётчики (например, "2 reminders · 1 task running"; задачи, ожидающие вас, считаются отдельно, например "1 waiting for you") и кнопка обновления. Панель никогда не забирает фокус у приложения, в котором вы печатаете: отметка напоминания или обновление оставляют это приложение на переднем плане; клавиатуру забирает только поле поиска задач Claude, после щелчка по нему. Значок показывается по умолчанию; выключить его можно в "Menu Bar Panel" в настройках.

Что панель читает и когда:

- Заметки: список — это собственная запись панели (она ведётся и когда панель закрыта), а Notes никогда не запускается: только если Notes уже запущено и AllInOneIME ранее получил разрешение им управлять, панель проверяет в нём изменённые заголовки и удалённые заметки.
- Напоминания: список AllInOneIME читается, когда панель раскрывается, каждые 60 секунд и при изменении напоминаний. Панель никогда сама не вызывает запрос доступа macOS: если macOS ещё не спрашивал вас, она показывает "Allow Access to Reminders", и запрос вызывает только эта кнопка; если вы отказали, она показывает "Open System Settings".
- Задачи Claude: панель выполняет `claude agents` только пока раскрыта: один раз при раскрытии, при обновлении и когда `@claude` передаёт задачу; а также каждые 15 секунд, пока какая-то задача не завершена, и перестаёт, когда завершены все. Последние ответы читаются из конца транскриптов Claude Code на этом Mac (`~/.claude/projects`), и только если транскрипт изменился.
- Пока панель закрыта, ничего из этого не выполняется; она лишь записывает заметки, которые сохраняет `@note`.

## Ввод и перевод

В настройках:

- **Input languages** (языки ввода): от одного до пяти из английского, китайского (пиньинь), французского, корейского и хинди, добавляются кнопкой + (она всегда видна; при пяти языках неактивна). После новой установки есть только английский. Новые текстовые поля начинают с первого; короткое нажатие Shift — следующий по порядку; если язык один, Shift не переключает.
  - **Французский** печатается в собственной раскладке: AZERTY, если на его карточке не выбрана другая. Его мёртвые клавиши (^, ¨, `, ´, ~) тоже работают от неё.
  - **Корейский** печатает хангыль в двухрядной раскладке (Dubeolsik), собирая каждый слог по мере ввода (g k s → 한); Shift даёт ㄲ ㄸ ㅃ ㅆ ㅉ и ㅒ ㅖ.
  - **Хинди**: набирайте слова латинскими буквами так, как они звучат, и получайте деванагари (namaste → नमस्ते). Распространённые слова пишутся так, как их пишут на хинди; в остальных случаях пробел вставляет первый вариант написания, цифра — другой, ⏎ — буквы как набраны, а "." — данду (।).
  - Имя команды, текст для `@open` и код (`@py`, `@js`) набираются латинскими буквами при любом языке; язык возвращается после команды.
  - `@improve` оставляет предложение на корейском, хинди или французском на его языке, а `@translate` переводит его на ваши языки (французский отличается от английского, если он входит в ваши языки ввода).
- **Language packs** (языковые пакеты): приложение поставляется с английским (и французским, которому нужна только раскладка macOS). Китайский, корейский и хинди — это пакеты, которые скачиваются при добавлении языка: при добавлении китайского (пиньинь) скачиваются его словари (около 34 МБ, 125 МБ в распакованном виде) с индикатором прогресса, и пиньинь работает сразу по завершении, без перезапуска; пакет корейского (таблица клавиш и правила сборки слогов из чамо) и пакет хинди (буквы и распространённые слова) занимают несколько килобайт. Пакет — это только данные (словари, таблицы и схемы, никогда не код), он указан в подписанном индексе и перед использованием сверяется по SHA-256, как и плагины. Карточка каждого языка показывает его пакет (версию, размер, источник) с кнопкой "Delete…", а при удалении языка предлагается удалить и пакет. При обновлении с 0.6.1 и более ранних версий китайский сохраняется без скачивания: установщик оставляет словари, которые шли со старой версией.
- **Fuzzy pinyin** (нечёткий пиньинь, при китайском вводе): звуки, которые вы не различаете, можно набирать любым способом, например z ↔ zh, n ↔ l, in ↔ ing. На странице "Input" выберите "Chinese (pinyin)" на панели языков ввода, включите "Fuzzy pinyin" и выберите пары; словари развёртываются заново за секунду-другую. Записывается файл `rime_ice.custom.yaml` в пользовательской папке Rime, и никогда поверх вашего собственного файла там.
- **Translate (@translate)**: добавьте языки, на которые нужно переводить (испанский, французский, немецкий, японский, корейский, китайский, хинди, бенгальский, тамильский и другие основные языки Индии…), и перетащите их в нужном порядке. Хинди, набранный латиницей ("aap kaise ho"), возвращается на деванагари. `@translate` пишет по строке на каждом языке в этом порядке (три варианта, если язык один); язык самого предложения пропускается. После новой установки перевод идёт на первый неанглийский язык из предпочитаемых языков вашего Mac; если там только английский, `@translate` открывает эту страницу, чтобы вы добавили язык.
- **Keyboard layouts** (раскладки клавиатуры): французский печатается в раскладке, выбранной на его карточке (`keyboardLayouts` в конфигурации). Для остальных языков macOS сохраняет под методом ввода вашу последнюю латинскую раскладку (AZERTY, QWERTZ, испанскую, US International…), так что вы печатаете как обычно, включая `@` там, где он есть в вашей раскладке, а мёртвые клавиши работают и в тексте команды (⌥E, затем E → é, ^, затем e → ê). Раскладки без латинских букв (русская, хинди InScript) нельзя использовать под методом ввода: переключайтесь на них через ⌃Space или вставляйте (⌃V) либо диктуйте текст в команду.
- `@improve` шлифует и переписывает без перевода; `@translate @improve` вместе переводят и переписывают за один запрос. Включите "@improve also translates" в настройках, чтобы `@improve` всегда делал именно так.

## Стили переписывания

После строк 1–3 идут варианты переписывания, **на том языке, на котором вы печатали**: для английского — на английском, для китайского — на китайском. Выберите любые из них в настройках:

- "Polish" (шлифовка): тот же тон, но естественнее
- "Concise" (кратко)
- "Formal" (официально): для руководителей и клиентов
- "Casual" (непринуждённо)
- "Tactful" (тактично)
- "Jargon" (жаргон): корпоративный язык Amazon по-английски (bandwidth, circle back…), жаргон крупных техкомпаний по-китайски. Плохие новости преподносятся мягче, например "this is a blocker bug" → "Oh! Looks like your team has the bandwidth to fix this minor issue!"

Варианты, которые меняют только пунктуацию или повторяют другую строку, не показываются.

### Список жаргона (ваши собственные термины)

У Jargon нет встроенного списка терминов. Вы можете составить свой (например, выражения, принятые в вашей команде), и модель будет отдавать предпочтение этим терминам. Среди кандидатов в строке Jargon поясняется, что значат использованные термины.

Список — это текстовый файл, по одному термину в строке, за которым может следовать его значение, отделённое "=", двоеточием или табуляцией (можно скопировать два столбца из электронной таблицы и вставить их). Строки, начинающиеся с `#`, — комментарии:

```
PRFAQ = a new-feature proposal: the press release and FAQ, written first
COE = an incident review
two-way door = a decision you can undo at any time
```

В настройках, в "Rewrite Styles → Jargon list", нажмите "New", чтобы создать пустой список в `~/.config/allinoneime/jargon.txt` и открыть его; если файл со списком у вас уже есть, нажмите "Choose File…", чтобы использовать его на месте (`jargonFile` в конфигурации). Изменения применяются сразу. Читаются только первые 150 терминов. Когда отмечен "Jargon", список отправляется в Bedrock вместе с каждым запросом.

## Голосовой ввод

<img src="../en/voice.png" width="340" alt="Удерживайте правую ⌥, чтобы говорить">

Удерживайте правую ⌥ и говорите; когда отпустите, текст вставится. Речь распознаётся на том языке, на котором вы печатаете (английский, китайский, французский, корейский или хинди). Если сначала набрать команду (например, `@improve `, `@question `), а потом говорить, текст добавится после команды, и ⏎ её выполнит; можно также нажать ⏎, не отпуская правую ⌥, чтобы выполнить команду сразу, как закончите. Речь распознаётся на самом Mac встроенным в macOS распознаванием речи (SpeechAnalyzer), и звук никуда не загружается; нужна macOS 26 или новее.

В первый раз:

- macOS спрашивает, может ли AllInOneIME использовать микрофон. Можно также заранее нажать "Allow Microphone" (разрешить микрофон) в настройках.
- Если на этом Mac ещё нет речевой модели для этого языка, она один раз скачивается автоматически. Её также можно скачать в настройках.

Запись начинается, только если удерживать клавишу около 0,2 с, поэтому быстрое нажатие правой ⌥ не включает микрофон (если клавишей действия выбрано "Tap ⌥", нажатие выполняет действие). Если во время удержания нажать другую клавишу (сочетание с ⌥, ⌥←), это считается сочетанием клавиш, и тоже ничего не записывается. Нажатие любой другой клавиши во время записи отменяет запись.

## Установка

Для работы нужна macOS 14 или новее, для голосового ввода — macOS 26 или новее. Установщик универсальный: работает на Mac с Apple silicon и Intel. Пока он проверен только на macOS 27 на Apple silicon (сборка для Intel — только собственным самотестом под Rosetta).

1. Скачайте `AllInOneIME-<version>.dmg` из [Releases](https://github.com/MicroZ-LLC/AllInOneIME/releases/latest) (только оттуда) и откройте его.
2. Дважды щёлкните в нём "Install AllInOneIME" и нажмите "Install". Метод ввода устанавливается в `~/Library/Input Methods`, а "AllInOneIME Settings" — в `~/Applications`. Только для этого пользователя; пароль администратора не нужен.
3. Установщик пока не заверен Apple, поэтому macOS не может проверить, кто его создал, и в первый раз сообщает, что не может проверить "Install AllInOneIME": нажмите "Done" (Готово) ("Cancel" в macOS 14), откройте "System Settings → Privacy & Security", внизу нажмите "Open Anyway" (Всё равно открыть) и подтвердите. Установщику каждой новой версии это нужно один раз.

После этого AllInOneIME включён и есть среди ваших источников ввода; переключайтесь на него сочетанием Ctrl+пробел (клавиша 🌐 переключает, только если в "System Settings → Keyboard" для "Press 🌐 key to" выбрано "Change Input Source"). Если установщик просит добавить его вручную, значит, этот Mac не позволяет программам включать его, и вам нужно один раз добавить его самостоятельно: "System Settings → Keyboard → Text Input → Input Sources → Edit… → + (внизу слева) → English → AllInOneIME" (Системные настройки → Клавиатура → Ввод текста → Источники ввода → Изменить… → + → Английский → AllInOneIME) (пиньинь он тоже печатает, как только вы добавите китайский в разделе "Input" его настроек).

Если Ctrl+пробел не приводит вас к AllInOneIME или через некоторое время всё переключается обратно на U.S., запустите установщик снова: он вернёт AllInOneIME в ваши источники ввода.

Чтобы обновиться, установите снова из образа диска новой версии, не удаляя старую; настройки, список жаргона и выученные слова сохраняются. Перед обновлением прочитайте [список изменений](../../CHANGELOG.md): в нём есть изменения каждой версии и примечания к обновлению.

Если у вас был установлен AIPinyin (прежнее название AllInOneIME), просто установите: старый AIPinyin.app и его ярлык настроек удаляются, а запись в ваших источниках ввода получает новое имя, добавлять её заново не нужно. Настройки, список жаргона и выученные слова при первом запуске переносятся в новые папки (`~/.config/allinoneime` и другие), а на месте каждой старой папки остаётся ссылка на новую.

Чтобы удалить, откройте "Install AllInOneIME" и нажмите "Uninstall…". Настройки и выученные слова сохраняются.

### Сборка из исходного кода

Для сборки нужен Xcode 26 или новее, так как голосовой ввод использует SDK macOS 26.

```sh
git clone https://github.com/MicroZ-LLC/AllInOneIME.git
cd AllInOneIME
make install
```

`make install` скачивает librime и словари rime-ice и проверяет их, собирает и устанавливает в те же места, точно так же добавляя метод ввода в ваши источники ввода. Устанавливаемое им приложение не содержит китайских словарей (они составляют китайский языковой пакет): если они уже были установлены, то сохраняются как пакет; иначе `make install-pack` устанавливает пакет из словарей рабочей копии, без скачивания. `make status` показывает установленную версию (`version:`) и есть ли метод ввода среди ваших источников ввода (`listed:`). Удаление: `make uninstall`.

## Настройка ИИ

Переводы и переписывание используют вашего собственного поставщика ИИ, и расходы идут на ваш аккаунт: по умолчанию Amazon Bedrock в вашем аккаунте AWS, либо Claude API, Gemini или сервис, совместимый с OpenAI (см. «Другие поставщики ИИ» ниже).

### Amazon Bedrock

1. Включите Bedrock в консоли AWS и убедитесь, что вам доступна выбранная модель. По умолчанию это Claude Haiku 4.5; при первом использовании модели Anthropic нужно один раз заполнить форму с описанием сценария использования.
2. Создайте ключ доступа с разрешением `bedrock:InvokeModelWithResponseStream` и поместите его в профиль в `~/.aws/credentials`. Пока поддерживаются только такие статические ключи, без SSO и assume-role.
3. Откройте "AllInOneIME Settings": его можно найти в Spotlight или в «Программах» либо открыть через значок метода ввода в строке меню → "Settings…". Выберите профиль, регион и модель и нажмите "Test Connection" (проверить подключение). "Language" (язык) в верхней части окна настроек может быть английским или китайским; по умолчанию ("System") он следует системе (китайский, если в предпочитаемых языках системы китайский стоит выше английского, иначе английский). Окно настроек, подсказки в панели кандидатов и меню ввода следуют этому выбору.

<img src="../en/settings.png" width="420" alt="Окно настроек">

### Другие поставщики ИИ: Claude API, Gemini, сервисы, совместимые с OpenAI

AWS не обязателен: выберите поставщика в "AI Provider" в настройках, вставьте API-ключ, нажмите "Save", затем "Test Connection".

| Поставщик | Модель по умолчанию | API-ключ |
|---|---|---|
| Claude API | `claude-haiku-5-5` (самая быстрая и дешёвая; Sonnet 5.5 и Opus 5.5 внимательнее, но медленнее и дороже) | [Claude Console](https://platform.claude.com) |
| Gemini API | `gemini-3.8-flash` | Google AI Studio |
| Совместимые с OpenAI | `gpt-6-luna` от OpenAI (или `gpt-5.4-mini`); в "Common Services…" (популярные сервисы) есть DeepSeek, Qwen, Kimi, Zhipu GLM, SiliconFlow, OpenRouter и Ollama на этом Mac: выбор сервиса заполняет его базовый URL, затем укажите модель | Ключ сервиса; в "Base URL" укажите его адрес, например `https://api.deepseek.com/v1`, или `http://localhost:11434/v1` для Ollama на этом Mac |

- API-ключи хранятся в системной связке ключей, никогда в файле конфигурации. Если там ключа нет, используются `ANTHROPIC_API_KEY`, `GEMINI_API_KEY` (или `GOOGLE_API_KEY`) и `OPENAI_API_KEY` из вашей оболочки.
- "Thinking" (рассуждение) по умолчанию низкое: метод ввода ждёт ответа на каждое предложение, а чем меньше рассуждений, тем быстрее. Для моделей, которые его не поддерживают, выберите "Not set" (не задано).
- Если выбраны Claude Opus 5.5 или Sonnet 5.5, запросы включают резервный вариант Claude API на случай отказа (`fallbacks: "default"`): когда классификатор безопасности отклоняет запрос, сервер повторяет его на другой модели.
- В файле конфигурации: `provider` (`"bedrock"`, `"anthropic"`, `"gemini"`, `"openai"`), а также `model`, `baseURL`, `effort` и `temperature` внутри `anthropic`, `gemini` и `openai` (незаданные используют значения по умолчанию).

Все настройки хранятся в `~/.config/allinoneime/config.json`; после изменения следующий перевод уже использует новые настройки, без перезапуска. Новые ключи:

| Ключ | Что делает | По умолчанию |
|---|---|---|
| `inputLanguages` | Языки ввода, от одного до пяти, первый — по умолчанию: `"en"` английский, `"zh"` китайский (пиньинь), `"fr"` французский, `"ko"` корейский, `"hi"` хинди, например `["en", "zh"]`, `["fr", "en", "ko"]`. Китайский, корейский и хинди работают после установки их пакета | `["en"]` (новая установка) |
| `keyboardLayouts` | Раскладка клавиатуры для языка ввода, по его коду (пока только французский): `{"fr": "com.apple.keylayout.French-PC"}` | Французский: `com.apple.keylayout.French` (AZERTY) |
| `outputLanguages` | На какие языки переводит `@translate`, по порядку: `["es", "fr", "de"]`, … | `["en"]` |
| `improveTranslates` | `@improve` также переводит (как `@translate @improve`) | `false` |
| `voiceInput` | Удерживать правую ⌥, чтобы говорить | `true` |
| `actionKey` | Клавиша действия: `"enter"` (⏎), `"optionTap"` (Tap ⌥), `"optionSpace"` (⌥Space), `"space"` (Space) | `"enter"` |
| `uiLanguage` | Язык интерфейса (окно настроек, подсказки в панели кандидатов, меню): `"zh"`, `"en"` | `null` (следовать системе) |
| `rewriteStyles` | Стили переписывания: `polish`, `concise`, `formal`, `casual`, `tactful`, `jargon`, например `["polish", "concise", "jargon"]` | Polish, Concise, Formal |
| `jargonFile` | Ваш собственный файл со списком жаргона | `null` (т. е. `~/.config/allinoneime/jargon.txt`) |
| `menuBarIcon` | Значок в строке меню и его раскрывающаяся панель | `true` |
| `fuzzyPinyin` | Пары нечёткого пиньиня: `["z-zh", "n-l", "in-ing"]` (z-zh, c-ch, s-sh, n-l, f-h, r-l, an-ang, en-eng, in-ing, ian-iang, uan-uang) | `[]` |

## Конфиденциальность

- Набор текста (английский и пиньинь) и вычисления `@calculate` полностью локальны. Только когда вы нажимаете клавишу действия в `@improve`, `@translate` или `@question`, это предложение отправляется выбранному вами поставщику ИИ (вашему собственному Bedrock или сервису, ключ которого вы добавили). Если отмечен "Jargon" и задан список жаргона, список отправляется вместе с ним.
- С AllInOneIME Cloud предложение проходит через сервер разработчика к поставщику модели (сейчас через OpenRouter): сервер хранит только счётчики, никогда не текст. При входе в аккаунт сохраняется только ваш адрес e-mail.
- Голос записывается только пока вы удерживаете правую ⌥ и распознаётся на Mac; распознанный текст отправляется только в перечисленных выше командах, когда вы нажимаете клавишу действия.
- Метод ввода читает текст из буфера обмена один раз и только когда вы нажимаете ⌃V или ⌘V в команде; содержимое, которое менеджеры паролей помечают как скрытое, не читается. Текст сначала показывается в команде и, опять же, отправляется только по нажатию клавиши действия. Последние версии macOS спрашивают, может ли AllInOneIME читать буфер обмена: разрешите. Чтобы вопрос не появлялся каждый раз, установите для AllInOneIME разрешение на вставку «всегда разрешать» в "System Settings → Privacy & Security".
- В полях паролей macOS переключается на собственную клавиатуру (U.S. или ABC) и возвращается обратно, когда вы их покидаете. Всякий раз, когда приложение, в котором вы печатаете, включает безопасный ввод, AllInOneIME не обрабатывает текст и не может записывать звук: клавиши вводятся как есть. И пока система находится в режиме безопасного ввода (поля паролей, "Secure Keyboard Entry" в Terminal и т. п.), ничего не отправляется ИИ.
- `@note` и `@reminder` не обращаются к ИИ: AllInOneIME передаёт текст только в Notes и Reminders на этом Mac и время напоминания тоже распознаёт на Mac (синхронизируют ли эти приложения его с другими вашими устройствами, зависит от их аккаунтов, например iCloud). Поэтому они работают и во время безопасного ввода.
- `@open` ищет только на этом Mac. Он запоминает, что вы с его помощью открывали (последние 200), в собственных настройках метода ввода (не в config.json), чтобы показывать это первым.
- Чтобы показывать ваши заметки, панель в строке меню хранит id и первую строку (до 80 символов) последних 30 заметок, сохранённых через `@note`, в собственных настройках метода ввода, в том числе когда панель выключена.
- `@py` и `@js` выполняются только по нажатию клавиши действия и только с кодом, который вы сами набрали или вставили: ответы ИИ и вывод других команд никогда не выполняются как код. `@py` использует `python3` вашего Mac, который может читать и записывать файлы и выходить в сеть, как в Terminal; `@js` выполняется в отдельном процессе, который не может читать файлы, выходить в сеть или запускать другие программы. Ни тот ни другой не выполняется во время безопасного ввода.
- Журналы не записывают то, что вы печатаете. Для любого стороннего метода ввода macOS предупреждает: "The developer can access anything you type with this input source" (разработчик может получить доступ ко всему, что вы вводите с помощью этого источника ввода); это общее системное предупреждение.

## Разработка

```sh
make test         # unit tests, plus tests that run the real Rime engine
make pack         # the Chinese language pack: build/packs/zh-pinyin-<version>.tar.xz, its sha256, its packs.json entry
make packs        # all the language packs: Chinese, and Korean and Hindi from LanguagePacks/ (ko-hangul, hi-phonetic)
make selftest     # drives the input method through a simulated text field: real Bedrock calls, plus on-device recognition tested with synthesized speech
make realtest     # types into a real app's text field (needs the screen unlocked; takes over the foreground for about 1 minute)
make screenshots  # regenerates the screenshots in docs/
make cli && .build/release/allinoneime-cli --styles concise,jargon "this is a blocker bug your team need fix it asap"   # try polishing and rewrites in the terminal
make icon         # regenerates the app icon and the menu bar icon from Resources/AppIcon.png
make dmg          # the release installer, build/AllInOneIME-<version>.dmg (universal; signed if there's a Developer ID certificate, optionally notarized)
```

Структура кода:

- `Sources/AllInOneIMECore`: клиент Bedrock, SigV4, промпты, двухуровневый конечный автомат ввода (включая @-команды и голосовой жест); без зависимости от AppKit
- `Sources/AllInOneIMERime`: обёртка над librime
- `Sources/AllInOneIME`: метод ввода на InputMethodKit, панель кандидатов, окно настроек, распознавание речи
- `Sources/AllInOneIMESettings`: ярлык "AllInOneIME Settings"
- `Sources/AllInOneIMEInstaller`: "Install AllInOneIME" на образе диска: установка, обновление и удаление

У языковых пакетов своя библиотека, отдельная от плагинов: репозиторий [MicroZ-LLC/AllInOneIME-languages](https://github.com/MicroZ-LLC/AllInOneIME-languages), раздаётся с https://languages.allinoneime.com/ и подписывается собственным ключом. `make pack` собирает архив; он публикуется там как файл релиза (релиз `zh-pinyin-<version>`, `ko-hangul-<version>`, `hi-phonetic-<version>`), а `swift Scripts/build-packs-index.swift <languages repo> build/packs/*.tar.xz.json` записывает туда `packs.json` и подписывает его в `packs.json.sig` ключом языковых пакетов из связки ключей (`allinoneime-languages-signing`). Приложение читает https://languages.allinoneime.com/packs.json, проверяет подпись, затем размер архива и его SHA-256. Чтобы опробовать пакет с локального сервера: `--test-key` подписывает тестовым ключом, а затем `AllInOneIME --install-pack zh-pinyin --library http://127.0.0.1:8765/ --key <its public key> --packs-dir <folder>`.

Bundle ID по-прежнему `com.aipinyin.inputmethod.AIPinyin`: macOS по нему запоминает добавленный источник ввода и разрешение на микрофон, поэтому его смена означала бы, что метод ввода придётся добавить, а разрешение выдать заново.
